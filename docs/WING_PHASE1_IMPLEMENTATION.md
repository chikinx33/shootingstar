# 주포 분기·편대 교전 1차 구현 — v10.0.2

2026-10-18. 사용자 승인한 `WING_FIGHTER_INTEGRATION.md`의 1차 범위만 구현했다. 기존 Flutter 엔진·캐주얼 메카닉 미술·자유 이동 전장을 유지한다. 원작 소스/자산을 제품에 편입하지 않았다.

## 웹에서 확인하는 방법

1. 로비 하단 버전이 **v10.0.2**인지 확인한다.
2. 성장 화면의 '독립 주포 / 주포 계열'에서 펄스 주포·중형 레일건·산탄 캐논 중 하나를 선택한다.
3. 출격해 경험치를 회수한다. **첫 레벨업인 Lv.2**에서 해당 주포의 두 특화와 일반 성장 한 개가 함께 제시된다.
4. 특화 하나를 고르면 이번 출격 동안 유지되고 HUD에 이름이 표시된다. 일반 성장을 선택해도 진행 가능하며 특화는 이후 일반 선택 풀에 남는다. 다시 뽑기는 기존 횟수를 사용한다.
5. 일반 전투에서 첫 편대는 약 8초에 진입한다. 일렬/펼침이 교대하며, 보스 접근·적 상한·진행 중 편대가 있으면 새 편대를 보류한다.

## 이번 패치의 자체 초기 수치

아래는 원작 수치를 복제한 것이 아니라 기존 엔진에 맞춰 시작한 자체 값이다. 수치가 최종 밸런스라는 뜻은 아니다.

| 주포 / 분기 | 행동 변화 | 교환 조건 |
|---|---|---|
| 펄스 / 집속 | 발사 위치 폭을 35%로 압축, 기존 각 탄에 관통 +2 | 각 탄 피해 90% |
| 펄스 / 확산 | 탄수 +2, 탄 간 각도 0.14rad의 전방 부채꼴 | 각 탄 피해 72%; 진화 빔은 폭 확대·피해 70% |
| 레일 / 과관통 | 기존 관통에 +5 | 각 탄 피해 80%, 단일 보스에는 추가 피해 없음 |
| 레일 / 축전 | 재장전을 끝낸 다음 사격 묶음의 피해 2배·탄 굵기 1.6배 | 재장전 1.4→1.8초, 다음 사격에는 보너스 없음 |
| 산탄 / 근접 압축 | 탄 간 각도 일반0.035/진화0.02rad, 실제 이동거리 140 이내 피해1.5배 | 140 초과 피해0.55배 |
| 산탄 / 파편 확산 | 탄 간 각도 일반0.19/진화0.11rad, 명중하면 양옆 파편2개 | 본탄 피해65%, 각 파편은 그 피해의40%, 수명0.45초 |

파편은 원래 맞은 적을 다시 때리지 않고 재분열하지 않는다. 충돌 순회가 끝난 다음 추가해 같은 리스트를 순회하면서 수정하지 않는다. 압축 산탄은 탄속 변화가 있어도 실제 이동거리로 근거리 여부를 계산한다. 특화 산탄은 전방을 향하고, 미선택 상태의 기존 발사 방식은 그대로다.

기존 진화 효과와 R/P/N에 겹쳐 적용한다. N 증가가 여섯 분기 모두에서 진화 전후 발사 수에 반영된다. 축전은 전투 시작 시 자동 2배가 아니며, 실제 탄창을 소진한 뒤 긴 재장전을 기다려야 한다. 원래 레일건 코드의 탄창·발사 주기는 미선택 때 유지했다.

## 편대 규칙

- 일렬4기 / 펼침5기. 새 적 역할이나 저장 ID를 추가하지 않고 기존 정찰기의 별도 편대 상태를 사용한다.
- 진입1.25초 → 사격 대기/예고 → 3.8초부터 교차 이탈 → 7.2초에 퇴장.
- 조준은 예고 시작에 고정한다. 기존 사격 함수·적 탄환 예산을 사용하며 진입·이탈 중 발사하지 않는다.
- 목적지는 월드 안에 두어 가장자리의 적을 처치했을 때 경험치가 회수 불가능한 곳에 남지 않게 했다.
- 편대에는 일반 선회·밀집 분리·먼 적 재배치를 적용하지 않아 이동 대형이 보존된다.
- 놓친 편대의 퇴장은 처치·경험치를 지급하지 않는다. 정상 처치는 기존 보상을 지급한다.
- 첫 편대8초, 다음 생성 시계20초. 진행 중 편대가 있으면 동시 추가하지 않고 보스까지8초 미만이면 생성하지 않는다. 기존 돌입 편대는 유지한다.
- HUD와 전장을 분리한 현재 레이아웃에 맞춰 적 사격 가능 영역의 옛 HUD 보정152px를 실제 전장 여백12px로 수정했다. 화면 안에 들어온 적만 기존 거리 조건·예고 후 사격한다.

## 유지한 성장·진화·저장

특화는 `GameEngine`의 출격 상태에만 기록한다. `upgrades`/`passives`에 새 항목을 넣지 않아 공격6/보조6 제한에 영향을 주지 않는다. 한 판에 두 특화를 선택하거나 다른 주포 특화를 적용하는 입력을 거부한다. 새 출격에는 초기화된다.

R/P/N 상한과 R3/P3/N2 주포 독립 진화, 무기5+대응 보조1 이상 진화, 드론/태양 기뢰/전격 기뢰/의료 드론 융합을 유지했다. 기존 선택 ID와 주무기/파일럿 목록 순서도 유지했다.

`lib/data/profile.dart`는 작업 전 스냅샷과 SHA-256이 동일하다. 영구 데이터·서버 저장 스키마와 장비 ID를 변경하지 않아 저장 이전을 추가하지 않았다. 정지/선택 중 발사·장전·편대 시간이 흐르지 않으며 보스 전환은 편대와 적 탄을 기존 방식으로 정리한다.
