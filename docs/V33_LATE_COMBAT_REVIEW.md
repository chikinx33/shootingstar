# v10.0.33 전투 밸런스·후반 완주 점검

2026-10-20. 사용자 요청에 따라 현재 엔진·성장·100항로/회차·보스 사슬을 다시 대조했다. 실제 상품/광고 ID는 활성화하지 않으며 Android APK를 빌드하지 않는다. 이전 v10.0.22 제품 평가 점수를 현재 점수로 재사용하지 않는다.

## 확인한 결함과 반영

| 항목 | 근거와 영향 | 변경 |
|---|---|---|
| 보스 접촉·환경 위험의 위협 배율 중복 | 호출부와 공통 `_damage`가 각각 `sqrt(threat).clamp(1,3)`을 곱함. 같은 후반 단계의 적탄보다 배율이 한 번 더 적용됨. 환경 규칙 문서의 단일 배율 설명과도 불일치 | 호출부는 기본 피해20/세계별4 또는7만 전달. 공통 함수에서 배율·방호·피격 무적 적용 |
| 기뢰 사망 원인이 일반 교전으로 기록됨 | 적/보스 기뢰가 `_damage(s.damage)`를 호출하여 전투 기록에서 원인을 구분하지 못함 | `기뢰` 원인과 활성화 전 이탈/보스 고리 출구 대응 안내 연결 |
| 최종 항로 결과가 일반 항로와 같음 | 100항로를 마쳐도 `CHAPTER COMPLETE`, 일반 성공 문구와 `다음 항로 출격`만 표시 | `CAMPAIGN COMPLETE`/100개 항로 완주/완료 회차와 성장 보존 안내/다음 회차 출격. 기존 회차 전환·정산을 호출하며 새 보상은 만들지 않음 |
