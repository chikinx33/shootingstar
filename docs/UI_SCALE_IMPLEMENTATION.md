# UI 크기·가독성 교정 — 2026-10-17

사용자가 첨부한 일시정지 화면은 긴 가로 버튼과 작은 글자/아이콘이 원본의 큰 덩어리 중심 구성과 달랐다. 기존 공통 테마의 기본 글자 14–15px와 전체 폭 결정 버튼을 제거하고, 화면 역할에 따라 실제 그림 크기를 고정하는 규격을 적용했다.

## 기준과 코드

- `UI_DESIGN_SYSTEM.md`: 실제 참고 이미지, 역할별 높이/글자/아이콘, 폭 비율, 줄바꿈, 글자 확대, 완료 조건의 공통 기준.
- `lib/ui/game_ui.dart`: 단일 토큰 원본과 `GameActionButton`. 주요 결정 최소 72px / 글자 22px / 아이콘 36px, 보조 결정 64 / 20 / 32. 폭 최대 264px, 폭/높이 최대 4.25.
- `AGENTS.md`, `CLAUDE.md`, `SHARED_SKILLS.md`, `GAME_DIRECTION.md`: 이후 Codex·Claude 작업이 같은 규격과 검사 절차를 읽도록 연결.
- `tools/qa/check_ui_contract.py`: 12px 미만 글자, 15px 미만 행동 글자, 28px 미만 행동 아이콘, 48px 미만 행동 높이, 행동 문구 축소/말줄임, 주요 결정 버튼의 개별 구현을 검사. 실행은 `python tools/qa/check_ui_contract.py`.
- `test/ui_contract_test.dart`: 모바일 4종과 130% 글자 배율에서 메뉴를 검증하고, 일시정지/결과 **실제 RasterPanel**의 높이·비율·글자·아이콘, 계속/종료, 보상 중복 방지를 검사. 투명한 터치 영역을 버튼 그림 크기로 계산하지 않는다.

## 실제 변경

일시정지/결과는 최대 344px 콘텐츠와 264px 결정 버튼으로 제한했다. 주요 행동을 눈에 먼저 들어오게 배치하고 통계/귀환의 높이와 글자도 늘렸다. 긴 귀환·일일 도전 문구는 축소하지 않고 줄바꿈한다. 결과 통계는 글자 확대 시 각 칸 안에서 줄바꿈한다.

홈 출격은 72px 높이를 확보하고 보이는 문구를 '출격'으로 간결하게 만들었다. 접근성 이름에는 원래 항로 이름을 유지한다. 후속 사용자 지시로 짧은 화면에서도 로비 스크롤을 완전히 제거했다. 현재 구성과 검증은 `CATALOG_FIXED_UI_IMPLEMENTATION.md`를 따른다. 하단 내비게이션은 88px 이상, 아이콘 44/48px, 글자 14px다. 홈 바로가기는 76×84px, 그림 40px다. 자원 숫자는 18px로 키우고 큰 값은 K/M로 표시하되 접근성에는 전체 값을 남긴다.

성장의 수집품/진화 연구는 아이콘 36px를 글자 위에 배치한 88px 이상 타일로 바꾸어 좁은 칸에서 마지막 한 글자만 끊어지는 현상을 없앴다. 일반 행동은 60px/18px/28px 이상을 기본으로 한다. 진화 연구의 좁은 개별 셀은 명명된 48px/15px 규격을 사용한다.

인벤토리는 68px 장비 그림·14px 이름/상태를 사용한다. 휴대폰에서 기본 3열, 글자 확대 시 2열이며 이름 칸도 배율에 맞춰 커진다. 메뉴/설명 글자의 6–11px 직접 지정을 없앴고 관련 안내는 14–16px로 높였다. 전투 스킬 선택은 56px 아이콘, 15px 제목, 14px 설명을 사용한다. 전투 HUD의 13px 스킬 그림/6px 별은 20px 그림과 12px 등급 숫자로 바꿨다.

생성 PNG에 대응하지 않는 계속/통계 기호는 의미가 맞는 글리프로 표시한다. 기존의 미등록 아이콘을 무조건 선물 그림으로 대체하던 연결을 수정했다. PNG 9장은 재생성하지 않았다.
