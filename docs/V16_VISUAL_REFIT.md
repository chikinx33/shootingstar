## 미술과 제작 결과

신규 독립 PNG8종은 `assets/art/refit_v16/`에 저장했다. 모두 내장 `image_gen`으로 제작했고 외부 이미지 API/CLI는 사용하지 않았다. 최초 프롬프트·소스는 `generation.json`, 도전 배지의 외곽선/여백 재시도는 `refinement.json`에 기록했다. PNG 픽셀은 수정하지 않고 복사했다. `manifest.json`은 실제 알파 경계와 원본SHA256을 기록한다. `tools/qa/audit_refit_art.py`는 원본 동일성·실제 투명도·가장자리24px 이상 여백을 확인한다.

- `hero.png`: 아이보리/오렌지 균형 기체 오로라.
- `vector.png`: 좁은 민트/청록 고속 기체 벡터.
- `monolith.png`: 넓은 자주/금색 중장 기체 모노리스.
- `backdrop.png`: 중앙 대비를 낮춘 앰버 격납고, 외곽 남색 구조/제한된 청록 포인트.
- `chest.png`, `growth.png`, `challenge.png`, `research.png`: 같은 아이보리/금색/청록 재질의 핵심 메뉴4종.

새 기체는 `RefitArt`에서 기존 공유 그림 주소를 교체하므로 로비·격납고·선택 슬롯·실제 전투가 동일한 픽셀을 사용한다. 엔진/적/보스/펫/장비의 게임 규칙과 저장 구조를 변경하지 않았다. 이번에 기존 적·보스·펫51개를 전부 새로 생성한 것은 아니다. 공통 UI 미술은 전체 화면에 적용하고, 신규 일러스트는 위8종이다.

## 레이아웃과 공통 렌더링

자원 표시는 한 줄의 아이콘/수량으로 정리했다. 항로는 남색 카드와 세계 미리보기로 구분한다. 짧은 화면에서는 세계명과 항로 숫자만 표시하며 글자를 축소하지 않는다. 훈련과 가이드는72px 출격 버튼 양옆에 배치하고 원래 콜백/접근성 이름을 유지했다. 로비의 기능은 스크롤 없이 접근한다. 안전 영역을 포함한320×568/글자130%에서만 사이드 바로가기를48px 이상 도색/26px 그림/13px 라벨로 조밀하게 배치한다. 일반 바로가기는40px 그림과14px 라벨, 내비게이션은88px 이상과44px 그림/14px 라벨을 유지한다. 신규 무기 편집 바로가기는 공간이 충분할 때만 전시 아래 추가된다.

공통 패널은 단일 연속 경로의 명암·안쪽 테두리·짧은 그림자를 사용한다. 비트맵 조각을 늘여 붙이지 않는다. 글자에 중첩된 좌우 그림자를 줄였고 중요 제목/행동의 굵기는 유지했다. 회색 슬롯은 남색/등급색 명암으로 교체했다. 이전 최소3열·체크 선택·짧은 팝업·개발자 별도 저장을 유지한다.

실제 첫 웹 캡처에서 중첩 배경의 drawColor가 앞서 그린 상단 자원을 지우는 문제가 발견되었다. 배경을 해당 사각형 안에만 그리도록 고쳤고 `refit_backdrop_test.dart`로 회귀를 방지한다. 기체/이름/무기는 하나의 정렬 그룹으로 묶었다.
