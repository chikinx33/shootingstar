## 경계

## 실제 연결 흐름 확인

QA 프로필에서 길드 등록 → 창설 → 출석 코인10 → 일일보급 구매 → 우편 1건 → 수령 후 0건 → 먹이30→60 및 설계도2 지급 → 루미 Lv.2 육성 → 미오 구조를 브라우저 버튼으로 수행했다. 장비/테크 보급을 각각 1회 열어 인벤토리7개, 테크 공격1/3 장착을 확인했다. 육성 일일임무 수령 후 200 C / 시즌50 XP, 새로고침 후 장비7개·테크1/6·우편0건이 유지됐다. 브라우저 오류 로그 없음.

훈련에서 펫 이미지와 체력 표시, 펫 동행·탄환 발사, 무기 선택을 확인했다. 20초/67격파 후 귀환 정산은 훈련 무보상으로 처리됐으며 성장 정비 복귀 버튼을 검증했다. 테스트 수치이며 사용자 플레이 기록에 반영하지 않았다.
