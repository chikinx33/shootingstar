## 반영

- 기존 실패 UI44건의 실제 동선을 복구했다. 장비 합성/펫 육성/보급/유물/보스 장비는 현재 슬롯과 상세를 열고 실제 페이지 버튼으로 접근한다. 고정 HUD로 옮겨진 시너지/특화는 전투 정보 창에서 읽고,240ms 선택 연출 후 실제 강화를 확인한다. 설정/연구 이름·닫기 제어도 현재 제품과 일치시켰다. 경제·저장·글자 크기·노치·입력 검사를 삭제하거나 건너뛰지 않았다.
- 항로 상세에10세계의 원래 목표, 고유 환경과 구체적인 회피 경로,3초 예고/2초 활성/보스 중 비활성 규칙을 추가했다. 그림은 공통72px 상세 규격으로 맞추고 긴 내용은 기존 고정 페이지로 읽는다.
- 격납고의 기존 `성장 길잡이`에서 최근 실패에 맞는 대응을 읽고 `출격 기록과 다음 목표`로 들어간다. 최근8회의 항로·무장·레벨·시간·격파·보스·마지막 피격·주요 피해 기여와 다음 출격 목표를 보관한다. 기록 상세에서 영구 연구/주무기 강화로 실제 이동한다.
- 기록은 로컬 전용이며 클라우드/서버 분석 이벤트로 보내지 않는다. 일반 전투 종료 정산과 같은 저장 값에 기록하고, 같은ID 중복·최대8건·잘못된 입력을 보호한다. 훈련/개발자/효과 재현은 일반 기록을 쓰지 않는다. 진행 교체 시 기록을 제거한다.
- 장비 상세를 열어 둔 사이 외부 진행 변경으로 해당 장비가 없어져도 빈 모달로 갇히지 않고, 설명과 닫기를 제공한다.
- 옵션의 옛 `진행 중 전투 제외` 문구를 실제 이어하기 동작에 맞게 바로잡았다.
