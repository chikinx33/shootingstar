## 현장 안내

누르기/떼기/이동은 실제 동작을 관찰한다. 눌렀다는 이유만으로 이동이나 경험치 회수까지 완료했다고 처리하지 않는다. 선택창·명시적 일시정지·보스 종료 동안 학습 시간을 누적하지 않는다. 보스 예고와 항성포 준비는 상황 안내를 우선한다.

새 패널을 추가하지 않고 기존 전장 하단 메타데이터 행을 사용한다. 14px와 명시적 접근성 레이블을 유지한다. 긴 설명은 정보창과 가이드의 고정 페이지에서 읽는다. 안내가 체력·보상·적탄·무장 선택을 대신 수행하지 않는다.

## 피해 설명

피해를 실제로 적용하기 직전과 직후의 선체 차이를 기록한다. 적탄·유도탄·레이저·폭발·적기/보스 접촉·환경 위험을 구분한다. 개발자 무적과 방패 전량 흡수는 선체 피해로 집계하지 않는다. 해당 기록은 출격별 메모리 상태이며 클라우드 저장이나 운영 서버 전송을 추가하지 않는다.

기존 피해 함수에 선택적인 출처를 붙였으며 피해 공식·공격 순서·불사 시간·보스 단계·보상 계산을 바꾸지 않았다. 결과 안내의 ‘마지막 피격’은 사망 원인의 최종 접촉을 설명한다. 전체 실패를 그 한 가지 원인으로 단정하지 않는다.

## 음향과 로딩

배경음은 실제 비행 입력 뒤 시작하고 명시적 정지/배경 전환/결과/종료에 맞춰 중단한다. 음량은 기존 설정을 사용한다. 오류 시 재생이 전투를 막지 않으며 5초의 재시도 간격을 둔다. 무기 효과음도 기존 재생 빈도와 동시 재생 제한을 유지한다.

게임 그림은 출격용 적 11개를 분리했다. 첫 로비에는 메뉴·보스 썸네일·도해에 필요한 그림만 디코딩한다. 처음 출격 시 필요한 적 그림이 전부 준비된 뒤 시뮬레이션을 시작한다. 이후 출격은 캐시를 재사용한다. 기본 그림 묶음이 정상적으로 로드되면 쓰이지 않던 이전 세대 로딩 분기를 제거했다.

원본 PNG 합계와 디코딩 크기로 추정한 RGBA는 네트워크 실측이나 GPU 메모리 실측과 다르다. 실제 로딩 속도·저사양 성능은 별도 검증 항목이다. 배포 용량과 첫 다운로드 용량을 동일하게 표시하지 않는다.
