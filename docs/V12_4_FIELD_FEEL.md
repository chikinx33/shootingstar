# v12.4.0 집 스테이지 조작·적·드롭·보스 전환 개편

사용자 요청(2026-10-24, v12.3 플레이 피드백) 12가지를 집 스테이지(`screenMode`)에 반영했다. 옛 자유 비행 경기장(`legacyArena`)은 바꾸지 않았다.

## 적

| 항목 | 변경 |
| --- | --- |
| 일반 적기 크기·체력 | 반경 ×1.3(무거운 적 ×1.25), 체력 ×1.4 (`_createEnemy`). 처음엔 ×1.4/×1.7로 했으나 피하지 않는 자동 비행 측정에서 피해 속도가 이전의 약 2배라 완화했다 |
| 적 총알 | 그림 크기 약 1.5배(반경 ×5.3~5.4로 그림), 판정 반경은 4→4.5만 늘려 회피는 공정하게 유지 (`hostileBulletRadius`) |
| 후방 등장 | 새 편대 `WaveKind.rear`: 화면 아래에서 올라와 고양이 옆을 지나 위로 빠짐. 7번째마다(3, 10, 17…) + 9번째 이후 무작위 후보. "후방 접근!" 알림과 경고음, 등장 후 2.6초 뒤부터 사격 |
| 중간 보스 | 5번째마다 나오던 호버 편대를 중간 보스 1기 + 호위 2기로 바꿈. 반경 30, 체력 ×4.5, 8자 비행, 4패턴 순환(조준 5갈래 3연사 → 이중 고리 → 쌍나선 → 내려오는 커튼), 체력 50% 이하 1.4배 빠름. 상단 넓은 체력바와 "중간 보스" 이름 표시 (`eliteAttack`) |

## 조작

- **조작 방식 두 가지**(설정 → 조작·음향 → 조작 방식). 기본값은 새 방식인 **손가락 따라가기**.
  - 손가락 따라가기: 누른 곳 56px 위로 고양이가 미끄럼 없이 곧장 날아간다(최고 속도 이동속도×2.1, 도착하면 멈춤).
  - 가상 조이스틱(기존 방식): 작은 기울기를 줄이는 정밀 곡선(입력^1.4)을 넣어 미세 회피 때 덜 미끄러진다. 최대 기울기는 그대로 1.
- 손을 떼면 5% 슬로모션이 되는 기존 규칙은 두 방식 모두 같다.
- **좌우 화면 확장**: 비행 가능한 영역이 화면 양옆으로 56px씩 넓어지고, 고양이가 가장자리로 가면 카메라가 따라 밀린다(`fieldRect`, `screenPan`). 손가락 따라가기는 밀린 뒤에도 손가락 바로 위에 오도록 역변환한다(`screenToField`).
- **항성포 버튼**: 글자 없는 지름 64px 원형 버튼(`StarCannonButton`), 오른쪽(설정 시 왼쪽) 가장자리, 전투 영역 높이 58% 지점. 충전은 고리로, 준비되면 금색. 스크린리더용 이름은 유지.

## 드롭과 보석

- 시간마다 떨어지던 무작위 보급(수리·폭탄·자석·주포 R/P/N)을 집 스테이지에서 끈다.
- **편대를 전부 격추했을 때**(놓친 적 없이) 마지막 적기가 아이템 1개를 떨어뜨린다: 총알 강화·미사일 강화(각 가중치 3), 수리(체력에 따라 0.5~4), 자석(보석 6개 넘을 때), 폭탄(1). 화면에 5개 이상이면 생략.
- **중간 보스 전용 보급 상자**(금색 선물 상자, 더 크게 빛남): 총알·미사일 동시 1단계 성장 + 체력 25% + 화면의 보석 모두 회수.
- 아이템 그림은 래스터 PNG(codex-imagegen): `icons_v12/item_bullet.png`(청록 캡슐), `item_missile.png`(주황 캡슐+고등어), `item_elite.png`(금색 선물 상자).
- 아이템과 보석은 거리와 함께 천천히 아래로 흐르고(34·40px/초) 화면 밖으로 나가면 사라진다. 보스 상자는 흐르지 않는다.
- **보석**은 더 이상 멀리서 끌려오지 않는다. 고양이 주변 회수 반경(집 스테이지는 1.25배) 안에 들어와야 흡수된다.

## 성장 카드

- **총알(주포)과 고등어 미사일**은 레벨업 카드에서 빠지고 드롭 아이템으로만 성장한다(`dropOnlyGrowth`). 드롭 한 번에 강화·진화가 번갈아 1단계씩 오르고, 둘 다 3이면 궁극(슬로모션 변신 연출 그대로).
- 궁극 카드는 효과의 첫 문장만 보이고, 길게 누르면 전체 설명이 나온다(글자 1.3배에서 카드가 넘치던 문제 수정).

## 보스 전환

- 평소에는 동네 거리 타일만 끝없이 흐르고, 집 그림은 보스 전용 지도로 분리했다(두 그림의 건물 크기가 달라 이어 붙이면 어색했다).
- 보스 3초 전부터 구름 떼가 흘러와 화면을 덮고(`cloudCover` 0→1), 완전히 덮인 순간(1.5초 전) 보스 지도로 바뀌며 남은 편대와 적 탄이 사라진다. 구름이 걷히는 순간 보스가 등장한다.
- 보스를 잡은 뒤 다음 구간이 남아 있으면 같은 구름 연출(2.6초)로 거리로 돌아간다.
- 구름은 적·탄 위, 고양이 아래에 그려 조종은 계속 보인다. 구름 그림은 기존 `worlds_v11/clouds.png`를 4겹으로 겹쳐 쓴다.

## 저장

중간 보스 여부(`elite`)와 구름 귀환 타이머를 전투 체크포인트에 저장한다. 보스전 중 복원하면 보스 지도로 시작한다. 편대 경로(`WavePath`)는 예전처럼 저장하지 않는다.

## v12.4.1 레벨업 팝업은 보석 순간에만

사용자 확인 요청: 보석을 줍지 않았는데 업그레이드 팝업이 뜨는지. 경험치 출처는 보석뿐이지만, 한 번에 다음 레벨보다 많이 먹으면 남은 경험치가 쌓여 8초 대기(`nextGrowthAt`)가 끝나는 순간, 선택 직후, 보스 정산 직후에 저절로 팝업이 떴다. 자동 비행 12판(시드 6 × 스테이지 2, 판당 200초) 측정에서 팝업 109번 중 **54번**이 그 프레임에 보석 없이 떴다(마지막 보석 후 중앙값 1초, 최대 12.8초).

수정: `_checkLevel`은 보석이 고양이에게 닿은 프레임(직접 회수)과 자석 보석 흡수가 끝난 순간에만 부른다. 선택 직후·보조 교체 직후·보스 정산 직후 호출은 없앴다. 남은 경험치는 버리지 않고 다음 보석 때 반영되며, 최종 승리 결과에는 기존처럼 남은 경험치가 레벨로 계산된다. 8초 대기 규칙은 그대로다.

재측정: 같은 조건 팝업 106번 — 보석 직접 회수 85, 자석 보석 도착 21, **보석 없이 0**. 새 테스트 `the draft opens only when a gem reaches the cat` 통과. `engine_test` 2개·`battle_resolution_test` 1개 실패는 수정 전과 같은 옛 8초 규칙 테스트다.

## v12.4.2 조작·보석·적기 크기

사용자 피드백(손가락 위치에 고양이가 가려짐, 조이스틱이 미끄러져 회피가 어려움, 보석·작은 적기가 너무 작음)을 반영했다.

- **손가락 따라가기**: 고양이가 손가락보다 104(420 기준, 기존 56) 위에 선다. 실제 전투 화면에서 누른 채 60프레임 뒤 손가락과 고양이의 세로 차이가 104×화면배율인지 위젯 테스트로 확인했다.
- **드래그 이동**(가상 조이스틱 대체): 누른 순간의 고양이 위치에서 손가락이 민 거리 × 드래그 속도(느리게 0.9·기본 1.15·빠르게 1.4)만큼만 이동한다. 손을 멈추면 그 자리에 멈추고 넘어가지 않는다. 가장자리에 막히면 기준점을 다시 잡아 반대 방향이 바로 먹는다. 목표 지점까지 최고 속도는 이동속도×2.6(기존 2.1). 조이스틱의 '반응 거리' 설정은 '드래그 속도'로 바꾸고 '손떨림 무시'는 설정 화면에서 뺐다(옛 자유 비행 경기장 조이스틱용 값은 그대로 저장). 옛 자유 비행 경기장은 기존 조이스틱을 쓴다.
- **보석**: 집 스테이지에서 1.9배 크게 그린다(약 14→27px). 회수 반경 1.25→1.5배, 흡수 거리 18→26.
- **작은 적기**: 판정 반경을 ×1.55로 키워 봤더니 피하지 않는 자동 비행이 다시 45초 안에 죽어서, 판정은 ×1.3 그대로 두고 그림만 반경×3.6(기존 2.7, 중형 3.0)으로 키웠다. 화면상 크기는 약 39→51px(420 기준)이다.
- 테스트: `house_controls_ui_test.dart`(실제 전투 화면 누르기·끌기 2개), `house_v12_test.dart`에 정지·무관성 이동과 크기 기준 2개 추가. 관련 54개 통과, UI 계약 통과. 사람의 손맛 평가는 하지 않았다.
