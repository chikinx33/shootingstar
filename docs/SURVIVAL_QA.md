## 반복 수정 기록
1. 초기 실제 화면에서 멀리 뒤처진 적이 상한을 차지해 주변이 한산해짐 → 650 거리 이상의 일반 적을 화면 밖에 재배치하고 추격 속도 조정. 회귀 테스트 추가.
2. 초반 메뉴에서 출격 버튼이 접힌 화면 아래에 위치 → 챕터 목록 위로 이동.
3. 브라우저 시계 정지 시 과거 시점 오류 → 페이지 시계 기준으로 정지 시점 계산.
4. 일시정지 검증에서 툴팁 소멸로 전체 접근성 트리 비교가 실패 → 실제 전투 타이머를 비교하도록 검증 수정.
5. 가속 시계 상태에서 성장 화면의 뷰포트를 변경한 뒤 Flutter 접근성 클릭 좌표가 화면 밖으로 보고됨 → 모바일 E2E는 동일 뷰포트로 유지. 데스크톱은 별도 기존 캡처와 Flutter UI 크기 변경 테스트로 구분. 최종 390×844 흐름 통과.
