## 구현과 스크롤 규칙

- `lib/ui/catalog_screens.dart`: `SupplyShop`, `SeasonMailbox`, 공통 고정 헤더/분류와 상품·보상 항목. 교환·단계·임무·순찰·우편의 기존 모델 동작을 유지한다.
- `lib/ui/collection_screen.dart`: 조사 개요는 고정 페이지, 세트와 유물은 항목 목록이다. 복원·강화·세트 선택·제작·분해·초기화의 비용/한도/반환 규칙을 유지한다. 확인은 `GameDialog`와 공통 행동 버튼을 사용한다.
- `lib/ui/fixed_lobby.dart`: 항로·기체·4개 바로가기·출격·훈련·가이드가 한 화면에 들어간다. 중앙 그림 영역만 유연하게 줄어든다. 짧은 노치 안전 영역은 바로가기 4개를 한 줄로 배치한다. 전체 의미의 접근성 라벨을 유지한다.
- `lib/ui/game_pages.dart`: 긴 비목록 콘텐츠를 **클릭식 고정 페이지**로 나눈다. 스와이프·스크롤·글자 축소를 사용하지 않는다. 실제 자식 높이로 페이지를 계산하며 비활성 페이지는 도색·입력·접근성에서 제외한다. 닫기와 이전/다음은 고정하고 부모의 사용 가능 높이를 채운다. 단독 펫·장비 성장·계정 폼은 패널 배경을 유지한다. 초과 높이 항목은 개발 검사에서 실패한다.
- `GameDialog`, 장비 상세·펫 교감·정밀 성장·설정·가이드·계정 폼·편성 상세·일시정지·결과의 비목록 본문은 고정 페이지를 사용한다. 획득 보상도 행 단위로 페이지를 나눈다.
- 펫 선물·각성과 정밀 성장 알림은 페이지 버튼 위 80px 여백의 떠 있는 알림으로 표시한다. 화면 아래에 고정된 페이지 버튼을 알림이 덮지 않아야 한다. `content_ui_contract_test.dart`는 알림이 표시된 상태에서 실제 좌표 터치로 페이지가 바뀌는지 검사한다.
- 실제 반복 목록만 세로 이동한다: 상품, 단계/임무/우편 보상, 유물/장비/펫/테크, 연구 노드, 챕터, 편성 슬롯, 길드 항목, 난도/교환, 전투 선택과 피해/빌드 항목. 허용 파일과 생성 위치 수는 `check_ui_contract.py`로 감사한다.
- `RewardSnapshot`은 수집품 조각을 포함한 실제 지급 증가분을 읽는다. 수령 버튼이 모델 동작을 한 번 수행하고 확인·닫기·페이지 이동은 지급을 다시 실행하지 않는다.

이 규칙은 `AGENTS.md`, `GAME_DIRECTION.md`, `UI_DESIGN_SYSTEM.md`에 반영했다. 이전 문서의 로비/모달 스크롤 설명은 폐기했다.
