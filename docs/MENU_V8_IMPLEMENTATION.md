## 새 생성 그래픽

`assets/art/menu_v8/`에 배경 3장과 투명 오브젝트 14장을 저장했다. 배경은 격납고/화물 창고/정비실이다. 오브젝트는 오로라·벡터·모노리스 3기, 장비/테크/펫 보급 3종, 성장/도전 배지, 장비 슬롯 6종이다. 개별 PNG만 사용하며 그리드 아틀라스로 생성하지 않았다. 장비는 슬롯별 공통 실루엣이며 두 세부 사양의 기존 이름/ID/능력치는 유지한다.

생성 도구는 내장 `image_gen`, 총 17회이며 별도 API 키를 사용하지 않았다. 생성 원본 경로와 오브젝트 프롬프트는 `generation.json`, 배경 전체 프롬프트는 `background-prompts.json`, 추가 기체 프롬프트는 `extra-ships.json`에 기록했다. 생성 원본을 지우거나 PNG 바이트를 편집하지 않고 프로젝트에 복사했다.

`manifest.json`은 SHA-256·원본 크기·알파 범위·안전 샘플 영역을 기록한다. 눈에 보이는 실루엣(alpha>=8)은 원본 가장자리에서 최소 24px 떨어져 있다. 그 실루엣 밖 12px를 더 포함해 샘플링한다. 생성물의 미세한 1~7/255 잔여 알파는 원본을 보존하고 렌더 단계에서 제거한다. 오브젝트는 항상 원본 비율을 유지하며, 배경만 비율을 유지한 cover를 사용한다. 자르기 영역 안에 다른 격자의 오브젝트가 존재하지 않는다.

## 패널·버튼·배치

- 버튼/패널의 PNG 늘이기와 9조각 렌더러를 제거했다. 단일 연속 경로에 면·상단 밝은 면·하단 두께·외곽선을 도색한다. 여러 비율에서 중앙 면에 가로/세로 접합선이 없는지 픽셀로 검사한다. SVG 자산이나 그림 대체용 벡터 스프라이트를 추가하지 않았다.
- 로비는 새 격납고 배경과 독립 기체를 사용한다. 하단 5개 분류는 새 그림과 금색 선택 상태로 구분한다. 계정 제목·레벨·설정 아이콘도 확대했다. 짧은 화면의 바로가기 4개는 한 줄로 배치한다. 재화는 필요한 경우 K/M로 축약하되 저장값과 접근성의 전체 수치는 유지한다.
- 보급은 새 상자/캡슐/구조 로봇과 읽기 쉬운 제목·보급권 수량을 나란히 둔다. 조건·보급 진행·행동을 그 아래에 둔다. 상품과 교환 품목 목록만 스크롤하며 제목·분류·하단 내비게이션은 고정한다. 실제 보급/교환/보상 수량은 기존 함수를 사용한다.
- 장비·펫 보급의 획득 팝업도 새 개별 PNG를 사용한다. 장비 보상 데이터의 원래 사양 ID를 슬롯 그림에 연결하며, 기존 아틀라스 칸의 인접 조각이 보상 카드에 남지 않게 한다. 실제 수령·중복 방지 로직은 바꾸지 않는다.
- 성장은 장비/펫/테크 분류를 고정한다. 장비의 장착/보관/관리 분류도 고정한다. 큰 화면은 중앙 기체 양옆 6슬롯, 짧은 화면은 기체가 먼저 보이고 두 슬롯씩 고정 페이지로 이동한다. 장착 현황과 관리 행동은 스크롤하지 않는다. 보관함만 실제 장비 항목의 목록이다. 수집품·연구·고급 성장·보급·시즌·길드의 기존 경로는 관리에 유지한다.

주요 72/22/36, 보조 64/20/32, 최대 행동 폭 264, 종횡비 4.25 이하를 유지한다. 큰 글자를 축소하거나 얇은 배너로 맞추지 않는다.
