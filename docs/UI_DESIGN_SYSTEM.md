### 전체 게임 V10의 미술 기준

사용자 확정: **라인이 굵은 아기자기하고 캐주얼한 메카닉 디자인**. 로비·실제 전투·장비·펫·보급·스킬·보상·도감에 같은 그림 주소를 사용한다. 큰 캐노피/짧은 날개/둥근 엔진의 SD 기체, 통통한 적/보스/펫, 굵은 검정선과 큰 색면으로 통일한다. 촘촘한 부품 묘사, 사실적인 금속, 원근이 강한 격납고로 다시 돌아가지 않는다. 로비/성장은 주황 패턴, 보급/상세는 보라 패턴, 전투는 밝은 단색 지면과 독립 소품으로 구분한다. 패널은 철청색·주요 행동은 노란 면과 굵은 어두운 외곽을 쓴다. PNG는 각각 독립된 오브젝트로 생성하고 원본 비율을 유지한다. 버튼/패널/빔은 연속 경로로 도색하며 이미지를 늘이거나 조각 접합하지 않는다. 생성 프롬프트·연결 범위·웹 증거는 `GAME_V10_IMPLEMENTATION.md`를 따른다.

HUD/웨이브 안내와 실제 전장 영역을 레이아웃으로 분리한다. 전장의 카메라와 터치 좌표는 남은 실제 전장 크기를 기준으로 한다. 상단 UI가 커졌다는 이유로 적/보스를 패널 아래에 숨기거나 안내 배너를 고정 좌표로 겹쳐 놓지 않는다.

## 배치·표현

- 화면 좌우 여백 최소 12, 결정 화면 16. 버튼 사이 12, 설명과 행동 사이 24를 기본으로 한다.
- 일시정지/결과의 콘텐츠 폭은 최대 344, 행동 폭은 최대 264다. 가운데 정렬하고 좁아지면 함께 줄어든다.
- 버튼·패널은 단일 연속 경로로 도색한다. PNG 버튼 전체 늘이기, 9조각 접합, 아틀라스 패널 샘플링을 사용하지 않는다. 테두리·상단 밝은 면·하단 두께가 실제 높이에 나타나야 한다. 투명한 터치 여백은 버튼 높이 증거가 아니다.
- 주요 행동은 노랑/주황 면과 굵은 어두운 글자, 보조 행동은 회청색 면과 굵은 흰 글자를 쓴다. 흰 글자는 어두운 외곽/그림자로 배경과 분리한다.
- 아이콘과 문구 사이 최소 12. 아이콘을 장식용 작은 점처럼 넣지 않는다.
- `TextScaler`를 존중한다. 행동 문구에 `FittedBox`, `BoxFit.scaleDown`, 글자 축소, 말줄임을 쓰지 않는다. 줄바꿈과 높이 증가로 해결한다.
- **리스트 항목 이외에는 스크롤을 허용하지 않는다.** 로비 전체는 `FixedLobby` 한 화면으로 고정한다. 그림 영역만 유연하게 줄이고, 안전 영역이 짧으면 바로가기 4개를 한 줄에 배치한다. 출격·훈련·가이드·하단 내비게이션이 모두 화면 안에 있어야 한다.
- 긴 상세·설명·폼·확인·일시정지·결과는 `GamePages`의 이전/다음 버튼으로 나눈다. `PageView`/스와이프/스크롤/글자 축소/잘림으로 대체하지 않는다. 페이지당 실제 높이로 분할하고, 비활성 페이지는 그리지 않고 입력·접근성에서도 제외한다. 제목·닫기·페이지 이동은 항상 고정한다.
- `ListView`는 상품·보상·우편·유물·장비·연구·임무·챕터·전투 선택/통계 등 반복 항목의 뷰포트에만 허용한다. `check_ui_contract.py`의 항목 목록 허용표를 유지한다. 새 화면을 일반 스크롤로 감싸지 않는다. `ship_hangar.dart`는 기존3종 기체의 그림·기본 성능·선택/해금 행동을 반복하는 목록1개만 허용하며 상단 제목/장착 상태는 고정한다.
