# v10.0.24 세계 전투와 중단 출격 복원

설계 목표는 세계를 회피 경로로 구별하고, 종료 때문에 한 판의 빌드와 보스 진행을 잃지 않게 하는 것이다. 기존 Flutter·자동 사격·입력 해제5%·성장/보상·항로 편대·보스 규칙을 유지한다. 공유 `roguelike-game-designer`의 교전·접근성/중단 저장·부하 공정성 기준을 적용했다. 신규 유료 생성이나 Android 빌드는 사용하지 않는다.

## 세계별 교전

기존 세계별 적 역할 풀, 항로별 편대와 보스 패턴에 아래 전장 규칙을 결합한다. 적 체력/성장 비용을 일괄 올리는 방식은 쓰지 않는다.

| 세계 | 위험과 실제 회피 판단 |
|---|---|
| 잔광 외곽 | 기체 위치에 고정한 반경58 표식에서 벗어나기 |
| 적색 성운 | 좌우92 간격의 세로 쌍열, 폭54. 가운데 통로 유지 또는 바깥으로 이동 |
| 공허 왕관 | 반경145, 두께36 고리. 안쪽/바깥쪽 중 위치를 선택 |
| 빙결 고리 | 간격100, 폭36 가로 봉쇄3줄. 줄 사이로 이동 |
| 균사 정원 | 중심에서76 떨어진 반경46 포자3개. 원 사이의 틈 이용 |
| 철묘 | 폭44 세로/가로 십자. 대각선으로 이탈 |
| 태양 | 폭40 광선3개의 방사. 광선 사이 방향 선택 |
| 심해 | 반경180→90으로 2초간 수축하는 고리. 바깥 유지 또는 중앙 확보 |
| 수정 | 폭44 X자 사선. 가로/세로 방향으로 이탈 |
| 특이점 | 좌우72 교대 이동한 반경135 안전 원. 원 안으로 진입/유지 |

18초 주기의10초 시점에 기체 위치를 고정하고3초 예고,13~15초에만 위험이 활성화된다. 중단/선택/일시정지 중 시계는 멈추고 입력 해제5%도 기존대로 적용된다. 고정된 중심은 기체를 추적하지 않는다. 카메라가 움직여도 동일한 월드 좌표다. 심해의 이동 방향/안쪽 한계도 예고에 표시한다.

색뿐 아니라 `예고/위험` 문구와 구체적인 대응 문구를 전장 상단과 하단 접근성 라벨로 알린다. 그리는 모양과 HP 피해 판정은 같은 `WorldField` 데이터를 사용한다. 장식 축소 설정에서도 필수 예고는 유지한다. 보스/보스 접근/격파 연출 중 환경 위험은 비활성이다. 훈련과 일일 도전의 기존 규칙은 유지한다. 새 적/탄환 액터를 추가하지 않는다. 기존 편대 시간표도 유지한다.

피해는 기존 환경 피해7×위협 제곱근 상한3, 기존 피격 무적/방호를 따른다. 첫 세계만 기본4로 낮춰 표식 회피를 소개한다. 순간이동·상태이상·이동 강제·새 재화는 추가하지 않는다. 10세계에서 위험 밖의 도달 가능한 지점이 여럿 존재하는지 검사한다. 실제 이용자가 세계를 구별하고 회피하는지에 대한 사용자 관찰은 별도 과제다.

## 이어하기와 보상 계약

- 일반/반복/시즌 도전 출격과 유효한 날짜의 일일 도전을 같은 기기에서 복원한다. 훈련, 개발자, 효과 재현은 일반 체크포인트를 기록하지 않는다.
- 활동 중 약2초마다, 일시정지/앱 배경 전환/성장 선택 전후에 저장한다. 선택/정지 중에는 같은 상태를 계속 기록하지 않는다. 강제 종료는 마지막으로 **성공한** 체크포인트까지 복구되며, 저장 직전까지의 완전 보존을 약속하지 않는다.
- `저장 후 로비`는 정산 없이 나간다. 로비 출격 버튼이 `이어하기`로 바뀌고, 실제 항로·레벨·시간을 확인한 뒤 이어간다. 새 출격을 원하면 별도의 포기 확인을 거친다. 포기는 미정산 전투만 제거한다.
- 복구는 항상 일시정지, 입력0이다. `계속 비행` 이후에만 진행하며, 닫혀 있던 시간은 계산하지 않는다. 무장·장비·펫·연구는 출격 당시 구성을 쓴다.
- HP/XP/RPN/무기·보조/특화·진화/선택·새로고침/타이머/전장 예고/적 행동·편대/탄환과 동일 적 참조/추적·관통 명중 이력/파일럿·펫/궁극기·시너지/자석의 미지급 XP/보스 단계·격파 시계를 저장한다. 일시적 입자·음향·도색 큐는 재생성하지 않는다.
- 난수는 상태를 저장하는32비트 구현을 사용한다. 인접 시드의 첫 배치가 치우치지 않도록 초기값을 혼합한다. 기존의 새 출격 난수 순서는 바뀌지만, 저장 후 이어가기에서 다시 추첨하거나 선택지를 바꾸지 않는다.
- 같은 `runId`를 유지한다. 로컬 프로필의 **한 저장 값**에 영구 진행과 체크포인트를 담아, 종료 보상·처리한ID 기록·체크포인트 제거를 원자적으로 저장한다. 저장이 실패하면 이전 기록으로 남으며 성공한 영구 지급을 두 번 수행하지 않는다. 기존 처리ID100개 보호도 유지한다.
- 저장 형식/숫자·enum·스킬ID/액터 수/전투 페이로드2MiB/손상 검사값/계정/항로·순환/일일 날짜/정산ID를 검사한다. 잘못되거나 만료된 전투는 복원하지 않고 안내하며, 영구 진행은 보존한다. 손상 검사값은 보안 서명이 아니다.
- 클라우드 내보내기/서버 업로드에서 `_battle`을 제외한다. 같은 계정의 미완료 출격이 있으면 배경 동기화로 덮어쓰지 않으며, 다른 계정·명시적인 클라우드 진행 선택·진행 교체는 체크포인트를 폐기한다. 다른 기기로 전투를 이전하는 기능은 아니다.

## 검증 기록

검증 수치·웹 실행·배포 결과는 작업 완료 후 이 절에 기록한다. 초기 실패 로그는 `.local/improve-v24/`에 보존한다. 전체 회귀에서 확인한 기존 실패와 이번 변경의 실패를 구분하기 위해 패치 직전8개 소스 파일을 별도 작업 폴더에 복원해 비교한다. 실제 과금/광고·실기기 장시간 측정·이용자 플레이 관찰은 이 패치의 완료 증거가 아니다.
