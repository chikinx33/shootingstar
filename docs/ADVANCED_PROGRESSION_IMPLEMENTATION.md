## 고급 장비 성장

장착·잠금·기본 강화·정밀 성장·저장 편성의 장비는 융합 재료가 될 수 없다. 기존 기본 합성에서도 저장 편성과 정밀 성장 장비를 재료에서 제외한다. 확인창은 선택한 두 ID와 비용을 보여주며, 취소하면 소모하지 않는다. 적용 직전에 재료 상태를 다시 검사해 일부만 소모되는 경우를 막는다.

정밀 성장 초기화는 추가 성장에 실제 사용한 크레딧·설계도와 융합 재료의 원래 ID·속성을 돌려준다. 대상의 기본 등급·강화·장착은 유지한다. 공간 부족·ID 충돌·환급 재화 상한 초과 시 초기화를 거부한다. 반환은 한 번만 가능하다. 보관 중인 재료 ID보다 큰 값에서 새 장비 ID를 생성해 재접속 후 충돌을 막는다.

## 펫 호감도·각성

경로: **성장 → 펫 → 각성·호감도**.

- 호감도는 펫별 최대 300이다. 120초 이상·10기 이상 처치한 정상 출전은 실제 출격 당시 펫에게 최대 10을 준다. 하루 전투 교감 총 30을 세 펫이 공유한다. 훈련·접근 불가 항로·중복 정산은 제외한다.
- 먹이 10 선물로 호감도 최대 10을 얻으며, 선물은 모든 펫 합쳐 하루 2회다. 한국 자정 갱신과 단조 증가 시각을 사용한다. 호감도 자체는 능력치를 올리지 않는다.
- 각성 1/2/3단계는 각각 펫 Lv.5/10/15, 기존 승급 1/2/3단계, 호감도 50/120/200을 요구한다. 비용은 100/200/300 C + 먹이 20/40/60 + 유전자 1/2/3이다. 기존 먹이 육성·승급·구조·출전·보조 배치를 보존한다.
- 출전 펫에만 두 스킬 중 하나를 적용한다. 전문 행동은 루미의 펫 탄 피해를 각성당 6%(최대 18%), 미오의 회복량과 볼트의 탄환 제거 반경을 각성당 5%(최대 15%) 늘린다. 신속 동행은 펫 행동 간격을 각성당 4%(최대 12%) 줄인다. 선택 변경은 무료이며, 플레이어의 모든 무기 피해에 새 펫 배율을 곱하지 않는다.
- 초기화는 실제 각성에 사용한 재료만 한 번 반환한다. 호감도·선물 횟수·전투 교감 상한·기존 육성·승급은 유지한다. 환급 상한이 부족하면 거부한다. 초기화와 무료 스킬 변경으로 새 성장 임무를 반복 지급하지 않는다.

각성 자격·선택 스킬·자원 비용은 게임에 표시한다. 비용과 효과는 자체 시작 규칙이며 장기 플레이 튜닝이 끝났다는 의미는 아니다.

## 저장 보존

프로필 버전 4와 이전 `progressionVersion: 1`을 유지하고 `content.advancedProgressionVersion: 1` 및 `dailyChallenge`, `advancedEquipment`, `petBond`를 추가했다. 기존 파일을 처음 읽을 때 원문을 `shootingstar.profile.v1.beforeAdvancedProgression`에 한 번 보관하고 새 필드를 저장한다. 기존 백업을 덮어쓰지 않는다.

옛 저장의 새 필드는 빈 값으로 시작하므로 이전 장비·재화·수집품·펫 기본 성장·편성이 유지된다. 장비 정밀 기록은 실제 존재하는 대상 ID에만 복원하고 융합 재료의 중복·충돌·속성을 검증한다. 계정 진행을 교체하면 새 계정의 추가 필드를 복원하고 누락된 필드는 초기화한다. 새 진행이 이전 계정에 남지 않도록 기존 정규화 경로를 사용한다.

서버 `cloud/write`에도 새 마커가 있는 저장을 구형 클라이언트가 누락하여 쓰는 경우 409로 거부하는 검사를 추가했다. 별도 로컬 D1에서 구형 쓰기·CAS 충돌·후속 정상 쓰기와 데이터 보존을 검증했다. 운영 서버에는 아직 배포되지 않았다. 로컬 시각·클라이언트 원장은 저장 편집을 막는 서버 권한 검증이 아니며, 실제 결제·광고 지급 검증을 대체하지 않는다.
