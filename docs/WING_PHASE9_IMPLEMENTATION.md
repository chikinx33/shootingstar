# 세계 보스·항로 보상 확장 — v10.0.11

2026-10-18. 공유 roguelike-game-designer의 실패/영구 성장 경제, game-balance의 기존 비용/수입 비교를 적용했다. 기존 기본 크레딧·회수 상자·장비/테크·시즌·파일럿/펫 성장·항로 마일스톤 보상은 유지하고 아래 확정 재화를 더한다. 새 재화·확률 추첨·과금·능력 배율은 추가하지 않았다. 자체 초도 수치이며 최종 플레이 경제/성장 속도 평가는 별도다.

세계/항로 인덱스는0~9다. 일반 항로 완주마다 **20 + 세계×3 + 항로×2 C**. 전초(5번째)는 설계도1, 수문장(10번째)은 설계도2도 준다. 항로 첫 보너스는 **40 + 세계×5 + 항로×2 C + 설계도2**다. 기존 경험치/골드 보조 배율은 기존 기본 크레딧에만 적용하며 새 보상에는 중복 적용하지 않는다. 순환에 따른 새 보상 배율은 없다.

첫100항로 보너스는 합계7150C·설계도200으로 한정된다. 세계 첫 보스 희귀 권은 전체10세계 합계 장비3·테크3·수집품2·펫 구조1이다. 반복 보스 회수에는 권을 넣지 않아 빠른 보스 재도전으로 권을 무한 생산하지 않는다. 기존 상자의 권 지급까지 제거하거나 대체했다는 뜻은 아니다.

- 기존 유효 출격 조건 **30초 이상·10기 이상 격파**를 요구한다. 실제 처치한 보스 수는 해당 항로의1/2/3기 상한으로 제한한다.
- 보스 처치 후 패배해도 보스 회수와 미수령 세계 첫 보너스는 정산한다. 보스가 없으면 지급하지 않는다.
- 새 항로 완주/첫 보너스는 **일반 항로 승리 + 전체 항로 시간 + 필수 보스 수**를 모두 요구한다. 기존 구형 승리/진행 처리를 재작성하지 않고 새 보상 검증에만 조건을 추가했다.
- 기존 별도 항로 도전은 보스 회수를 받을 수 있지만 새 일반 항로 완주/첫 보너스는 지급하지 않는다. 훈련은 무보상, 일일 도전은 기존 토큰 규칙을 유지한다.
- 정산은 기존 run ID 최근100개 중복 방지 경로 안에서 실행한다. 첫 세계/항로 보너스는 각각10/100개의 영구 수령 집합으로 따로 보호한다. 오래된 모든 출격 ID에 대한 영구 안티치트라는 의미는 아니다.

## 저장·이관·클라우드

`CampaignRewardBook`을 Profile에 추가하고 루트 `campaignRewardsVersion:1`, `campaignRewards:{bossWorlds:[],routes:[]}`를 기존 version4 저장에 더한다. 기존 주무기 소유/강화·편성·인벤토리·항로 순환·프로필 키는 유지한다. 기존 저장에 새 기록이 없으면 빈 기록으로 시작하고 로드만으로 보상을 지급하지 않는다. 과거에 완주한 항로도 업데이트 이후 유효하게 재도전하면 새 첫 보너스를1회 받을 수 있다. 기존 완료 기록을 지우거나 소급 보상을 자동 지급하지 않는다.

새 보상은 기존 자원 상한 안에서 실제 양수 증가량만 적용한다. 결과 내역도 실제 증가분을 표시한다. 기존 상자 처리로 이미 상한을 넘은 값이 있더라도 새 보상 처리에서 자원을 차감하지 않는다. 상한으로 더 받을 수 없는 첫 보너스도 수령 기록은 남는다. 다른 기본 보상 처리를 새 상한 규칙으로 전면 변경하지 않았다.

Worker는 새 마커가 있는 저장의 기록 배열 길이/범위/중복/정수 타입을 검사한다. 새 저장이 서버에 올라간 이후 구버전의 마커 누락/변경을409로 막고, 같은 버전에서도 이미 수령한 ID를 삭제하는 덮어쓰기를409로 막는다. 기존 revision CAS·주무기/콘텐츠 보호를 유지한다. 이는 실수로 기록을 잃는 것을 막는 보호이며 로컬 저장 편집을 완전히 차단하는 기능은 아니다. D1 스키마/운영 데이터 마이그레이션·초기화는 하지 않았다.
