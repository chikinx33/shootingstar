# 개발자 테스트 공간 — v10.0.14

## v10.0.22 전투 연출4종 추가

상단✨ → 연출 재현에서 피격·스킬 진화·궁극기·방패 역습을 바로 실행한다. 기존4종과 같은3열 그림 슬롯/뒤로/다시 재현을 사용한다. 화면 전환 후 재생하며 이 네 재현은 손을 떼어도 정상 속도다. 일반/개발자 진행·설정은 그대로 보존한다. 세부 동작과 변경 부분 검증은 `V22_COMBAT_REPLAYS.md`.

## v10.0.21 즉시 연출 재현

상단✨ 또는 전투/연출 재현에서 자석 흡수·보스 클리어·보상 수령·구매 연출3열 슬롯을 누르면 바로 실행한다. 뒤로가기/다시 재현을 제공한다. 기존 일반·개발자 저장과 설정을 보존하며, 별도 비저장 복사본에서 실제 전투/획득·구매 경로를 호출한다. `V21_SLOW_MOTION_AND_REPLAYS.md`를 따른다.

## v10.0.14 사용자 후속 변경

개발자 진행은 `shootingstar.developer.v1`에 일반 진행 `shootingstar.profile.v1`과 분리해 저장한다. 테스트 메뉴/빌드/레벨/RPN/교전/성능 설정·선택 장비/기체/항로와 보급 탭을 복원하며, 테스트 화면을 보다가 새로고침하면 같은 메뉴로 돌아온다. 뒤로가기·탭 닫기·재시작으로 해제하지 않고 자물쇠에서 명시적으로 종료할 때만 별도 개발자 저장을 제거한다. 종료 전에 대기 중 쓰기를 마무리하고 이후 쓰기를 막아 개발자 저장이 다시 생기지 않도록 한다. 일반 저장은 병합/초기화하지 않는다. 개발자 프로필에는 CloudSync를 연결하지 않는다.

반복 상품/장비/무기/기체/펫/테크/유물/세트/보스 장비/연구/편성/도감/시즌·우편을 공통 `GameSlotList`/`GameSlotRows` 최소3열로 정리했다. 130%에서도3열을 유지하고 이름을 줄이거나 잘라내지 않는다. 이름·그림·수량/등급만 개요에 남기며, 기존 상세/구매/강화/장착은 슬롯을 눌러 연다. 일반/테스트가 같은 컴포넌트를 사용한다. 아래 v10.0.13 기록 중 메모리 전용·새로고침 종료 규칙은 이 변경으로 대체한다.

## 진입과 종료

옵션은 장식과 중복 완료 페이지를 제거한 고정 단일 보드다. 제목 옆 컴파일 버전을 3초간 누르고 `0623`을 입력하면 임시 개발자 홈으로 이동한다. 옵션 제목 뒤 열린 자물쇠와 테스트 화면의 자물쇠는 일반 모드로 돌아간다. 새로고침도 일반 저장으로 시작한다.

일반 진행을 JSON으로 깊게 복사한 `Profile.developerCopy`를 사용한다. SharedPreferences와 CloudSync가 연결되지 않고 `save()`는 쓰지 않는다. 테스트 구매·성장·전투 결과는 일반 진행에 합치지 않는다. 계정/클라우드 저장은 일반 모드에서 사용한다. 이 PIN은 테스트 진입 장치이며 서버 계정 권한을 바꾸지 않는다.

## 테스트 메뉴

상단 메뉴는 전투5개·성장9개·콘텐츠5개다. 큰 화면에는 분류 탭도 제공하고 작은 화면에서는 전체 메뉴 선택기에 분류를 함께 표시해 본문 공간을 확보한다. 반복 장비/상품/스킬 목록만 스크롤하며 설정 폼은 GamePages 고정 페이지를 쓴다. 출격 버튼은 전투 설정 하단에 고정한다. 성장/콘텐츠를 확인한 뒤 상단에서 전투 메뉴로 돌아와 출격한다.

- 전투: 10종 주무기·20특화, 3기체·전체 파일럿·장비 선택, 10세계×10항로, 전투 Lv.1~100, R/P/N, 주무기 영구 강화·파일럿·연구 레벨, 시작 체력, 궁극기 충전, 7종 보급 아이템.
- 빌드: 스킬 단계·진화 지정, 정면 돌파/폭발 확산/방패 역습과 융합3종 프리셋. 공격6+보조6 슬롯과 기존 전투 계산을 유지한다. 특화/시너지는 선택한 무장과 조합이 실제로 맞아야 한다.
- 교전: 세계별 보스3단계, 방패·중장/돌입/일렬/펼침 즉시 교전, 항로 시작 시각·캠페인 순환.
- 성능: 초기 적0~260·적탄0~1000·효과0~160, 고정 시드, 0.5/1/2/4배 진행, 무적, 레벨업 자동 선택, 실제 프레임 간격으로 측정한 FPS·현재 적/탄/효과 수. 부하는 처치/수명에 따라 감소하며 기기 간 성능 보증 수치는 아니다.
- 성장/콘텐츠: 기존 주무기·장비·펫·테크·연구·수집품·편성·보스 장비·보급·도전·활동 보상·시즌/우편·진화 도감을 아래 본문에 연결한다. 아이템 직접 지급에서 장비 종류/등급/레벨을 지정해 장착하고, 펫/테크 단계와 보상 조건을 즉시 설정한다.

개발자 프로필은 전체 기체/무기/항로/수집품, 모든 장비 종류의 희귀 샘플과 펫/테크 사용을 해금한다. 크레딧/설계도는 구매 시 감소하지 않으며 소모성 테스트 재료를 보충하고 일일 교환 제한을 초기화한다. 슬롯 수·장비 등급 상한 같은 전투 규칙은 유지하고 단계는 테스트 메뉴에서 지정한다. 원래 프로필의 전투·성장·진화·보상·저장 규칙은 유지한다.
