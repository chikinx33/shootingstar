# 개발자 테스트 공간

## 진입과 종료

옵션 제목 옆 컴파일 버전을 3초간 누르고 `0623`을 입력하면 개발자 홈으로 이동한다. 옵션 제목 뒤 열린 자물쇠와 테스트 화면의 자물쇠로 일반 모드에 돌아간다. 이 PIN은 테스트 진입 장치이며 서버 계정 권한을 바꾸지 않는다. 기체 조립 편집기는 테스트 화면 상단 오른쪽의 조절 아이콘으로 연다(`SHIP_PART_EDITOR.md`).

## 저장 분리

- 개발자 진행은 `shootingstar.developer.v1`에 일반 진행 `shootingstar.profile.v1`과 분리해 저장한다. 테스트 메뉴·설정·선택 상태를 복원하며, 테스트 화면을 보다가 새로고침하면 같은 메뉴로 돌아온다.
- 뒤로가기·탭 닫기·재시작으로 해제하지 않고 자물쇠에서 명시적으로 종료할 때만 개발자 저장을 제거한다. 종료 전에 대기 중 쓰기를 마무리하고 이후 쓰기를 막는다.
- 일반 진행을 JSON으로 깊게 복사한 `Profile.developerCopy`를 쓴다. 일반 저장은 병합/초기화하지 않고, 개발자 프로필에는 CloudSync를 연결하지 않는다. 테스트 구매·성장·전투 결과는 일반 진행에 합치지 않는다.

## 테스트 메뉴

- 개발자 프로필은 기체·장비·병아리 등을 해금하고, 재화는 구매 시 줄지 않으며 소모성 테스트 재료를 보충한다. 슬롯 수·장비 등급 상한 같은 전투 규칙은 유지한다.
- 전투 설정(기체·무기·장비·세계/항로·교전·레벨·성능 부하·무적 등)은 그림 슬롯으로 고르고, 출격 버튼은 전투 설정 하단에 고정한다. 반복 항목 목록만 스크롤한다.
- 연출 즉시 재현(자석 흡수·보스 클리어·보상 수령·구매·피격·스킬 진화·궁극기 등)은 비저장 복사본에서 실제 전투/획득·구매 경로를 호출하며 일반·개발자 저장과 설정을 보존한다.
- 성능 표시는 실제 프레임 간격으로 잰 FPS와 현재 적/탄/효과 수다. 기기 간 성능 보증 수치가 아니다.
