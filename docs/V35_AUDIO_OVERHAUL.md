# v10.0.35 음향 전면 개편

사용자 요청에 따라 어두운 배경음과 기존 효과음을 교체하고 로비/전투 음악을 구분한다. 실제 결제/광고 ID 미정·APK 금지는 유지한다.

## 제작

`tools/compose_audio.py`는 외부 음원·샘플·유료 API 없이 numpy로 자체 작곡/합성한다. 고정 seed로 재생성하며 기존 두 생성 스크립트도 이 구현에 위임한다.

| 곡 | 구성 |
| --- | --- |
| `lobby-groove.wav` | C 장조120 BPM,16마디/32초. 킥·스네어·하이햇·엇박 코드 플럭/베이스·A/B 멜로디·스테레오 에코 |
| `battle-drive.wav` | D 장조136 BPM,16마디/약28.235초. 빠른 리듬/드럼 필·촘촘한 리드 멜로디·후반 벨 응답 |

음표/에코 꼬리를 다음 루프로 순환 믹싱한다. 기존 `orbit-loop.wav`는 백업 후 배포 자산에서 제거했다. WAV24kHz/16비트, 음악 스테레오·효과음 모노다. 음악 peak .72/RMS 약 .154·.142, 효과음 peak .64이며 실제 재생 gain은 별도로 적용한다. 생성54개 = BGM2곡 + 효과음52개(단독 미리보기 호환 `shoot.wav` 포함). 실제 주무기는10개의 `weapon-*.wav`다.

## 재생·성능

`GameAudioHost`가 일반/개발자 프로필의 현재 설정을 듣고 전체 앱의 `AudioDirector` 하나를 공유한다. 음악1 + 효과음6플레이어까지 지연 생성하며 반복음4채널과 중요한 피드백2채널을 분리한다. 반복음은 벽시계 간격을 제한하고 중요한 채널도 로딩 중 최신 요청1개만 보관한다. 음소거/설정/장면 전환은 세대 번호로 로딩 중 효과음도 취소한다. 오래된 요청은 자기 채널만 정지시킨다.

위치 스트림은 사용하지 않으므로 `AudioPlayer.positionUpdater=null`로 기본 프레임별 위치 조회를 중단한다. 음향은 전투 RNG·피해·보상·저장에 관여하지 않는다. 시각 효과 비활성/풀 소진과 별도로 음향 발생을 관찰한다. 첫 실제 탭/키 입력 후 음악을 시작하며 자동 재생 제한을 우회하지 않는다. 배경 전환은 음악/효과음을 정지하고 전투의 기존 일시정지를 유지한다. 장치 오류는 조작/진행을 막지 않으며 음악 재시도는 이후 입력에서만 한다.
