# v10.0.17 상세 창·전투 연출·항로 배경

2026-10-19. 사용자가 지적한 장비 상세의 큰 그림, 세로 행동 나열, 무의미한 두 번째 페이지를 직접 수정했다. 일반 진행·개발자 진행의 저장 형식, 성장 비용, 보상, 전투 판정은 변경하지 않았다.

## 상세 화면

- `GamePages`는 여러 페이지일 때도 현재 페이지의 실제 내용 높이로 창을 계산한다. 페이지 용량은 부모의 최대 높이로 계산하므로 작은 마지막 페이지로 이동해도 페이지 수가 흔들리지 않는다. 모달 스크롤은 추가하지 않았다.
- 장비는 72px 정보 헤더, 등급/레벨/잠금, 효과·비용, 나란한 장착/강화, 합성/반환 관리 셀 순서다. 장착 중·최대 강화 상태는 설명으로 표시한다. 반환은 강화 투자 시에만 제공하고 별도 확인 후 실행한다. 합성도 별도 재료 확인 후 기존 모델로 확정한다. 헤더 X만 닫기로 남겼다.
- 주무기·기체·펫·테크·진화 도감은 작은 정보 헤더를 사용한다. 주무기의 중복 강화 설명, 이미 선택한 장착 버튼, 최대 단계의 강화·승급 버튼을 정리했다. 펫/테크의 실행 불가능한 상태 전용 조작도 조건부로 숨긴다.
- 유물 상세 역시 그림과 상태를 헤더에 묶고 제작/분해를 같은 행으로 구성했다. 조각이 없으면 분해, 강화 투자가 없으면 초기화를 표시하지 않는다. 중복 닫기도 제거했다.
- 주요 결정은 기존 `GameActionButton` 크기를 유지하며 좁은 관리 셀만 `GameUi.compactButton`을 쓴다. 소스 계약 검사는 장비 상세에서 이 스타일의 셀만 허용한다. 글자 축소·리스트 밖 스크롤은 추가하지 않았다.

## 실제 전투에 연결한 표현

`CombatCues`는 저장하지 않는 일시적인 표현 이벤트다. 전투 RNG를 읽지 않으며 최대 80개, 명중 숫자 최대 14개를 그린다. 실제 타격·명중·발사·보급·진화·시너지·보스 이벤트에서 생성한다. `CombatVfx`와 기존 `BattlePainter`가 공유 PNG 위에 시간에 따른 효과를 겹친다.

| 기능 | 화면 표현 |
|---|---|
| 기체·적 비행 | 맥동하는 추진 화염과 코어 |
| 주무기·보조 탄환 | 발사광, 탄도/미사일 잔상, 명중 섬광, 피해 숫자 |
| 번개 | 실제 타격 지점까지 흔들리는 연결 광선 |
| 장판·폭발·격추 | 무기 계열색의 확산 고리, 파편, 단계적으로 커지는 충격파 |
| 방패·수호자·역습 | 회전 방호 호, 흡수 고리, 육각 격자, 준비 상태 고리 |
| 경험치·보급 | 회수 잔상, 보급 신호, 획득 고리 |

효과 줄이기는 기존 설정을 사용한다. 추진·잔상·입자·흔들림은 줄이고 공격/방어 판독에 필요한 표시를 남긴다. 순간 연출 시간은 일시정지/성장 선택과 함께 멈춘다. 보조 수치 자체가 별도 공격을 만들지 않는 경우 기존 HUD 상태를 유지한다.

## 새 배경과 원본

내장 `image_gen.imagegen`으로 생성한 `assets/art/flight_v17/orbital_lane.png`를 사용한다. 생성 PNG는 수정 없이 복사했고 SHA-256을 원본과 비교했다. 프롬프트와 원본 위치는 같은 폴더 `generation.json`, 검사 결과는 `.local/v17-asset-audit.json`이다. 외부 API/CLI 생성은 사용하지 않았다.

앰버 전체 배경을 남색/청록 궤도 항로와 측면 정거장으로 교체했다. 로비·전투가 같은 미술 기반을 사용하며, 전투에는 세계별 색조·시간에 따른 배경 이동·별도 대기 흐름을 적용한다. 원본 비율을 유지하고 세로 반사 반복으로 경계를 연결한다. 탄환과 겹치는 장식·큰 정중앙 구조물은 배경에 넣지 않았다. 메뉴 본문은 기존 남색 차광을 유지하고 로비 기체 이름은 밝게 바꿨다.
