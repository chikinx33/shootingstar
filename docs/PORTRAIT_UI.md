# 세로 모바일 UI · v4.1

기준 화면은 390×844이며 휴대폰에서는 실제 가용 너비와 높이를 사용합니다.

- 앱 전체 Navigator를 하나의 세로 뷰포트에 배치합니다. 홈, 길드, 계정, 팝업 모두 같은 화면 규격을 사용합니다. 넓은 브라우저에서는 가운데 세로 화면으로 표시합니다.
- 홈의 스크롤형 소개 영역을 전장 미리보기·현재 챕터·기체·하단 출격 버튼 구조로 교체했습니다. 작은 휴대폰에서도 출격/훈련/하단 탭을 바로 누를 수 있습니다.
- 챕터 목록은 하단 시트에서 선택합니다. 시트는 작은 화면에서 스크롤되며 선택 상태를 바로 반영합니다.
- 성장 메뉴 6개를 3열×2행으로 표시하고 인벤토리는 3열 아이템 슬롯으로 배치했습니다. 장착 슬롯 6개와 개별 아이템 상세/합성/잠금 기능은 유지합니다.
- 버튼과 칩은 모바일 터치 밀도를 사용합니다. PC 브라우저에서도 작은 데스크톱 기본 밀도로 축소하지 않습니다.
- 전투의 데스크톱 사이드 패널과 중복 AspectRatio를 제거했습니다. 전투 영역이 전체 화면을 채우고 HUD와 전투 알림은 안전 영역 안에서 겹쳐 표시됩니다. 기체는 맵 가장자리에서도 화면 정중앙에 유지되며, 이동할 수 없는 맵 바깥은 어둡게 표시합니다. 그림은 가로·세로 동일 배율이며 카메라·스폰·위험 구역은 실제 보이는 높이에 맞춥니다.
- Android 세로 방향 고정. 모바일 웹의 가로 화면에는 회전 안내를 표시하고 화면 변경 시 전투를 일시정지합니다. 세로로 돌아온 후 재개할 수 있습니다.
- SafeArea로 노치와 하단 제스처 영역을 확보합니다. 키보드 표시 시 휴대폰 화면 너비는 유지됩니다.

검증: 320×568, 360×640, 390×844, 430×932 화면의 출격 버튼 노출, 성장 메뉴 접근, 전투 영역, 일시정지; 1280×900의 세로 프레임·팝업 범위; 가로↔세로 전환; 상단 44/하단 34 안전 영역에서 챕터 선택. 실제 모바일 크기 브라우저 화면 캡처는 `tools/qa/evidence/portrait-v4/`에 보관합니다.

Flutter analyze 오류 없음, 63개 테스트 통과. 웹 및 Android debug APK 빌드 성공. Cloudflare v4.1.0 공개 배포 후 version.json, D1 health, main.dart.js SHA-256 일치를 확인했습니다. Android 실기기 터치/회전 검증은 별도입니다.

변경 전 소스: `docs/before-portrait-v4.zip`. 계정·클라우드 저장·길드 데이터 구조는 변경하지 않습니다. 새 이미지 생성 호출은 없습니다.


## v4.1.1 중앙 추적 카메라
- 전투 캔버스는 노치 여백을 포함한 전체 앱 뷰포트를 사용하며 HUD/팝업에만 SafeArea를 적용합니다.
- 카메라는 항상 기체 위치에서 뷰포트 반폭·반높이를 뺀 좌표입니다. 맵 경계에서도 카메라를 제한하지 않으며 기체 이동 범위는 기존대로 유지합니다.
- 320×568~430×932 전투 화면 크기와 화면 중앙 좌표, 맵 네 모서리 및 카메라 이동량을 검증했습니다.
- Flutter analyze 통과, 테스트 64개 통과. 초기 테스트는 화면 전환 애니메이션이 끝나기 전 0.2px 오차를 감지하여 전환 완료 후 검증하도록 수정했습니다. 병렬 실행 중 Dart 스레드 시작 오류가 발생해 단일 테스트 실행으로 전체 통과를 확인했습니다.
- 390×844 브라우저에서 이동 전후 중앙 유지, 드래그 입력, 일시정지/재개 확인. 증거: tools/qa/evidence/center-camera-v4/battle-390x844.png.
