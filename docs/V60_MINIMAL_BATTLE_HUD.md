# v10.0.60 전투 HUD 정리

- 상단: 항로 번호·경과 시간·정보/일시정지와 체력·레벨/경험치의2줄. 체력은 하트와 현재 HP, 경험치는 레벨과 게이지로 표시한다. 최대 체력/XP 수치·전체 제한 시간은 접근성 및 정보 창에서 확인한다.
- 상단의 큰 카드 테두리·R/P/N·부품6칸·보조6칸·특화/연계/파일럿 표시는 제거한다. 부품/보조 슬롯은 `BattleLoadoutDetails`로 정보 창에 옮기며 기존 상세 수치와 상태도 그 안에서 유지한다.
- 보스의 체력/공격 예고와 일시적 출현 안내는 전장 내부 오버레이를 유지한다. 상태 변화로 전장 크기를 바꾸지 않는다.
- 하단의 슬로모션·조작/전술·처치 수 설명을 제거한다. 해당 문구만을 만들던 FlightCoach 관찰도 전투 UI에서 제거한다. 조작·슬로모션·피해·저장·보상 규칙은 변경하지 않는다. 저장 오류는 정보 아이콘의 경고와 정보 창/일시정지에서 유지한다.

## 집중 검증

실제 NotoSansKR 글꼴/320×568/글자1.3에서 상단85.75px, 전장482.25px이다. v59의 동일 조건 HUD170.88px/전장389.12px 대비 헤더 약85px 감소, 전장 약93px 증가(기존 외부8px 여백 제거 포함)다. 적 안내 종료와 보스 등장 전후 전장 사각형이 불변이며 정보 창에서 이전 무기/보조 슬롯을 확인하고 닫은 뒤 정상 재개한다. 하단 부연 문구 부재도 확인한다.

관련 검사: `test/combat_hud_layout_test.dart`의 `Size(320.0, 568.0) / 1.3` 한 조건. 전체 회귀/8조건 검사는 반복하지 않는다. APK는 빌드하지 않는다.
