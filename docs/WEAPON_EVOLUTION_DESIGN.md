# 무기 성장 개편 — 강화 · 진화 · 궁극 **[확정·구현 v12.1.0, 2026-10-24]**

사용자 지시: 모든 무기는 **성능 강화**와 **성능 진화**가 있고, 최종 단계는 바로 직전 단계와 **완전히 다른 궁극의 성능·디자인**을 가진다. 단순히 공격력·공격 속도만 오르는 업그레이드는 없앤다.

## 1. 공통 규칙

### 1.1 두 갈래 성장 + 궁극

| 구분 | 무엇이 바뀌나 | 예시 | 카드 색 |
|---|---|---|---|
| **강화** 1~3단계 | 그 무기의 *수치* | 공격력, 공격 속도, 쿨타임, 사정거리, 탄속, 크기, 공격 반경, 지속 시간 | 파랑 |
| **진화** 1~3단계 | 그 무기의 *특성* | 개수 증가, 관통(단계별), 분리, 폭발, 유도, 튕김, 둔화, 연쇄 | 보라 |
| **궁극** | 이름·디자인·작동 방식 전부 | 드론 정찰기 → 공수 정찰 모선 | 금색 |

- 강화와 진화는 **각각 따로** 1→2→3으로 오른다. 어느 쪽을 먼저 찍을지는 플레이어가 고른다.
- 강화 3 + 진화 3을 모두 채우면 다음 레벨업에 **궁극 카드가 반드시 나온다.**
- 한 무기의 총 선택 수는 7장(강화 3 + 진화 3 + 궁극 1)이다. 한 판에 레벨업은 보통 14~18번이므로, **한 판에 궁극 2개 안팎**이 목표다. 모든 무기를 궁극까지 올리는 판은 없다. 무엇을 궁극까지 키울지가 빌드 선택이다.
- 같은 강화 단계 안에서도 무기마다 오르는 수치가 다르다. 예를 들어 발칸은 사거리, 털실은 폭발 반경, 냥펀치는 회전 속도가 오른다.
- 궁극은 **새 PNG 그림 또는 새 글로우 연출 + 새 이름 + 새 작동 방식**이다. 선택하는 순간 1.2초 슬로모션, 기체 확대, 이름 배너가 나오는 **변신 연출**이 붙는다.

### 1.2 지금 규칙에서 바뀌는 것

| 지금 | 개편 후 |
|---|---|
| 기체 무기(part:W#)는 레벨마다 "피해 +20%"만 오른다 | 무기별 강화 3 + 진화 3 + 궁극 |
| 아이템 공격은 Lv1~5에서 수치만 오르다가 짝 보조 스킬이 있으면 진화한다 | 강화 3 + 진화 3 + 궁극. **짝 보조 스킬 조건은 없앤다** |
| 주무기는 "주포 강화" 카드 한 종류뿐이다 | 고양이별 주무기도 강화 3 + 진화 3 + 궁극을 가진다(무기 종류 자체는 고정) |
| 영구 파츠 레벨 | 그대로 둔다. 기본 수치만 올린다(출격 중 성장과는 별개) |

### 1.3 칸
- 주무기 1(고양이 고정)
- 기체 무기 W1~W3 (v12.11.0부터 W4 상부 포탑·드론 칸은 없다. 아래 표의 W4·드론 항목은 장착 칸이 없다)
- 아이템 공격 최대 4칸
- 보조 스킬(공격력·쿨타임·체력·속도·자석)은 지금처럼 따로 유지한다.

## 5. 그림 · 연출

- **새 PNG가 필요한 궁극 형태:**
  - 트윈 회전 포탑
  - 참치 순항 미사일
  - 공수 정찰 모선 + 소형 공수 정찰기
  - 냥냥 융단 폭격 포대
  - 태양 냥냥 개틀링 총열
  - 거대 앞발
  - 레드닷 위성
  - 후방 자주포 본체(기본형)
  - 모두 기존 화풍(굵은 외곽선, 카툰)으로 만든다.
- **글로우 연출로 하는 것:** 레일 빔, 태양 광선, 발톱 충격파, 낙뢰, 그물, 태풍 반달, 핀볼 범퍼 섬광.
- **카드 표시:**
  - 강화(파랑)·진화(보라)·궁극(금색) 테두리로 구분한다.
  - 카드 아래에 "강화 2/3 · 진화 1/3"처럼 진행도 점을 보여 준다.
  - 궁극 카드에는 변신 후 모습의 작은 그림을 넣는다.
- **변신 연출:** 궁극을 고르는 순간 1.2초 슬로모션 → 해당 무기 확대 → 새 모습으로 교체 → 금색 이름 배너.

## 6. 구현 순서 (제안)

1. **데이터 틀:** 무기별 강화/진화 단계표, 카드 종류 3가지, 진행도 저장(이어하기 포함). 기존 "+20%" 카드를 대체한다.
2. **기체 무기 3종** (발칸 · 고등어 미사일 · 정찰 드론): 강화·진화 → 궁극.
3. **아이템 공격 6종:** 기존 Lv1~5/짝 진화를 새 틀로 옮긴다.
4. **주무기 3종:** 고양이별 강화·진화·궁극.
5. **후방 자주포** 신규 + **궁극 그림·변신 연출**.
6. **밸런스:** 자동 전투 시뮬레이션으로 "한 판에 궁극 2개 안팎", 무기 간 피해 편차를 맞춘다.

## 7. 확정 사항과 구현 메모 (v12.1.0)

- 사용자 확정: 강화 3 + 진화 3 + 궁극, 후방 자주포 추가, 짝 보조 스킬 조건 삭제.
- 코드: `lib/game/weapon_growth.dart`(단계표·카드·적용), `growth_arms.dart`(주무기·기체 무기), `paw_weapons.dart`(아이템 공격과 궁극 효과), `ui/upgrade_slots.dart`(카드 색·진행 점), `ui/ultimate_banner.dart`(변신 배너).
- 저장: 출격 체크포인트에 `growthEnhance`·`growthEvolve`·`growthUltimates`.
- 후방 자주포: 새 함대는 W3에 기본 장착. 기존 함대는 한 번만 자주포를 받고, W3의 뒤로 쏘는 발칸이 자주포로 바뀐다(발칸은 보관함에 남음).
- 보스 보급 상자: 무기 하나의 다음 강화/진화 1단계를 무료로 준다.
- 밸런스 조정:
  - 드론의 적 탄 요격은 진화 2부터만 된다(설계 문구대로).
  - 트윈 회전 포탑은 연사 1.5배, 적 탄 35% 확률 요격으로 낮췄다.
  - 성장으로 화력이 크게 오른 만큼, 뒤쪽 집일수록 편대 적 체력(+12%/단계)과 보스 체력(+12%/집 번호)을 올렸다.
- 기체 위 후방 자주포 그림: `icons_v12/mortar_mount.png` (v12.1.2).
- 궁극 그림(짧고 통통한 치비형): `assets/art/icons_v12/` mothership · para · tuna · turret · paw · satellite · cloud · mortar.
