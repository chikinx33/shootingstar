원본 XAPK/스트리밍 분할 파일은 현재 기존 경로에 없다. 보관 본체는 Unity IL2CPP 메타데이터이며 C# 원본 소스가 아니다. 메서드 본문·일반 전투의 실제 확률·등급별 XP·색상·시간 경계는 복구하지 못했다. 따라서 아래 값은 원작에서 추출한 수치가 아니라 사용자 관찰과 확인한 분리 구조를 현재 게임에 맞춰 설계한 값이다. 원작 자산/코드를 게임에 복사하지 않았다.

## 적용 규칙

기존: 일반 적 모두1개/2XP, 엘리트4개/8XP, 보스20개/40XP.

| 항로 진행 시간 / 제한 시간 | 일반 적 보석 | 기본 확률 | 연속 미드롭 최대 |
|---|---|---|---|
| 첫1/3 | 초록4XP | 50% | 5마리 |
| 중간1/3 | 파랑8XP | 25% | 11마리 |
| 마지막1/3 이후 | 금색16XP | 12.5% | 23마리 |

각 단계의 다음 처치에서는 미드롭 상한 보정이 발동한다. 기존에 떨어진 보석은 나중에 시간이 지나도 가치가 바뀌지 않는다. 시간은 기존 항로 진행 시계이며 보스 대결/일시정지의 기존 정지 규칙을 따른다. 일반 적의 예상 수급을2XP/처치 부근에 유지하면서 후반 보석의 개수는 줄이고 개당 가치를 높인다. 엘리트는 파랑1개/8XP, 보스는 금색2개+파랑1개/총40XP를 확정 지급한다.

각 단계5만 회의 동일 시드 표본: 초록25,397개/2.03176XP·처치, 파랑12,984개/2.07744XP·처치, 금색6,475개/2.072XP·처치. 전부 드롭하던 방식 대비 물체 수를 줄이며 성장 속도가 급격히 줄거나 증가하지 않게 했다. 이는 균일 처치 표본이며 모든 장비/숙련도에서 같은 레벨이 나온다는 보장은 아니다.

## 수치·시각·저장 연결

- 원본 위치 API와2XP 구 데이터를 유지하는 `ExperienceCrystal` 값 모델을 사용한다. 일반 견인·스캐너 이동에서 XP를 잃지 않는다.
- 보석은 자체 Canvas 다이아몬드이며 초록/파랑/금색의 색·크기·면 분할이 다르다. 자석으로 날아오는 보석도 같은 등급으로 그린다. 이미지 생성/외부 호출은 없다.
- 이동 그림 캐시는 위치뿐 아니라 등급 변경도 감지한다. 그림은 등급별3개만 캐시한다.
- 바닥 보석은 기본 XP를 보관하고 실제 획득/자석 시작 시 경험치 보너스를 한 번 적용한다. 기존 개수 상한 초과의 자동 XP 회수 규칙에도 실제 값을 합산한다.
- 드롭 전용 RNG와 연속 미드롭 수를 저장한다. 전투 RNG와 분리하며 저장 전후 드롭 순서가 같다. 체크포인트의 선택 필드 `crystalXp`/`xpDrops`가 없는 옛 저장은 보석당2XP로 복원한다. 잘못된 길이/음수/과대 XP/RNG는 거부한다.
- 회수 추진기의 기존16개×2XP 기준 발동 빈도는 기본32XP 단위로 유지한다. 고등급 보석 때문에 부당하게 느려지지 않으며 한/영 설명을 함께 바꿨다.
- 지난 패치의2줄 HUD·안정된 전장·하단 설명 제거는 유지한다. APK는 빌드하지 않는다.
