# 전투 HUD 정리 — v10.0.19

2026-10-19. 사용자가 요청한 상단 정보 밀도와 실제 전투 면적 개선이다. 전투 규칙·성장·보상·일반/개발자 저장 형식은 변경하지 않았다.

- 체력과 경험치/레벨을 한 행의 독립 게이지로 묶었다. 수치와 색을 함께 표시한다.
- 시간·항로와 주포 R/P/N을 짧은 헤더에 배치했다. 전체 항로/도전 이름과 주포 수치는 접근성 이름과 전투 정보 창에 유지한다.
- 무기/보조 각6슬롯은 폭에 따라 커지는 정사각형 대신 도색32px(+여백2px)의 가로형이다. 기존28px 그림과12px 이상 단계/E 표식을 유지한다. 빈 슬롯은 작게 표시한다.
- 긴 특화/시너지/파일럿 설명은 HUD의 상태 배지와 ‘전투 정보’ 창으로 나눴다. 정보 창에서는 실제 장착 주무기 이름, 체력/경험치, 무기·보조 전체 단계와 역할을 읽는다. 정보 창을 열면 전투·입력이 멈추며 닫으면 이어진다. 앱이 배경에 있으면 일시정지를 유지한다.
- 일시정지/정보 버튼은48px 터치 영역, HUD와 별도로 남은 실제 전투 영역을 기준으로 카메라·터치 좌표를 계산한다. 보스 체력·예고/안전 통로 문구는 유지한다.
- 320px/글자130% 캡처에서 라벨이 세로로 갈라진18차 시안을 발견해, 글자 배율에 맞는 라벨 폭으로19차에서 수정했다. 18차 업로드와 최종19차 업로드를 구분한다.

## 확인 범위

- 소스 계약과 Dart 분석: 새 오류/경고 없음. 기존 정보 수준 lint19개는 유지했다.
- HUD8조건: 모든 슬롯·라벨 한 줄·정보 열람 정지/복귀·일시정지를 검사했다. 주포 분기/시너지/장비 연계8조건씩은 긴 설명이 전투 정보에 유지되는지 확인했다. 저장 분리/재접속2개와 모바일 카메라/전장 크기4조건도 확인했다.
- 기존 `portrait_test.dart`의 데스크톱/노치2개는 이전 로비 선택자를 찾지 못하는 별도 실패로 기록했다. 이번 변경과 관계없는 로비/챕터를 다시 수정하지 않았다. 전체 게임 테스트를 모두 통과했다고 주장하지 않는다.
- 실제 웹은 HUD만 320·360·390·430 × 글자1.0/1.3, 최고 항로의 채워진 슬롯·보스 예고·정보 열람/닫기·일시정지/계속·터치 조작을 검사한다. 코드: `tools/qa/hud-v19.cjs`, 캡처/좌표: `tools/qa/evidence/hud-v19/`.
- 초기 자동화에서 의미 노드 선택과 진행 중 전투의 `networkidle` 대기 기준이 맞지 않은 것은 검증 도구에서 수정했다. 정보/보스 문구를 숨기거나 검증 조건을 글자 축소로 맞추지 않았다.
- 실제 APK와 계정·저장 데이터에는 쓰지 않았다. 별도 손님 브라우저에서 실행했다. 빌드·배포·활성 버전/API 증거는 `.local/quick-web/`에 기록한다. 공개 화면의 Access 인증 제한은 로컬 실화면 확인과 구분한다.
