# 이미지 아트 v6.0.0

2026-10-16 요청에 따라 코드로 그리던 게임 일러스트와 UI 장식을 래스터 이미지로 교체했다. Flutter/Canvas 구조와 전투 계산은 유지한다. 한글, 수치, 게이지 비율, 레이아웃·클리핑·피격 영역을 계산하는 좌표는 실시간으로 처리한다. 이미지로 글자를 구워 넣지 않는다.

## 원본과 적용

원본 폴더는 `assets/art/raster_v6/`이다. 내장 `image_gen`으로 새로 제작한 PNG 7장에 146개 셀을 배치했다. 기존 이미지·장비·펫·테크 아트는 보존했다. 모든 셀을 서로 다른 게임 기능으로 추가한 것은 아니며 일부는 예비 아트다.

| 이미지 | 구성 | 적용 |
| --- | --- | --- |
| enemies.png | 4×3 / 12셀 | 10종 적, 지원 드론, 가디언 |
| bosses.png | 4×3 / 12셀 | 10세계 보스, 예비 아군 기체 |
| projectiles.png | 6×4 / 24셀 | 일반·중탄, 미사일, 드릴, 구체, 부메랑, 기뢰, 빙결, 레이저, 경험치, 추진 화염 |
| effects.png | 4×4 / 16셀 | 피격·폭발·실드·장판·자석·위험 예고·조준 |
| icons.png | 8×8 / 64셀 | 메뉴, 무기·보조 스킬, 보급품, 설정·성장 UI |
| panels.png | 2×3 / 6셀 | 기본·선택·보상 카드, 버튼, HUD·게이지 |
| worlds.png | 4×3 / 12셀 | 10세계 지면·성운과 예비 UI/격납고 배경 |

정확한 생성 입력은 `prompts.json`, 크기·파일 SHA-256은 `manifest.json`에 기록한다. 외부 이미지 API 실행기나 API 키를 사용하지 않았다. 생성된 투명 이미지의 알파 채널은 유지했다. 시트는 재도색하거나 배경을 잘라내지 않고 소스 사각형을 지정해 사용한다.

`lib/art/raster_assets.dart`가 디코딩 결과를 앱 단위로 공유한다. PNG 합계는 약 15.97MiB, 원본 크기 RGBA 디코딩 계산은 약 41.99MiB다. 이 수치는 텍스처 자체의 계산이며 브라우저 전체 메모리 사용량은 아니다. 카드·버튼은 테두리 조각의 크기를 유지하고 가운데·변 부분을 늘린다. 생성된 패널의 실제 테두리에 맞춰 소스 영역을 별도 지정했다.

## 동작 보존과 가독성

- `engine.dart`, 적 행동·무기·고유 모듈 계산, 프로필·저장 형식, 밸런스 데이터는 변경하지 않았다. 변경 전 소스는 `.local/visual-before-20261016`에 보관했다.
- 적 역할별 실루엣과 세계별 보스 형태를 분리한다. 적탄·위험 예고는 적색, 아군 에너지는 청록/청색 계열이다.
- R/P/N 보급은 이미지와 실제 문자 라벨을 함께 표시한다. 화면 밖 개체는 그리기만 생략하며 전투 시뮬레이션을 제거하지 않는다.
- 효과 줄이기는 추가 입자·자석 파동·회전 장식을 줄인다. 위험 예고는 유지한다. 장식용 페인터는 포인터를 가로채지 않는다.
- 버튼·대화상자는 Flutter의 입력·초점·접근성 구조를 유지한다. 버튼의 한글 글꼴을 명시했다.
- 장시간 휴대폰 실기기 성능은 이번 데스크톱 브라우저 검사로 보증하지 않는다.

## 웹 검증

`tools/qa/evidence/visual-v6/`에 정적 분석·Flutter 검사·정식 웹 빌드, 37개 장면, 기존 저장 이관·재접속, 부하 측정과 정식 앱 조작 증거를 보관한다. 전투 장면 검사에는 별도 QA 진입점의 높은 선체·주입된 무장이 포함되며 자연 완주나 실제 이용자 승률 검사가 아니다.

정식 진입점은 `lib/main.dart`, QA 진입점은 `tools/qa/campaign_preview.dart`이며 공개 배포에는 정식 `build/web`만 사용한다. APK는 빌드하지 않는다.

최종 로컬 검사: Flutter 104개 통과, 정적 분석 문제 없음, 정식/QA 웹 빌드 성공. 웹 37장면의 브라우저 예외 0건이며 기존 저장 이관·재화/인벤토리·선택·재접속 보존을 확인했다. 설정창은 Flutter 웹 접근성 오버레이를 통해 실제 좌표 터치로 닫힘을 확인한다. 단순 DOM 겹침 판정에 대한 강제 클릭은 사용하지 않았다.

부하 장면은 적 260기·투사체 59개 상태에서 데스크톱 headless Chrome 모바일 뷰포트로 1.812초간 측정했다. 프레임 간격 중앙값 18ms, 95백분위 29ms다. 휴대폰 실기기나 장시간 성능을 의미하지 않는다.
