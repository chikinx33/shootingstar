## 적용 구조

- 계정: 로그인/가입/복구 분류와 계정 헤더 고정. 폼·동기화 현황·복구 코드·충돌 선택은 `GamePages`. 입력 20/라벨 18/안내 16, 주요 행동 72/22/36, 보조 행동 64/20/32. 키보드가 열리면 장식 헤더와 분류를 접고 앱바의 키보드 닫기를 남긴다. 오류/요청 상태 변경 시 첫 페이지부터 다시 표시한다. 기존 아이디/비밀번호/닉네임 검증과 로그인/복구/동기화/충돌 백업/로그아웃 코드를 그대로 호출한다.
- 설정: `FlightSettings`의 `GameDialog`. 큰 88 높이 스위치, 48 터치 음량 증감, 기존 연속 슬라이더, 저장 안내 16. 효과음·음량·시각 효과 줄이기는 기존 프로필 setter로 저장한다. 라이선스는 패키지 항목만 목록이며 전문은 고정 페이지다. 계정 바로가기도 같은 계정 화면으로 연결한다.
- 비행 가이드: 96 PNG와 22 제목으로 네 단계 구분. 기존 설명과 조작 안내를 유지한다. 헤더 닫기는 가이드 완료를 처리하지 않고 ‘비행 준비 완료’만 기존 완료 콜백을 한 번 호출한다.
- 진화 도감: 고정 제목/무기·보조 분류, 스킬 항목만 목록. 72 그림/24 이름/16 조건/64 상세 행동. 상세는 144 그림과 진화 조건/짝 스킬을 고정 페이지로 표시한다. 조건은 `survivalSkills`에서 읽고 해금·성장 수치를 새로 만들지 않는다. 태양/전격 기뢰와 구급 요격대는 기존 기뢰/드론 PNG에 불꽃·전기·구급 그림을 겹쳐 재화 아이콘 오표시를 수정했다.

결정 버튼 폭은 최대 264, 실제 도색 높이/종횡비는 공통 규격을 따른다. 폼·설정·가이드·상세에 스크롤이나 글자 축소를 넣지 않는다. 팝업 본문은 게임 테마의 글꼴을 명시적으로 상속해 Flutter 기본 빨간 오류 글꼴이 나타나던 공통 문제를 수정했다. 팝업·단계 제목과 설정 스위치에는 명확한 접근성 이름을 제공한다.

Windows에서는 각 Flutter 명령 전 프로젝트의 `.pub-cache`를 `PUB_CACHE`로 설정한다. `test/support_ui_contract_test.dart`는 320×568 / 360×640 / 390×844 / 430×932 × `TextScaler` 1.0/1.3의 여덟 조건을 검증한다. 계정 폼과 키보드 220 인셋·검증 오류·요청 중 비활성화·연결 재시도·충돌 취소/확인·복구 코드 숨김·로그아웃, 설정 변경 후 재실행, 패키지 목록/라이선스 전문, 가이드 네 단계, 무기/융합/보조 상세와 저장 불변을 검사한다. 팝업 제목의 실제 `RenderParagraph` 색상과 밑줄도 검사한다.

브라우저는 기본 게임 8797과 동일 UI를 쓰는 글자 확대 전용 진입점 8798을 사용한다. 130%는 페이지 줌이 아닌 실제 Flutter `TextScaler.linear(1.3)`이다. 매 조건마다 새 모바일 Chrome 컨텍스트에서 실제 UI로 게스트 저장을 만들며 사용자 브라우저의 저장을 읽거나 초기화하지 않는다. 테스트용 자원·장비·편성을 설정한 뒤 실제 포인터/터치/휠/페이지 이동/입력/새로고침을 검사한다. 목록의 제목 고정, 비목록 좌표 불변, 버튼의 화면 안 실측 크기와 스크린샷을 남긴다.

계정/클라우드 전송은 전부 로컬 대체 응답으로 차단한다. 기존 클라이언트의 로그인·동기화 실패/재시도·충돌 백업·취소/기기 진행 선택·로그아웃을 검사한다. 대표 390px·130%에서는 가입/48자리 코드 복구도 실제 UI와 기존 클라이언트를 거친다. 실제 서버 운영·실계정 인증 검증을 뜻하지 않는다. 실제 온라인 서비스 검증은 출시 전 별도 수행한다.
