# v10.0.30 진행 복구·조작 접근성

실제 ID 없이 개선 가능한 진행 복구와 조작 접근성을 구현했다. 기본 전투·100항로·성장·수급·입력 해제5%는 유지한다. 실제 ID/운영자 정보/기기·이용자 검증은 별도 출시 조건이며 APK를 빌드하지 않는다.

## 직접 백업과 게스트 복원

경로: **계정 → 저장·복구 도움말 → 진행 백업·복원**.

- 웹은 JSON 파일 다운로드, 네이티브 경로는 백업 내용 복사를 제공한다. 파일 선택/클립보드 읽기·검증·현재 진행 비교·명시적 확인 후 적용한다. Android 파일 선택/클립보드는 소스 구현이며 네이티브 실행 증거가 아니다.
- 기기 저장소를 사용할 수 없는 일반 프로필도 메모리의 진행을 내보낼 수 있다. 복원에는 정상 저장소가 필요하다. 개발자/연출 재현 복사본은 제외한다.
- 형식 `shootingstar.progress.backup`, schema1, 최대512 KB, SHA-256 내용 검사, 지원 진행 version4와 핵심 수치·항목 수를 검사한다. 체크섬은 손상 감지이며 거래 인증/치트 방지 서명이 아니다.
- 비밀번호/세션/복구 코드·길드 바인딩/닉네임/대기 보고·유료 권리·중단 전투·기기 출격 기록은 파일에 담지 않는다. 검증 광고 크레딧의 적용 합계는0으로 정리하며 유료 소유권을 복원하지 않는다. 암호화되지 않은 개인 게임 데이터라는 안내를 표시한다.
- 계정 연결/로그인/만료 계정의 미동기화 진행·저장 충돌·전투·미완료 출격에서는 덮어쓰기를 막는다. 계정 진행은 기존 동기화/충돌 해결 정책을 따른다.
- 복원 전 스냅샷은 `shootingstar.profile.v1.beforeManualRestore`에 보관한다. 현재 저장에 성공한 뒤 메모리에 적용하고, 실패 시 원래 캐시/저장 복구를 시도한다. 저장소가 쓰기를 거부할 때 내구성을 보장한다고 주장하지 않는다. 중복 복원과 준비 중 진행 변경을 차단한다.
- ‘복원 전 진행으로 되돌리기’도 비교/확인을 요구한다. 앱 데이터 삭제와 계정 삭제의 기존 `.before*` 정리 대상에 기기 백업도 포함된다. 별도로 내려받은 파일은 앱이 자동 삭제하지 못한다.

구현: `ProgressBackup`, `Profile.restoreGuestBackup`, `ProgressBackupScreen`. 파일 선택은 [Flutter file_selector](https://pub.dev/packages/file_selector), 웹 저장은 설치된 `cross_file`의 `XFile.saveTo`를 확인해 연결했다.

## 조작·음향 설정

경로: **옵션 → 조작**, 일반 전투 **일시정지 → 조작·음향 설정**.

| 설정 | 선택 | 기본값 |
|---|---|---|
| 반응 거리 |60/45/32px에서 최대 입력 |45px |
| 손떨림 무시 |0/5/10px |5px |
| 능력 버튼 |오른쪽/왼쪽 |오른쪽 |
| 조작 시험 |실제 입력 수식의 방향/크기 표시 |전투·시간·보상 변화 없음 |
| 음향 |효과음·배경음과 음량 |기존 설정 공유 |

기체 최고 속도·공격·난도·보상은 같다. 항성포/파일럿 능력을 함께 이동하며, 설정을 닫아도 일시정지를 유지한다. 입력을 비우고 체크포인트를 갱신한 뒤 명시적으로 ‘계속 비행’을 눌러야 재개한다. 방향 반전·두 번째 손가락 무시·영역 이탈/취소와 입력 해제5%는 보존한다. 설정은 기존 저장/클라우드/백업에 포함하며 구형 저장은 기본값을 쓴다.

옵션 링크를3개로 늘릴 때320px/글자130% 개발자 보드에서7px 넘침을 발견했다. 라이선스 셀의 문구 폭을 확보해 글자18px/행56px와 기존 문구·진입을 보존했다. 모든 상세는 `GamePages`/공통 결정 버튼이며 목록 외 스크롤을 추가하지 않았다.

공유 `roguelike-game-designer`의 `accessibility-difficulty.md`를 적용해 접근 장벽과 전투 난도 계약을 구분했다. 스킬 원본은 변경하지 않았다.

`tools/qa/evidence/completion-v30/summary.json`은 모바일320/360/390/430 × 글자1.0/1.3에서 실제 파일 다운로드·내용 검증·파일 선택·복원 취소·복원·되돌리기·설정 저장·고정 화면 휠/터치 검증8조건을 확인한다. 일반 전투의 실제 일시정지→설정→왼쪽 배치→복귀→명시적 재개와 왼쪽 항성포 위치도 확인했다. 기존 계정/사용자 탭은 변경하지 않았다.

Flutter semantics 활성화 대기·설명 포함 접근성 이름·SharedPreferences 웹 저장의 중첩 JSON을 검수 스크립트에 반영했다. 현재 통과 근거는 `summary.json`이며 이전 실패는 하니스 점검 기록이다.

v10.0.31/32의 마지막 화면 검수에서 기본 아이콘 테마의 색 누락으로 새 조작 기호가 어둡게 보이는 원인을 확인했다. 기본 전경색을 흰색으로 명시했고 PNG 그림·배치·글자·버튼 크기는 유지했다. 표시 수정 후 관련 UI21개가 통과했다(`.local/completion-v32/contrast-ui-tests.log`). 전체653개는 기능이 동일한 v10.0.30에서 수행했으며 표시 수정만으로 전체 검사를 반복하지 않았다. 최종 정식 화면은 `tools/qa/evidence/completion-v30/release-smoke.json`이다.
