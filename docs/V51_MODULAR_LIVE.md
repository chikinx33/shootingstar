# v10.0.51 조합형 기체 실전 적용

사용자 승인으로 v10.0.50 미리보기를 실제 편성·로비·격납고·전투로 전환한다. 기체 고유 능력은 계속 기획 단계이며 발동 기능을 추가하지 않는다. APK 빌드 금지를 유지한다.

## 저장·외형·이관

격납고 → 기체 조립. 본체·무장·방어·지원 탭과 지원 좌/우/후방 위치를 유지한다. 변경은 즉시 저장하고 다음 출격부터 적용한다. 기체 구매는 기체 해금에서 진행한다. 전방 주포는 필수이고 나머지는 해제 가능하다. 미보유 기체와 지원 포드는 장착할 수 없다.

`AircraftAssembly` 값 하나를 실제 로비/격납고/전투가 공유한다. 세 본체는 독립 스프라이트이며 같은 부품을 기체별 물리 앵커에 배치한다. 좌우 날개/장갑은 하나의 장비 값으로 두 위치에 그린다. 포탑과 날개는 실제 조준 방향으로 회전하며 발사 포구도 같은 좌표를 사용한다. 기체/펫/장비 썸네일도 신규 아틀라스로 전환한다.

기존 소유·레벨·각성·투자·재화를 삭제하거나 재구매시키지 않는다. 펫 ID0/1/2는 축전/수리/차폐 지원으로 대응한다. 기본6개 공격/방어 부품은 이관 때 제공한다. 구 저장은 첫 로드 때 `.beforeModularAircraft`에 원본을 한 번 남긴다. `aircraft.version=1`과 프리셋/클라우드 내보내기에 부품·지원 위치를 저장한다. 실제 서버는 부적합 장착·중복 지원·잠긴 기체/지원 포드를 거부하고, 구 클라이언트의 조립 정보 삭제를 차단한다.

구버전 중단 전투는 당시 규칙으로 재개한다. 새 출격부터 조합형 체계를 쓴다. 신규 체크포인트에는 조립·지원 레벨·타이머·차폐·지상 액터와 투하 중 폭탄을 저장한다. 현재 로비 구성으로 진행 중 전투를 덮어쓰지 않는다.

## 실제 전투

| 부품 | 기본 기능 |
|---|---|
| 주포 | 전방 고정 발사. 기존10개 주무기 ID는 주포의 발사 모드로 유지. 유도 침도 전방 원뿔을 벗어나 뒤로 돌지 않음 |
| 보조 포탑 | 상부 물리 포구에서 공중 전방위 조준. 차폐 발생기와 교체하면 공격 대신2초마다 최대 선체2.5% 차폐, 상한18% |
| 날개 | 좌/우 바깥쪽 측면 원뿔. 한 쌍의 기본 피해 예산 합계10/1.4초. 두 포드를 중복 장비로 계산하지 않음 |
| 후방 | 엔진 사이 포구에서 뒤로만 쌍발. 후방 표적이 없으면 발사하지 않음 |
| 지상 폭격창 | 지상 적만 조준.0.45초 투하 예고 후 반경60의 지상 전용 피해. 공중 적/보스 피해 없음 |
| 장갑 | 측면6% / 보강10% 감소. 기존 방어 효과와 합산해 최종70% 상한 유지. 수호자 강화는 추가 감소 최대8%,2초마다 근접 탄환1발 차단 |
| 수리 포드 |12초마다 선체1.8%에 레벨/각성 계수를 적용해 회복. 최대 선체 상한 |
| 축전 포드 |6초마다 에너지3, 파일럿 대기1.2초 단축에 레벨/각성 계수 적용 |
| 차폐 포드 |4초마다 선체2.5%에 레벨/각성 계수 적용. 부품 차폐 전체 상한22%. 낮은 상한의 충전이 기존 더 큰 차폐를 깎지 않음 |

모든 지원 포드는 공격탄/피해를 생성하지 않는다. 기존 보조 스킬 ID는 매핑된 장착부의 피해/효율 강화로 작동하며 보이지 않는 독립 무기를 만들지 않는다. 파일럿의 기존 능력은 유지하되 공격은 보조 포탑에 종속하고 지상 피해를 차단한다. 기체 자체의 신규 특수 능력과 구별한다.

기존 주무기의 후방/원형 공격은 사용자 확정 전방 주포 규칙에 맞춰 전방 파동/충격탄/광탄으로 전환한다.20개 발사 분기도 전방 규칙에 맞게 설명과 기능을 바꾼다. 주포 강화 보급/진화/테크/보스 세트와 정밀 연계(+8%)/순환 방호(주포8회마다 선체3%, 상한15%)는 새 피해 원천에 연결한다. 주포·보조·날개·후방·지상은 독립 타이머를 쓴다.

지상 적3종(탱크/장갑차/고정 포탑)은 별도 표적 층이다. 세계 좌표1.0배 불투명 착륙 패드 위에서 이동한다. 공중 기체와 접촉 피해/밀치기를 교환하지 않는다. 포격은0.8초 고정 조준 예고 뒤 느린 탄환을 발사한다.5대 및 전체 액터 예산 상한, 거리750 회수. 새 아틀라스/생성 원문은 `assets/art/airframe_v51/`에 보존한다.
