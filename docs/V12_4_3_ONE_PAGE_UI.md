# v12.4.3 결과창·로비 한 페이지 정리

사용자 지시(2026-10-25): 결과창이 장황하고 페이지로 나뉘어 불편하다. 꼭 알아야 할 정보만 한 페이지에, 절대 스크롤 없이. 로비의 페이지 넘김 화면도 스크롤·페이지 없이 바꾸고 중요한 정보는 팝업으로.

## 결과창 (`battle.dart` `_result`)

- 한 페이지 고정(페이저 없음): 고양이 그림, 결과 제목(집을 지켜 냈다냥! / 다음엔 꼭 이긴다냥), 집 이름(패배 시 '마지막 피격 · 원인'), 격파·레벨·시간 3칸, 보상(+N 츄르), 큰 버튼 '다음 집으로'(패배 '다시 출격'), 작은 버튼 3개 [보상 · 통계 · 귀환].
- '보상' 팝업으로 옮긴 것: 보스·진행 시간, 획득 내역/저장 오류, 시즌 XP, 테크 해금 안내, 패배 대응 요령, 보상 내역·광고 추가 보상 버튼.
- 없앤 것: 영어 머리말(CHAPTER COMPLETE 등), 긴 부연 문장, 중복 안내.
- 320×568·글자 1.3처럼 좁으면 고양이 그림만 숨긴다.
- 버튼의 접근성 이름(‘다음 항로 출격’, ‘성장 정비 · 귀환’, ‘전투 통계’)은 그대로라 기존 자동 점검이 쓴다.

## 일시정지 (`_pausePanel`)

제목 '일시정지', 복원 안내(있을 때만), '계속 비행', [통계 · 설정], [저장·로비 · 귀환]. 하단 부연 문구 삭제. `_scrim`은 페이저 없는 고정 오버레이.

## 검증

- 새 테스트: `one_page_screens_test`(16화면×2크기), `one_page_states_test`(계정 모든 상태·안내 팝업), `one_page_dialogs_test`, `result_screen_test`(결과 2크기×글자 1.0/1.3×승패 + 일시정지 320×568 글자 1.0/1.3). 관련 20개 파일 실행 결과 실패는 옛 문제 1건(`ui_test`의 '출격 편성' 제목 — 격납고가 모듈 작업장으로 바뀐 뒤의 옛 테스트)과 `content_ui_contract_test`의 '주무장' 탐색(이전부터 실패)뿐이다. `command_ui_contract_test`(연구 화면)·`item_slots_test`(보급 상점) 실패는 이번에 건드리지 않은 화면에서 멈춘다.
- `world_resume_test`의 '레벨업 선택 저장' 테스트는 v12.4.1(보석 순간에만 팝업) 변경을 반영하지 못해 실패하던 것을 이번에 고쳤다.
- `dart analyze lib` 오류·경고 0, UI 계약(일시정지·결과는 페이저 없는 고정 페이지로 규칙 갱신)·가운데 정렬 검사 통과.
- 실제 NotoSansKR 글꼴로 360×720 캡처(결과 승/패, 일시정지, 조작, 펫, 저장 도움말, 계정)를 보고 확인했다.
- 한계: 320×568이나 글자 1.3에서는 일부 로비 화면이 여전히 2페이지로 나뉠 수 있다(넘침 오류 대신 최후 수단). 진행이 많이 쌓인 프로필의 모든 화면을 다 확인하지는 않았다.
