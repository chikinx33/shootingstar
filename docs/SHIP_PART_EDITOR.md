# 기체 조립 편집기 — v10.0.70 (v10.0.71 대칭·방향 버튼)

2026-10-24 사용자 지시: 조종석 유리 속 고양이 같은 미세한 배치는 마스터가 직접 편집 모드에서 조정·저장하고, 그 값을 실제 게임에 반영한다. 구조는 PuzzleKnight의 연출 에디터(버전 길게 누르기 → 코드 → 편집기, 로컬 프리뷰에서는 프로젝트 JSON에 직접 저장)를 따랐다.

## 들어가는 법

1. 옵션(톱니) → 제목 옆 버전을 3초 누르고 개발자 PIN 입력 (기존 개발자 모드와 같다).
2. 테스트 화면 상단 오른쪽의 조절 아이콘(`기체 조립 편집기`)을 누른다.

## 편집

- 위쪽 캔버스에 선샤인 17개 레이어가 겹쳐 보인다. 추진기 불꽃 4프레임은 실제로 움직인다.
- 부위 선택: 캔버스를 탭(가장 위 부위), 가운데 부위 이름 버튼(목록), 좌우 화살표(순서대로).
- 캔버스를 드래그하면 선택 부위가 움직인다. `기준점` 탭에서 드래그하면 그림은 그대로 두고 회전 중심만 옮긴다.
- 버튼은 방향 이름으로 표시한다(v10.0.71 사용자 지시): 위치 `← 왼쪽으로 / 오른쪽으로 →`, `↑ 위로 / ↓ 아래로`, 크기 `작게 / 크게`, 회전 `↺ 반시계 / 시계 ↻`, 기준점 가로·세로, 그리는 순서 `뒤로 보내기 / 앞으로 가져오기`. 가운데에 현재 값이 보인다.
- 한 번 누르면 한 단계, 길게 누르면 연속으로 움직이며 한 번의 되돌리기로 묶인다. 단계는 미세/보통/크게.
- 캔버스 도구: 배경색 바꾸기, 선택 외 흐리게, 돋보기 `작게 보기`/`크게 보기`(40%~400%, 처음 80%), `가운데로`.
- 빈 배경을 누르면 선택이 풀린다. 선택이 없을 때 끌면 부위 대신 화면이 움직인다(v10.0.72).
- 노란 선은 선택 부위 테두리, 빨간 십자는 기준점이다. 이 안내선만 코드로 그리고 게임 그림은 모두 PNG다.

## 좌우 대칭 부위 (v10.0.71)

날개·추진기·미사일·윙건·추진기 불꽃은 왼쪽 한 장을 그리고 오른쪽은 거울상(`mirrorOf`)으로 쓴다. 목록에는 `날개 · 좌우 함께`처럼 하나만 보이고 함께 움직인다.

- 버튼은 오른쪽 부위 기준이다. `바깥쪽으로 ←→`는 두 쪽이 서로 멀어지고 `→← 안쪽으로`는 가까워진다. 가운데 값은 중심선에서의 거리다.
- 위아래 이동, 크기, 그리는 순서, 표시는 두 쪽이 똑같이 바뀐다.
- 회전은 세로 중심선 기준 대칭이다. `↺ 바깥쪽 들기`는 두 날개 끝이 함께 올라가고 `바깥쪽 내리기 ↻`는 함께 내려간다.
- 캔버스에서는 손가락으로 잡은 쪽이 손가락을 따라가고 반대쪽이 거울처럼 움직인다.
- 한쪽만 다르게 하려면 `순서·표시 → 한쪽씩 편집`. 다시 묶으려면 `좌우 함께`(왼쪽 값을 기준으로 맞춘다).

## 붙어 다니는 부위 (`attachTo`)

추진기 불꽃은 해당 추진기에, 조종석 유리와 기본 기체 불꽃은 기본 기체에 붙어 있다. 부모를 옮기거나 돌리거나 키우면 붙은 부위가 같이 움직인다. 붙은 부위만 따로 고칠 수도 있다.

## 저장과 반영

- `저장`: 리비전(r)이 1 오른다. 이 브라우저에 항상 저장된다.
- 로컬 실행(`PLAY_SHOOTINGSTAR.cmd` → `tools/play_web.py`, 127.0.0.1)에서는 프로젝트 파일 `assets/data/ship_layouts.json`에도 바로 기록된다(이전 파일은 `.local/ship-layouts-backup/`에 리비전별 백업). 상단 줄에 `프로젝트 파일`로 표시된다.
- 배포 사이트에서는 이 브라우저에만 남는다. `JSON 복사`로 내용을 전달하면 프로젝트 파일에 반영한다.
- 불러올 때는 게임 기본값(번들) / 프로젝트 파일 / 이 브라우저 저장본 중 리비전이 가장 높은 것을 쓴다.
- `저장본으로`는 마지막 저장 상태로, 상단 되돌리기는 한 단계씩(최대 80) 돌린다. 저장하지 않고 나가면 확인을 묻는다.

## 데이터 형식 (`assets/data/ship_layouts.json`)

캔버스는 정사각형, 중심 (0,0), 한 변 = 1. 각 레이어:

| 키 | 의미 |
|---|---|
| `x`, `y` | 기준점의 캔버스 위치 |
| `width`, `aspect` | 폭(캔버스 비율), 높이 = 폭 × aspect |
| `pivotX`, `pivotY` | 그림 안 기준점 (0~1, 좌우 반전 뒤 기준) |
| `rotation` | 기준점 기준 시계 방향 각도 |
| `z` | 클수록 위에 그림 |
| `flipX`, `visible`, `mirrorOf` | 좌우 반전, 표시, 거울상 원본 |
| `attachTo` | 붙어 다닐 부모 레이어 |
| `frames`, `fps` | 애니메이션 프레임(불꽃) |

`tools/render_ship_layout.py`는 같은 규칙으로 PNG를 그려 확인한다. `tools/build_ship_parts.py`는 `assets/concept/sunshine_parts_v1/`의 원본에서 에셋과 **기본값 JSON을 다시 만들며 편집값을 덮어쓰므로**, 편집 뒤에는 실행하지 않는다.

## 초기 배치

`sunshine_parts_v1` 합체 시험 값을 옮겼다. 조종석 유리(고양이)는 기본 기체에서 잘라 `canopy` 레이어(z 7)로 분리해 동체 장갑(z 5)·기수(z 6) 위에 둔다. 사용자 지적대로 장갑에 묻히던 고양이가 보이게 하기 위한 초기값이며 최종값은 편집기에서 정한다.

추진기는 v10.0.71부터 좌우 한 쌍 그림 대신 왼쪽 한 장(`engine_left.png`)과 거울상으로 나눴다.
