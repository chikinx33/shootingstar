# 입력 해제 슬로모션·즉시 재현 — v10.0.21

2026-10-19 사용자 요청. 전투에서 누르지 않는 동안5%, 전투 영역을 누르거나 이동 키를 누르는 동안100% 속도다. 이동하지 않고 누르기만 해도 정상 속도다. 손 떼기/포인터 취소/영역 이탈은 입력을 비우고5%로 복귀한다. 일시정지·선택창·앱 배경 전환은 기존의 완전 정지를 유지한다.

## 즉시 재현

- 자석: 같은 실제 공급품/흡수/레벨 선택 경로로56개 보석을 회수한다.
