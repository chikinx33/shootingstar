# v10.0.63 로비 슬롯과 떠 있는 부품

사용자 요청: 로비 기체80%, 눈으로 슬롯 표시/숨김, 슬롯별 보유 장비/특성/성능 비교, 부품 연결선 제거, 본체 뒤를 미세하게 따라오는 부품.

## 적용

- 로비 `ArcadeAircraft.visualScale=.8`. 로비 카드/조작 영역은 줄이지 않으며 다른 카탈로그/전투 크기를 변경하지 않는다.
- 눈은 기체 상단48px 조작이다. 기본은 완성 기체이며 켜면 장비6/무장6/지원3 분류를 선택할 수 있다. 넓고 긴 전시 공간에는 슬롯을 공간 배치하고, 작은 화면에서는 반복 슬롯만 목록 안에서 이동한다. 화면 전체/주요 메뉴/출격 버튼은 고정이다.
- 슬롯을 누르면 해당 슬롯의 보유 목록, 항목을 누르면 특성, `장착`을 누르면 실제 장비/조립을 변경한다. 장비는 기존 인벤토리 ID를 쓰고 지원 부품은 해금한 지원 레벨을 확인한다. 다른 지원 위치에 있던 같은 장치는 중복 생성하지 않고 이동한다. 필수 주포 해제는 제공하지 않는다.
- 장비 ▲/▼는 같은 슬롯의 기본 화력/선체 기여량 차이다. 계산은 실제 `gearDamage/gearHull`와 같은 `gearBaseContribution`을 공유한다. 수치가 같으면 회색 표시다. 고유 기능과 세트 효과를 임의의 전투력으로 더해 좋은 장비라고 단정하지 않고 상세에서 별도로 보여준다. 공격 포탑/차폐 같은 다른 역할은 특성 비교로 안내한다.
- 새 장착은 기존 자동 저장/다음 출격 스냅샷을 따른다. 중단된 전투의 장비/보상을 소급 변경하지 않는다.
- 합성 렌더의 강제 레일/연결선을 제거했다. PNG 본체 자체와 부품의 디자인/크기는 유지한다.
- 전투 본체는 기존 입력대로 이동한다. 주포/보조/날개/후방/장갑/센서/코어/추진/지원에0.04~0.115초의 서로 다른 추종 지연, 최대1.28~3.68 전장 단위의 시각 오프셋을 적용한다. 정지하면 지수적으로 수렴하며 탄성 진동/본체 흔들림을 넣지 않는다. 기존 무장 반동과 합성하고 효과 축소에서는 표시하지 않는다.
- 지연은 시각 상태에만 있다. 조종/피격 판정/발사 좌표/난수/전투 저장을 바꾸지 않는다. 레이저/보스/경험치/이번 전투 성장 수치 변경 없음.
