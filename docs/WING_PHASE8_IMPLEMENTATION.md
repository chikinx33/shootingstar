# 세계별 보스·단계 교전 — v10.0.10

2026-10-18. roguelike-game-designer의 보스/교전 설계 기준을 적용했다. 기존 보스의 HP·보상·65%/30% 격벽·코어 공격 기회·보스 수와 전투 시계를 유지하면서 세계별 위협과 단계별 순서를 확장했다. 자체 초도 수치이며 최종 승률/밸런스 판정은 실제 플레이 피드백이 필요하다.

## 세계와 단계

첫 항로·첫 보스의 단계1→2→3 기본 순서다. 기존 항로 변형을 유지해 항로 인덱스+이번 보스 회차를 더한 나머지로 시작 순서를 회전한다. 따라서 같은 세계의 다른 항로/두 번째 보스는 동일한 순서로 시작하지 않을 수 있다.

| 세계 | 기본 순서 | 주요 판단 |
|---|---|---|
| 잔광 외곽 | 통로 방사탄 → 조준 부채탄 → 직선 돌진 | 통로 읽기·측면 회피·돌진 이탈 |
| 적색 성운 | 조준 부채탄 → 표식 포격 → 직선 돌진 | 움직이기 전 고정된 표적 확인 |
| 공허의 왕관 | 통로 방사탄 → 기뢰 고리 → 쌍열 레이저 | 출구와 중앙 통로 활용 |
| 빙결 고리 | 느린 조준탄 → 쌍열 레이저 → 표식 포격 | 느린 탄 사이 위치 선점 |
| 균사 정원 | 표식 포격 → 통로 방사탄 → 기뢰 고리 | 후반 소환 적 우선순위 |
| 철의 묘지 | 기뢰 고리 → 표식 포격 → 쌍열 레이저 | 설치 구역 이탈·통로 선택 |
| 태양 용광로 | 직선 돌진 → 조준 부채탄 → 표식 포격 | 돌진 경로 고정 후 피하기 |
| 심해 전파 | 쌍열 레이저 → 느린 방사탄 → 느린 조준탄 | 중앙 통로와 저속 탄막 간 교대 |
| 수정 미궁 | 조준 부채탄 → 쌍열 레이저 → 통로 방사탄 | 측면 회피와 중앙 이동을 구분 |
| 특이점 심장 | 기뢰 고리 → 쌍열 레이저 → 표식 포격 | 세 가지 공간 제어와 소환 적 대응 |

1단계는 기본 공격을 반복해 익힐 기회를 준다. 2·3단계는 매 두 번째 사이클에 해당 세계 배열의 직전 공격을 사용해 교대한다. 순서는 고정 규칙이며 플레이어 HP/장비/DPS에 따라 몰래 바꾸지 않는다. 적색/공허/심해/수정/특이점의 후반 방사·부채 공격만 기존1.65초 추가 발사를 유지한다. 첫 단계와 새 설치/레이저 공격에 예고 없는 추가 발사를 붙이지 않는다.

## 공통 시간과 대응

모든 사이클은 기존 **예고1초 → 공격1.2초 → 코어 개방2초**다. 경고 시작에 방향·보스 원점·플레이어 표적을 고정한다. 포격·기뢰·쌍열 보스는 경고/공격 중 원점을 움직이지 않는다. 화면은 기존 보스 아트와 HUD를 사용하고 새 공격은 전장 안의 경로/원형 예고만 추가했다. 공통 레이아웃·글자 크기·내비게이션은 변경하지 않았다.

| 공격 | 규칙과 회피 |
|---|---|
| 통로 방사탄 | 기존 ±0.42라디안 안전 통로, 세계별16~20발 후보 중 통로 방향 제외. 속도105, 빙결/심해85 |
| 조준 부채탄 | 기존7발·0.16라디안 간격, 고정 방향으로 속도150, 빙결/심해85. 옆으로 이동 |
| 직선 돌진 | 기존1~2.2초 구간, 속도210/태양240. 경로 표시와 실제 이동 거리 유지 |
| 쌍열 레이저 | 고정 축 좌우70에 길이420의2줄. 반폭10·피해10·지속0.55초. 플레이어 반경12를 제외한 중앙 통로96거리. 예고1초 동안 피해 없음, 한 광선에서 반복 피해 방지. 발사점이 화면 밖이어도 광선은 실제 전장 클립 안에 표시 |
| 표식 포격 | 고정 표적과 좌우88의3점. 원 반경30을 먼저 표시하고1초 후 속도360 포탄. 기존 착탄/1회 폭발 경로로 피해10, 수명1.15초. 표식은 플레이어 이동을 따라가지 않음 |
| 기뢰 고리 | 고정 표적 주위115거리의 최대7개 후보, 반경22·피해10. 열린 방향 ±약45도 제외, 예고1초 후1.2초 활성. 경계 보정 후 표적70거리 이내/중복/출구 방향 후보 제거. 모서리에서는 전장 안쪽으로 출구를 바꾸며 초록 선으로 표시 |

보스 탄/광선/포격/기뢰는 코어가 열릴 때 정리한다. 광선은 기존 요격 불가, 포탄은 기존 요격 가능 판정을 따른다. 방사탄/포탄의 실제 피해는 기존 선체 방어·피격 무적 경로를 사용한다. 코어 개방 중 소환 적의 사격까지 사라지는 완전 무적 구간이라는 의미는 아니다.

균사/특이점은2·3단계 공격 때만 최대2기씩 소환하며 살아 있는 소환 적은4기까지다. 플레이어90거리 이내에는 생성하지 않고 기존 최초 사격 지연을 사용한다. 단계 전환/격파 때 소환 적·적탄을 정리하되 정리 자체에 처치/XP 보상을 지급하지 않는다. 기존 보스 상자/격파 보상은 유지한다. 일반 항로 편대가 보스전에 섞이지 않는 기존 전환도 유지한다.

## 보존과 검사

구현은 `world_bosses.dart`와 엔진의 보스 경로, 전투 예고 렌더링에 한정했다. 주무기 영구 소유/강화·발사 분기·기술/장비 연계·일반 웨이브/편대·R/P/N·진화·융합·프로필/서버 저장·기체 선택 소스16개의 작업 전후 SHA-256을 비교한다. 백업 `.local/wing-phase8-before/manifest.json`.

관련 Flutter **38개** 통과: 신규9 + 기존 보스7 + 캠페인12 + 항로 웨이브10. 새 검사는10세계×3단계의 실제 발사/돌진, 단계별 교대, 고정 표적/경로와 정지·성장 선택, 쌍열 중앙/직격, 포격 고정점 피해/회피, 기뢰 예고/활성 및 네 모서리 출구, 소환/탄 상한, 단계 전환 정리/무료 보상 방지, 격벽 피해 하한을 포함한다. 기존 검사는100항로 보스 사슬·진화/융합/저장 이관과 항로별 편대 스케줄을 포함한다.

최초 새 검사의 ‘모든 공격은 탄환을 만든다’는 조건이 돌진에서 실패해 돌진 활성도 인정하도록 고쳤다. 나머지37개는 통과했고 수정한1개만 다시 실행했다. 초기 분석의 정수 타입1건과 블록 스타일1건을 수정한 후 변경3파일 분석 문제0. 통과한 전체 검사를 반복하지 않았다. UI 소스 계약도 통과했다.

정식 웹에서 빠른320px 로비/출격 검사와390px 훈련3회로 새 포격·기뢰·쌍열 예고 및 각1~3단계의 자연 전환을 확인했다. 실제 화면 PNG3장을 육안 확인했고 브라우저 예외/오버플로0건이다. 훈련은29초에 자연 보스가 나오지만 캠페인의 격벽 피해 제한이 없는 기존 별도 모드다. 따라서 훈련 브라우저 증거를 캠페인 완주나 정식3단계 강제 통과 증거로 주장하지 않으며, 캠페인 단계 계약은 엔진 검사로 구분한다. 별도 QA 빌드·사용자 계정 수정·APK 빌드는 하지 않았다.
