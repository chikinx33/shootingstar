# 폐허 도시와 구름 배경 · v4.4.0

사용자 승인: OpenAI 기본 이미지 생성 2회. 별도 API 키 미사용, 세부 모델/정확한 과금은 도구에서 미공개. 추가 호출 없음.

## 이미지
- assets/art/ruined_city_ground.png: 도로·교차로·붕괴한 건물이 보이는 수직 항공 시점, 1254×1254 RGB.
- assets/art/cloud_layer.png: 독립적인 옅은 구름 덩어리, 1254×1254 RGBA. 실제 알파 범위 0~254 확인.
- 원본은 Codex 생성 폴더에 보존하고 프로젝트로 복사했다. 기존 survival_terrain.png도 보존했다.

## 층 순서
1. 먼 도시 지면: 카메라 이동량 24%, 540 논리 픽셀 타일. 동일 가장자리를 연결하도록 교차 반전 반복해 이음선을 줄인다.
2. 대기 안개: 낮은 대비의 청회색 반투명 층.
3. 구름: 카메라 이동량 48%, 초당 오른쪽 4/아래 2.5 논리 픽셀 바람. 서로 다른 크기·불투명도와 행별 오프셋.
4. 위험 구역/전투 경계/경험치/적/탄환/기체, 그 위에 HUD.

구름은 전투 판독성을 위해 모든 전투 오브젝트 아래에 그린다. 카메라와 별개인 atmosphereTime은 보스전에도 흐르지만 일시정지/스킬 선택에서는 멈춘다. 효과 줄이기 설정에서는 독립적인 바람 애니메이션을 멈춘다. 홈 전장 미리보기에도 같은 새 이미지 2개를 적용했다.

생성 프롬프트 핵심: 완전 수직 고고도 도시 항공 시점, 멀리 보이는 작은 도시 블록과 도로, 구름 없는 지면; 별도 구름은 투명 여백과 부드러운 반투명 가장자리, 지면/하늘 배경 없음. 직접 코드로 구름을 그리는 대신 승인된 생성 래스터를 사용했다.

검증: Flutter analyze 및 테스트 74개 통과. 390×844 브라우저 전투에서 지면/구름/전투 오브젝트 합성과 이동 후 레이어 차이를 확인했다. Android debug APK 빌드 성공. 공개 v4.4.0 build9 배포, D1 health 정상, JS와 새 이미지 2개 SHA-256 일치. 배포 ID 01f34b49-538d-4941-8899-649a5f52a098. 증거 tools/qa/evidence/city-cloud-v4/.
