# v10.0.54 부품2배와 발사 반동

## 사용자 요청 반영

v53의 부착 폭을 모두 정확히2배로 바꿨다. 본체 단위76, 로비의 기본 배율1.6을 유지한다. 새 이미지를 생성하거나 세부 묘사를 추가하지 않았다.

| 부품 | v53 폭 | v54 폭 |
|---|---:|---:|
|주포|22%|44%|
|보조|30%|60%|
|날개|28%|56%|
|후방/지상|22%|44%|
|장갑|23%|46%|
|지원|28%|56%|
|센서/코어/벨트|18%|36%|
|추진기|26%|52%|

큰 무장이 서로 묻히지 않도록 날개/장갑은 좌우, 코어/벨트는 하부 좌우, 지상/후방은 중앙 하부로 재배치했다. 지원은 후방 좌우와 뒤에 분리했다. 센서는 전방 주포의 큰 렌즈 장치로 겹쳐 조립한다. 포구 위치도 같은 폭과 원본 종횡비에서 계산한다.

최초 실제 웹 화면에서 확대 부품 사이가 벌어져 보이는 문제를 발견했다. 본체와 각 장착점 사이에 굵은 검정 외곽/아이보리 색면의 단순한 결합 레일을 추가했다. 작은 패널선·볼트나 새 원본 그림 없이 크기와 부품의 물리적 연결을 함께 유지한다. 비공격 지원 장치는 떠 있는 장치로 둔다.

로비의 큰 그림은 세로 공간을 더 쓰며 기본 렌더 배율을 줄이지 않는다. 반면 고정56/72px 기체 목록이나 조립 상세는 실제 원본 아틀라스·피벗·거울 장착·선택 장비·지원 위치로 전체 경계를 계산해 맞춘다. 따라서 작은 목록 칸은 전체 기체를 축소해서 보여 주며, 그 안에서도 부품과 본체의 상대 크기는2배다. 목록 그림이 버튼 밖으로 넘치지 않게 하는 처리를 ‘모든 UI에서 화면상2배’라고 보고하지 않는다.

## 반동

- 실제 탄환 생성 때 해당 주포/보조/좌우 날개/후방만 발사 반대 방향으로 밀린다. 지상 공격은 폭격창에 짧은 반응을 준다. 발사하지 않은 지원/장갑은 반동을 받지 않는다.
- 25ms 후퇴 후135ms 복귀, 총160ms. 주포4.5px, 산탄/리볼버6px, 다른 포3.5px, 폭격창3px. 주포 반동의20%만 본체 전체에 약하게 전달한다.
- 한 무장에 한 반동만 남기므로 산탄/쌍포/다중 발사 수만큼 누적하지 않는다. 좌우 날개 상태와 포구 섬광 제한 키를 분리해 동시에 발사해도 각각 보인다.
- 기본 포구 섬광 반경8에서 주포13/그 외10으로 확대했다. 별도 화면 흔들림/강제 정지/조종 위치 밀림은 추가하지 않는다.
- `CombatCues`의 독립적인6개 상한 상태이며 난수·피해·탄환·체력·보상·저장값을 바꾸지 않는다. 일시정지에서 시간이 멈추고 복귀 후 사라진다. 체크포인트에 들어가지 않는다. 효과 축소/비활성 상태에서는 표시하지 않는다.
