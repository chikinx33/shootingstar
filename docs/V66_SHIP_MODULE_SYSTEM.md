- W2: 동체 레일, 피해1.4/연사0.7/범위1.3/관통+1, 지상 가능.
- W3: 후미 원형 베이스, 후방60° 팬, 피해0.6/수+2.
- W4: 상부 육각 베이스, 360° 최근접 조준, 피해0.6/범위0.9/사거리0.8.

- 무기3종(건/미사일/드론) 모두 네 위치 사용 가능. 미사일의 교대/대형/후방추적/수직 다중 낙하, 드론의 좌우편대/선행/후행/공전을 실제 전투에 연결했다. 드론은 독립 체력/피격/6초 복구가 있다.
- 파츠 인스턴스별 레벨과 기체별 구성 저장. 이동은 같은 인스턴스를 옮기며 복제하지 않는다. 독립 복사본은 다른 슬롯에도 장착 가능. 한 인스턴스를 여러 기체의 편성에 저장하는 것은 허용한다.
- 잠긴 기체 미리보기는 무료 파츠를 생성하지 않는다.
- 수치 계산은 resolvePartStats에 집중. 기체 레벨은 파츠 피해에 중복 적용하지 않는다. 파츠Lv5 발사 수/Lv10 관통 이정표. 기체·파츠 강화는 C/설계도 소비.
- 새 로비/격납고/성장/보급 모듈 경로는 같은 UI다. 눈 ON 소켓/보조7슬롯, 보유 목록, 방향 그림/변경 전후 수치, 장착/강화/미사용 파츠 분해를 연결했다. 편성/파일럿/기록/후원 메뉴는 격납고 메뉴에 유지했다. 보급은 무기3종/보조7종을 독립Lv.1 파츠로 순환 지급하며 실제 획득 팝업에 새 그림을 쓴다. 보유240개 상한, 먹이 교환은 중단하고 예전 먹이 잔액은 보존한다.
- 본체·빈 소켓·파츠를 분리한 정사영 캔버스 아트. 총열은 직사각형이며 원형 총구는 없다. 무장 반동/미세 추종은 시각 효과로 유지한다.

- 서버는 모듈 인스턴스/레벨/위치/중복 보조를 검증한다. 구버전 클라이언트가 새 moduleFleet를 지우는 저장을409로 막는다.

## 이전 데이터

- 기존 인벤토리/재화/해금/진행/구형 조립 기록을 삭제하지 않는다. 기본 장비12종은1회만 새 파츠로 변환한다. 새 보급 획득도 같은 경로다. 세계 세트20종은 보관하며 새 전투에 효과를 적용하지 않는다.
- 구형 무장 보유·강화와 원본 조립은 legacyArchive에 남는다. 기존 전방 주포는 기체 고유 주포로 대체, 날개/회전포/후방/폭격은 해당 W슬롯으로 이전한다. 연구 공격/체력 레벨은 기체 레벨로 반영하고 별도 중복 적용하지 않는다.
- 레거시 지원3종은 보조로 변환한다. 이관 지원은 반복 재생성을 막기 위해 분해 불가. 다른 기체 장착/레거시 잠금·편성 보호 파츠도 분해 불가.
- 새 편성은 ID를 저장하고 적용 시 현재 강화 레벨을 쓴다. 이전15슬롯 편성은 기록을 남기고 새 편성으로 다시 저장하도록 안내한다. 진행 중인 구형 전투 체크포인트는 원래 전투 경로로 유지한다.
