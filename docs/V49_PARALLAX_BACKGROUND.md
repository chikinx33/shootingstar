# v10.0.49 전장 배경3개 레이어

문제의 반투명 건물은 FlightSceneArt.landmarks가 ‘lobby/guild’등 메뉴/장비 PNG를42%/27% 불투명도로 전장 가장자리에 반복한 것이었다. 카메라 x를 무시하고 화면 폭의6%/94%에 배치하여 화면을 따라붙는 장식처럼 보였다. 이 경로와 별도 구름 타원 장식을 제거했다. 메뉴/장비 그림을 배경 소품으로 쓰지 않는다. 항로 선택의 명시적 아이콘은 GameArt에만 남긴다.

내장 imagegen 스킬과 built-in image_gen.imagegen으로3개 독립 PNG를 생성했다. 외부API/CLI는 사용하지 않았다. 원본은 generated_images에 유지하고 `assets/art/parallax_v49/far.png`, `middle.png`, `near.png`에 복사했다. 원경은 불투명 하늘/구름, 중경과 근경은 실제 알파0의 빈 공간과 거의 불투명(알파254)의 구조물이다. 원본 프롬프트와 출처는 같은 폴더의 `generation.json`에 저장했다. 이미지 자체의 픽셀 편집/알파 재가공은 하지 않았다.

| 레이어 | 내용 | 카메라 이동 비율 | 전장 자동 이동 | 로비 자동 이동 |
|---|---|---|---|---|
| 원경 | 낮은 대비의 청록 하늘/구름 | 0.10 | 4px/scene초 | 1.4px/초 |
| 중경 | 작은 부유섬/먼 초소 | 0.28 | 12px/scene초 | 4.2px/초 |
| 근경 | 가장자리 도크/도시 절벽 | 0.55 | 24px/scene초 | 8.4px/초 |

이동식은 `(-camera.x*f, -camera.y*f + time*speed)`다. 전장의 기준점은 세계 중심의 초기 기체 위치로 두며 초기 배경은 가장자리 구도를 유지한다. 실제 이동은 양축 모두 반대로 반응한다. 각 레이어가 다른 비율로 이동하므로 ‘같은 이미지 여러 장’이나 화면 고정 소품이 아니다. 렌더는 레이어별 같은 비율의768px 디코드 이미지를 공유하고 프레임별 디코드/픽셀 가공/전체 saveLayer는 없다. 각 면의 양축2타일 거울 주기로 음수 좌표와 오랜 전투의 반복 경계에서 같은 parity를 유지한다. 기존 세계 색조/대비막과 모든 탄환/예고는 배경 위에 그린다.

전투 정지는 기존 atmosphereTime/position 보존으로 같은 배경을 유지한다. 효과 축소 시 전장 배경 시간과 카메라를0으로 고정한다. 로비는 기존 paint-only 시계와 경로 가림/앱 배경/OS 애니메이션 축소 정지 규칙을 유지한다. 엔진 수치/보상/저장/5% 입력 해제 규칙은 수정하지 않는다.

검증과 정식 웹 배포 증거는 실행 후 기록한다. APK는 빌드하지 않는다.

집중 검사 `test/parallax_background_test.dart`1건 통과: 실제3개 이미지/중앙 알파/구조물의 실체, 거리별 양축 카메라 이동량·방향, 실제 도색 텍스처의 좌표 이동, 양·음수 양축 타일/2타일 반복 경계,1시간·큰 좌표에서 빈 픽셀 없는 반복을 확인했다. `.local/quick-web/20261020-151141-529739/report.json`(관련 검사9.74초). 기존 로비 경계 검사도 원경4px/s의 새15/30초 경계로 갱신했으나 별도 전체 로비 검사는 반복하지 않았다.
