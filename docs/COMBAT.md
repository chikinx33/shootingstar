# 군집 생존 v2 전투·성장 규칙

## v4.5.1 보스와 진화 무기 개정 (2026-10-16)

아래 v4.5 규칙 중 보스와 드론·낙뢰에 관한 설명을 대체한다. `roguelike-game-designer`의 적 예고/공격/회복 구조와 `game-balance`의 단일 대상·범위 효율 구분을 적용했다. 보스 HP 공식, 기존 계정 재화와 저장 버전 4는 변경하지 않았다. 변경 전 소스: `.local/boss-before-20261016`.

### 원인과 변경

통제 실험에서 진화 낙뢰가 보스 한 기에 같은 발동의 12~14타를 몰아 넣었다. 진화 6무기 조합은 첫 보스가 등장한 첫 업데이트(0.05초 이내)에 처치해 기존 체력 단계별 패턴을 건너뛰었다. 실험의 선체 100000은 공격 효율 측정을 위한 장치이며 생존 능력의 증거가 아니다.

- 낙뢰: 사거리 420, 덜 맞은 적부터 분산한다. 발동당 같은 적 최대 2회, EVO 3회. 총 타격 수(기본 Lv.5 6회/EVO 12회, 테크 +2)는 유지하므로 군집 상대 역할을 보존한다. 추가 테크 타격도 단일 대상 상한을 넘지 않는다.
- 드론 EVO: 발사 간격 배율 0.45 → 0.65, 대신 탄환에 1회 관통을 추가한다. 안전한 자동 조준의 단일 보스 효율을 낮추고 군집 처리 효율을 보완한다. 주포 레이저의 전방 정렬, 로켓의 목표 추적은 유지한다.
- 보스: 매 주기 **1초 방향 고정 예고 → 1.2초 공격 → 2초 코어 개방**. 예고와 개방 중에는 움직이지 않는다. 공격 후 집중 사격할 위치를 잡는 것이 목적이다. 모든 시간은 전투 정지·선택창과 함께 멈춘다.
- 방사형은 예고된 초록 안전 통로(방향 기준 ±0.42rad)를 비우고 발사한다. 부채꼴은 예고 시작 시 조준을 고정하므로 옆으로 피할 수 있다. 돌진은 예고 방향으로 초속 210, 1.2초 이동하며 플레이어를 재추적하지 않는다. 예고 경로 너비 68은 보스 지름이며 기체 반경만큼 추가 여유를 두고 벗어나야 한다.
- 방어 상태 피해 배율 0.35, 코어 개방 상태 1.25. 65%/30%/0%에 격벽이 있다. 닫혀 있을 때 다음 격벽을 넘지 못하며, 개방 시 한 격벽을 파괴하면 다음 단계 예고로 넘어간다. 초과 피해는 다음 격벽으로 이월되지 않는다. 폭탄도 같은 규칙을 따른다. 훈련은 피해 배율·격벽 제한에서 제외한다.
- 단계가 바뀌면 이전 적탄을 정리한다. 세 패턴은 챕터·보스 차수에 따라 시작 순서를 바꾼다. 기체가 강해져도 최소 한 번씩 패턴을 보여주며, 적 HP를 플레이어 DPS에 맞춰 몰래 늘리지 않는다.
- HUD에 예고/격벽/코어 상태를 글자로 표시하고 체력바에 격벽 눈금을 넣는다. 보스 둘레는 방어 시 금색, 개방 시 청록색. 주요 예고는 효과 축소 설정에서도 표시한다. 출현 위치를 HUD 아래로 옮겨 예고 시작점이 가려지지 않게 했다.

### 검증과 해석

세 챕터 × 기본/진화/성장 계정 × 세 시드, 총 27회 통제 실험에서 모두 처치했으며 세 단계와 최소 세 번의 공격을 거쳤다. 기본 조합은 주포·로켓 Lv.3, 진화 조합은 6무기 Lv.5와 대응 보조 6종 Lv.5, 성장 계정은 여기에 공격 강화·장비·쿨다운 보너스를 추가했다.

| 조합 | 변경 전 첫 보스 | 변경 후 첫 보스 (세 챕터 범위) |
|---|---|---|
| 기본 2무기 | 9.55~14.65초 | 18.55~23.15초 |
| 진화 6무기 | 등장 업데이트 내 처치 | 6.55~6.90초 |
| 성장 계정 + 진화 6무기 | 등장 업데이트 내 처치 | 6.60초 |

시간은 등장 업데이트 직후부터 측정하므로 0.05초 해상도 오차가 있다. 변경 전 fixture의 속도 보조를 변경 후에는 장판의 실제 진화 조건인 회수 보조로 교정했다. 변경 전 즉사 결과는 이동 이전에 발생하므로 이 교정의 영향을 받지 않는다. 시작 거리·AI도 변경했으므로 위 표는 변경 묶음 전체 비교이며 개별 수치 변경의 단독 효과를 주장하지 않는다.

초기·성장 계정의 실제 선체를 사용한 전체 1챕터 자동 회피 조작 6회도 모두 완주했다. 실제 전투 시간은 620.45~626.05초로, 세 보스전에 합계 약 20~26초가 추가됐다. 별도 기존 신규 계정 회피 테스트도 세 챕터 각각 2/3 완주를 유지했다. 이는 정해진 조작과 시드의 회귀 검증이며 사람의 승률이 아니다.

극단적 순간 피해에서도 단계 생략 금지, 예고 방향 고정, 정지·선택창의 시계 동결, 안전 통로, 폭탄 우회 금지, 낙뢰 연타·거리 제한, 드론 관통을 테스트한다. 웹 QA는 별도 `tools/qa/boss_preview.dart` 진입점에서 실제 BattleScreen/Engine/Painter를 사용한다. 높은 선체와 보스 직전 시작은 검증용 fixture이며 정식 `lib/main.dart` 빌드에 포함되지 않는다. 운영 계정이나 클라우드 데이터를 사용하지 않는다.

판정 기준: 통제 실험 40초 이내 완주, 세 단계 노출, 강한 조합의 시간 이점 유지, 기존 전체 챕터 완주 회귀 없음. 강한 계정끼리는 약 6.6초 하한에 모이는 절충이 있다. 다음 실제 플레이에서는 예고 이해도, 격벽 대기 체감, 기본 조합의 20초 안팎 전투가 지루한지 확인한다. 최소 지원 모바일 기기 FPS와 이용자 난이도 평가는 이번 자동 검증 범위 밖이다.

## v4.5 개정 (2026-10-15, 아래 과거 규칙보다 우선)

- 현재 주포는 수직 전방 사격이다. 주포 EVO는 삼중 탄막에 사거리 520의 관통 레이저(기본 피해 70, 기본 주기 0.9초)를 추가한다. 로켓 EVO는 살아 있는 목표를 유지하고 목표가 사라지면 재탐색한다.
- 선택 카드에 진화 재료와 보유 상태를 표시한다. 출격당 재추첨 3회, 보조 슬롯이 6개 차면 필요한 진화 재료로 교체 1회가 가능하다. 교체는 해당 레벨업 선택을 사용하고 제거한 보조의 모든 레벨을 잃는다. 가능한 진화가 둘 이상인 보스 상자는 무료 진화 선택창을 연다.
- Lv.12까지 최초 후보 생성은 보유 무기 강화를 최소 하나 포함한다. Lv.6/9에는 가능한 누락 진화 재료를 우선 포함한다. 재추첨은 기존 후보 제외를 우선하므로 같은 보장을 반복하지 않을 수 있다.
- 플라스마 장판은 여러 장이 겹쳐도 적 하나에 0.4초당 한 번 피해를 준다. 낙뢰는 이미 죽은 적을 다시 타격하지 않는다. 수호자 Lv.3 이상 방패는 3초 주기 중 기본 1.8초 활성화되며 지속 시간 보조로 최대 3초가 된다.
- 보스 체력은 `650 + 챕터인덱스*240 + 등장차수*300`(도전 배율 별도). 체력 65%/30%에서 패턴 단계가 바뀌며 전환 시 공격 유예를 둔다. 챕터 시간은 보스전 중 멈추고, 실제 전투 시간은 계속 흐른다. 선택·정지 중에는 둘 다 멈춘다.
- 엔진은 첫 진화 시점과 무기별 유효 피해(남은 체력을 넘는 피해 제외)를 기록한다. EVO 로켓의 직접 피해는 `missile-evo`, 폭발은 `missile`로 기록되므로 집계 시 합산한다.
- 보상은 [CONTENT.md](CONTENT.md)의 v4.5 규칙을 따른다. 기존 저장 버전 4를 유지하며 실제 계정 저장을 초기화하지 않는다.

적·탄환 상한 검증과 웹 화면 검증은 수행하지만 모바일 실기기 FPS나 이용자 난이도 검증을 대신하지 않는다. 변경 전 소스는 `.local/balance-before-20261015`에 보관했다.

## 전장과 출격

- 월드 1800×2400, 가시 영역 논리 좌표 420×720. 이동에 따라 카메라가 추적하며 세계 경계에서는 카메라가 멈춘다.
- 주포 하나로 출발. 전방위 가장 가까운 적을 자동 조준한다.
- 챕터 600 / 900 / 900초. 보스는 전체 시간의 1/3, 2/3, 3/3 각각 12초 전에 출현. 앞 보스가 살아 있으면 다음 보스가 기다린다. 세 보스와 생존 시간 모두 충족해야 승리한다.
- 45초 훈련은 29초에 보스 1회. 보상·해금·전적 변화 없음.
- 군집은 한 번에 여러 개체가 가시 영역 가장자리 밖에서 등장. 일반 적 상한 220, 보스 포함 221. 650 이상 뒤처진 일반 적은 화면 밖으로 재배치. 보스는 재배치하지 않는다.
- 일반 추격기, 고속 측면 이동기, 정예. 보스는 챕터와 등장 차수에 따라 방사형 탄막·조준 부채꼴·예고 후 돌진의 세 패턴을 순환한다. 스테이지 2·3은 기존의 세로 위험 영역·고리 위험 영역을 유지한다.

## 성장

무기 후보 8종과 보조 후보 8종. 장착은 각각 6종 제한. 신규 스킬은 슬롯이 남아 있을 때만 선택지에 나오며, 장착한 스킬은 계속 강화 가능. 무기·보조 5단계. EVO는 추가 선택으로 발동하며 무기 슬롯을 더 차지하지 않는다.

| 무기 | 보조 조건 | EVO 변화 |
|---|---|---|
| 펄스 블래스터 | 고밀도 탄약 | 삼중 탄막 |
| 추적 로켓 | 고출력 연료 | 4발 추적 폭격 |
| 요격 드론 | 에너지 큐브 | 사격 간격 55% 추가 감소 |
| 광자 수레바퀴 | 추진 부스터 | 12방향 탄환 |
| 중력 지뢰 | 장갑 증폭기 | 설치 간격 1.7→0.65초 |
| 플라스마 장판 | 회수 자기장 | 기본 반경 28→65 |
| 궤도 수호자 | 지속 전지 | 기본 반경 62→95 |
| 이온 낙뢰 | 전술 기록기 | 한 번에 12회 타격 |

첫 성장 경험치18. 다음은 `18 + level*10 + max(0,level-8)^2*1.5`. 성장 선택 사이 최소8초 교전하며 초과 경험치는 보관한다. 보조 스킬로 피해·범위·쿨다운·속도·선체·수집·지속 시간·경험치를 강화한다. 소모된 선택지는 다시 나오지 않고, 더 이상 강화가 없을 때 회복 선택을 제공한다.

장판은 첫 접촉 후 사라지지 않고 0.4초 간격으로 범위 내 여러 적에게 피해. 수호자는 주변 적 밀어내기와 3단계 이상 탄환 제거. 보스 보급은 가능한 EVO를 우선 지급하고, 없으면 장착 무기 강화 또는 회복.

## 보급과 성능 경계

27초에 첫 일반 보급, 이후36초 간격(일반 생성은 전체 보급4개 미만). 회복20%, 자석은320 이내 바닥 경험치만 회수, 폭탄은220 이내 일반 적240 피해·보스 최대 체력2.5% 기본 피해(격벽 판정 적용). 자석은45초부터60초 간격으로 미회수1개까지 별도 생성하며 R/P/N은24초부터30초 간격으로 미회수2개까지 생성한다. 보급은120~165 거리의 우회 지점에 나타난다. 보스 처치 위치에 보급 상자 추가.

투사체는 수명 또는 플레이어 거리 1000 이상에서 제거. 입자 최대 161. 경험치 결정1400 초과 시 오래된 보석을 같은 위치의 고가치 보석으로 합쳐 개체 수를 제한한다. 회수하지 않은 경험치를 자동 지급하지 않는다.

## 메타 성장

- 15초 미만·0격파 귀환은 보상과 출격 횟수 증가 없음.
- 30초·10격파 이상이면 설계도 1(승리 시 총 3), 장비 부품 1(승리 시 2). 부품 슬롯은 출격 횟수로 순환한다.
- 장비 6슬롯: 앞 3슬롯 화력, 뒤 3슬롯 선체. 강화 20단계, 합성 5등급. 장비 강화에는 크레딧+설계도, 합성에는 슬롯별 부품을 소모한다. 현재는 개별 장비 인벤토리가 아닌 슬롯별 합성이다.
- 챕터 클리어 후 도전 가능. 군집 수 +2/스폰, 보스 HP +40%, 첫 도전 클리어 설계도 +5. 도전 보상은 일반 챕터 해금을 대신하지 않는다.
- 누적 100격파·3출격·첫 클리어·장비 강화 5회의 임무. 각 100크레딧+설계도 3, 1회 수령.
