# V10 전체 플레이 그래픽 통일 — 웹 반영·검증 완료

2026-10-18 후속 사용자 승인으로 **v10.0.0+16을 공개 웹테스트에 배포**했다. 로비 하단 버전·새 배포·최신 재검증과 공개 Access 인증 제한은 `WEB_RELEASE_V10.md`에 기록한다. 아래의 "운영 배포는 하지 않는다"와 새벽 로컬 주소/해시는 당시 작업 범위 및 역사적 결과다. 이후 패치는 `AGENTS.md`와 `WEB_RELEASE_VERSIONING.md`를 따른다. Android APK 빌드 금지는 유지한다.

사용자 지시: 로비 한 장으로 범위를 제한하지 않는다. **라인이 굵은 아기자기하고 캐주얼한 메카닉 디자인**을 로비·전투·성장·보급·장비·펫·스킬·보상과 나머지 콘텐츠 화면에 적용한다. 기존 저장/ID/게임 수치 유지, 목록 밖 스크롤 금지, 모바일 320/360/390/430와 글자 130%의 실제 웹 검증을 유지한다. Android APK와 운영 배포는 하지 않는다.

## 연결 구조

- `GameArt`가 전투와 모든 콘텐츠 그림의 공통 주소를 정의한다. 새 PNG는 `assets/art/game_v10/`, 기존 V9의 독립 기체/메뉴 PNG는 `assets/art/lobby_v9/`를 공유한다. 모든 파일은 독립 생성물이다. 원작 자산은 복사하지 않았다.
- `RasterAssets.load`는 V9+V10을 로드하고 이전 V6/V7 아틀라스를 로드하지 않는다. V8 이름을 참조하던 메뉴는 새 공유 자산으로 연결된다. `ArcadeAircraft`가 사용하는 기체도 로비와 같은 실제 이미지 인스턴스다.
- 전투는 새 기체·적·보스·펫·탄환·효과를 사용한다. 기존 흐릿한 도시 아틀라스와 사실적 구름/안개를 제거한다. 배경은 세계별 단순한 색면과 독립 AI 소품, 도시/산업 구간의 넓은 도로로 구성한다. 열 세계의 이름/순서/규칙은 유지한다.
- 지면의 반복 반사와 소품의 방향을 분리한다. 반복 바닥 타일이 뒤집혀도 건물/소품 그림은 똑바로 서 있도록 보정하며, 가장자리 클립은 안티앨리어싱 틈을 만들지 않는다. 소품은 90px·불투명도 52%로 전투 오브젝트보다 조용하게 표현한다.
- 빔과 버튼/패널은 길이 변화가 필요한 연속 도색 경로를 사용한다. PNG 늘이기/9조각 접합/아틀라스 격자 추출은 하지 않는다.
- HUD는 굵은 외곽의 프레임, 큰 체력/경험치 막대, 정사각형 무기/보조 12셀로 구성한다. 글자 축소를 하지 않는다. 충돌/공격/보상 수치는 유지한다.
- HUD와 웨이브 안내의 실제 높이를 먼저 배치한 뒤 남은 영역을 전장으로 사용한다. 기체/적/보스가 상단 패널 밑에 가려지는 것을 막고 터치 좌표도 전장 내부를 기준으로 처리한다. 일시정지/선택/결과는 전체 화면 위에 표시한다. 웨이브 안내에 고정된 top 좌표를 사용하지 않는다.
- 장비·펫·도감·보상은 같은 ID를 같은 그림으로 연결한다. 펫 보상도 실제 종류를 표시한다. 보급 카드는 큰 그림 상자로 제목을 밀어내던 배치를 줄이고 조건을 구절 단위로 배치한다.

## 생성과 검사

내장 `image_gen`을 사용하며 별도 유료 API 키/CLI를 사용하지 않는다. 새 묶음은 PNG 51장(일반 적11, 보스10, 펫3, 장비6, 스킬/투사체/효과/드롭/소품/배경21)이며, 전체가 갖춰지지 않으면 런타임이 완료 묶음으로 취급하지 않는다.

`assets/art/game_v10/generation.json`에 채택한 원본 경로와 전체 프롬프트가 있다. 원본 바이트를 그대로 복사한다. 처음 생성한 기뢰형 적은 그림이 캔버스 가장자리에 닿아 재생성했다. `audit_game_art.py`는 실제 알파와 최소 24px 안전 여백, 원본 바이트 일치를 검사한다. 일부 생성물의 최대 알파는 254이며 정상적인 투명 PNG로 취급한다. 렌더 단계에서 미세한 알파 잔여값을 제거하며 원본 파일은 수정하지 않는다.

글자 확대는 실제 Flutter `TextScaler.linear(1.3)`으로 검증했다. 목록 외 화면은 휠·터치 후 위치가 고정되고 큰 내용은 페이지 버튼으로 이동한다. 목록은 항목만 스크롤하고 제목/분류는 고정한다. 사용자 브라우저 저장소에 연결하거나 지우지 않았으며, 독립 게스트에서 실제 보급으로 얻은 장비 ID·장착·편성·진행을 재로드하여 비교했다. 계정/길드의 온라인 전송은 로컬 API 스텁이며 운영 서버 검증을 의미하지 않는다.

기능 회귀 후 마지막 하단 탭 외곽선을 연속 도색으로 정리했다. 66개 Dart 파일의 해시 스냅샷에서 달라진 파일은 이 도색을 가진 `arcade_home_widgets.dart` 하나뿐이다. 그 최종 빌드에서 실제 출격, 전체 메뉴/보급/보상, 길드/편성/연구/챕터를 각각 8조건씩 다시 검증했다. 최종 런타임 해시는 이 마지막 빌드 기준이다. 오래된 `failure*` 파일은 수정 전 진단 자료이며 최종 통과 캡처 수에서 제외한다.

보스·스킬 선택·99,999 선체·열 세계 배치 이미지는 명시적인 렌더 픽스처이며 실제 승리/획득으로 보고하지 않는다. `actual-battle-*` 및 `actual-after-touch-*`는 실제 로비에서 실제 엔진으로 출격한 화면이다. 반복 실행이 긴 브라우저 QA는 조건마다 Chrome을 새로 열어 이전 CanvasKit 그래픽 컨텍스트를 남기지 않는다.

실제 과금·광고는 `STORE_RELEASE_CHECKLIST.md`의 출시 전 필수 미완료 게이트로 유지한다.

로컬 웹 서버는 `tools/qa/serve_preview.py`를 사용한다. 동시 모바일 브라우저가 65개 이미지 파일을 요청할 때 연결 대기열이 부족하지 않도록 128로 두고, 브라우저 캐시를 재검증하며 로그를 파일에 남긴다. 운영 서버/계정/저장소를 수정하는 도구가 아니다.
