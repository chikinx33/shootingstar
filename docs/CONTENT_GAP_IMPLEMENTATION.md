# XAPK 비교 후 시스템·콘텐츠 보완 · 2026-10-17

## 자체 규칙과 성장 범위

아래 숫자는 추출한 원작 수치가 아닌 Shootingstar의 시작 규칙이다. 실제 플레이 밸런스가 확정됐다는 의미는 아니다.

- 유물 조사 1회는 획득한 보급권 1장을 쓰고 순환 순서의 유물 조각 3개를 준다. 다음 유물을 화면에 표시한다. 현금 결제나 광고 보상을 가장하지 않는다.
- 유물 복원·강화 비용은 순서대로 조각 1/2/4/6/8개다. 강화 초기화는 발견을 유지하고 실제 사용한 강화 조각만 돌려준다. 조각 1개 분해→가루 1, 선택 조각 1개 제작→가루 3이다.
- 완성된 3종 세트 중 최대 2개를 활성화한다. 개별 최대 효과는 화력 +10%, 선체 +12%, 회수 반경 +15%, 쿨다운 단축 +2%다. 모든 세트 추가 효과를 동시에 적용할 수 없다. 기본 수집 상태가 비어 있으면 기존 전투 성능이 유지된다.
- 수집 효과는 `ContentSystems`의 기존 출격 능력치에 합산되고 `BattleScreen`이 실제 엔진에 전달한다. 격납고 강화를 별도 배율로 복제하지 않는다.
- 주간 목표는 유효 출격 5회·처치 1,200기·보스 3기·진행 1,800초다. 기존 보상 자격 검사 후 기록하며 훈련·중복 정산·접근 불가 항로는 제외한다. 도전은 주간에 집계하지만 일반 항로 최고 진행·클리어 기록을 만들지 않는다.
- 일일 상자는 일일 임무 보상을 1/2/3개 받은 뒤, 주간 상자는 주간 임무 보상을 2/4개 받은 뒤 열린다. 보상은 보급권과 기존 성장 재료를 사용한다. 전체 출석·상자·항로 보상표는 `lib/data/fleet_journal.dart`의 `FleetReward` 상수에서 확인한다.
- 빠른 순찰은 오늘 유효 출격 1회 후 하루 한 번 80C·설계도 2·먹이 10을 지급한다. 기존 30분~8시간 누적 순찰을 소비하지 않는다.
- 영구 연구는 기존 비용 `80 + 현재 단계 × 60`, 단계당 화력 8%·선체 12%·회수 15%를 그대로 사용한다. 새 화폐나 두 번째 강화 계층을 추가하지 않았다.

## 저장과 서버

기존 프로필 버전 4를 유지하고 `content.progressionVersion: 1`, `content.collections`, `content.journal`, 루트 `hangarPresets`를 추가했다. 옛 저장은 빈 수집품·활동·6개 구성으로 읽으며 장비 ID와 기존 진행은 유지한다. 옛 계정 진행으로 교체할 때 새 필드를 초기화해 이전 계정의 보상을 섞지 않는다.

새 보상은 한국 시간 자정, 주간은 월요일 자정에 갱신한다. 기존 단조 증가 시각으로 일반적인 시계 역행을 막는다. 이는 클라이언트 저장 편집이나 임의 미래 시각 조작을 막는 서버 권한 검증이 아니다. 실제 결제·광고와 관련한 서버 지급 검증은 출시 전 필수 작업에 남아 있다.

서버의 `cloud/write`는 저장된 `progressionVersion: 1`을 누락한 구형 클라이언트의 쓰기를 409로 거부하도록 추가했다. 별도 **로컬 D1 DB에서만** 정상 새 저장·구형 쓰기 거부·기존 데이터 유지·새 클라이언트 후속 쓰기를 검사했다. 이 보호 코드는 아직 운영 서버에 배포되지 않았다. 배포 전후를 혼동하지 않는다.
