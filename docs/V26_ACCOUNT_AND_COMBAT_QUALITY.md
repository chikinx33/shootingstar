## 반영한 동작

- 계정에 영구 삭제 경로를 제공한다. 정확한 아이디와 현재 비밀번호를 다시 입력해야 하며 중복 제출/처리 중 뒤로가기를 막는다. 오인 삭제를 줄이기 위해 설명과 취소가 있는 고정 페이지를 사용한다.
- 서버는 세션·요청 제한·비밀번호 verifier를 확인하고 계정/현재 verifier를 조건으로 삭제한다. 기존 외래 키가 세션·진행 저장 이력·길드 가입/개인 보고/보상을 제거한다. 공유 길드와 비개인 집계는 유지한다.
- 성공 응답 뒤 이 기기의 진행·중단 전투·최근 출격 기록·계정/이관 임시 백업을 정리하고 새 게스트로 돌아간다. 잘못된 비밀번호는 데이터를 보존한다. 서버 삭제 확인과 기기 정리 오류를 구분한다. 네트워크에서 응답이 유실되면 서버 결과를 확정할 수 없으므로 성공으로 표시하지 않는다.
- 중단 출격 중 계정 전환/로그아웃을 막고 이어서 정산하거나 포기하도록 이유를 알린다. 영구 진행의 동기화와 같은 기기의 전투 이어하기를 구분한다.
- 저장·복구 도움말에 기기/계정 차이, 복구 코드, 충돌/저장 실패 대응을 제공한다. 진단 정보는 사용자가 직접 복사하며 자동 전송하지 않는다. 닉네임·아이디·비밀번호·토큰·복구 코드·인벤토리는 제외한다.
- 세계 썸네일에 실제 전장의 원본 궤도 배경과 세계별 랜드마크를 크게 합성한다. 작은 칸에서540px 지형을 통째로 축소해 소품이 보이지 않던 문제를 고친다. 새 그림 생성/비용은 없다.
- 광선/검격의 끝에서 큰 적의 중심이 길이 밖에 있어도 선체가 공격 범위에 겹치면 맞는다. 특화의 명중/회복 확인도 같은 함수를 사용한다. 범위를 벗어난 적과 사라진 적은 맞지 않는다. 피해·주기·가격을 일괄 조정하지 않는다.
