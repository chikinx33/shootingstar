# 비행 교전 v6.1.0

2026-10-16: 일반 적기의 접촉 추적을 사격 거리 유지와 선회 교전으로 바꾼다. 직선 충돌을 노리는 적은 별도 돌입 편대로 분리한다. 기존 10개 역할의 번호를 유지하고 `kamikaze`를 마지막에 추가했다. 프로필·재화·장비 저장 형식과 플레이어 무기 수치는 변경하지 않는다.

## 비행

이전 정찰기·장갑기·분열기는 직접 추적했고 모함은 가까워져도 전진했다. 이제 일반 적은 접근 → 사거리에서 선회/측면 사격 → 근접 시 이탈한다. 기체 그림은 실제 비행 방향으로 회전하며, 조준 방향과 구분한다. 위빙기는 좌우 흔들림, 궤도기는 빠른 선회, 중장갑·모함은 느린 측면 이동을 한다.

기본 교전 거리는 아래 표를 사용한다. 세로 화면의 좌우 경계·HUD에 가려진 곳을 계속 돌지 않도록 화면 크기와 현재 방위에 따라 거리를 줄인다. 좌우는 중앙에서 174, 위쪽은 화면 중앙에서 HUD 여유 180을 뺀 범위를 사용하며 최소 목표 거리는 130이다. 현재 거리가 목표보다 35 이상 작으면 후퇴한다. 75 이내에서는 발사 준비 중에도 긴급 이탈한다. 플레이어가 추격해 실제 충돌하는 경우 접촉 판정은 유지한다.

| --- | ---: | --- | --- |
| 정찰기 | 175 | 단발 총알 | 5.8 / 0.45 |
| 위빙기 | 200 | 2발 부채꼴 총알 | 5.2 / 0.5 |
| 중장갑기 | 225 | 고폭탄 | 7.5 / 1.0 |
| 포격기 | 245 | 곡사 유탄 | 7.0 / 1.0 |
| 창형 요격기 | 215 | 미사일 | 8.0 / 1.0 |
| 궤도기 | 220 | 유도 에너지탄 | 6.5 / 0.75 |
| 기뢰기 | 230 | 지연 기뢰 | 7.5 / 0.7 |

간격은 준비 시간을 포함한 발사 주기이며 실제 재장전에는 0~0.9초 분산을 더한다. 최초 공격도 2.5~4.5초로 분산한다. 일반 적은 화면의 전투 영역 안, 플레이어와 85~460 거리에서만 무장을 발사한다. 군집이 커져도 무조건 탄막을 늘리지 않는다. 일반 적탄 예산은 `44+세계×4+소항로`, 최대 90이다. 유도 에너지탄 6개·미사일 5개·고폭탄/유탄 합계 6개·레이저 2개·기뢰 10개 상한을 따로 적용한다. 보스의 기존 발사 패턴은 유지한다.

## 돌입 편대

v10.0.7에서 돌입을 갱신했다. 첫 편대18초, 이후 기본34초/교차 비행 구간22초 간격과 세계별4~6기를 유지한다. 1.25초 진입 후1초 동안 두 직선 항로를 점선으로 예고하고 속도220으로 돌진한다. 좌우 항로 간격140, 같은 항로의 앞뒤 간격32이며 생성 순간의 목표를 고정한다. 예고 중 접촉 피해가 없고 돌진 중에는 상태 둔화가 적용된다. 중앙 또는 항로 밖으로 이동하거나 격추해 대응한다. 충돌·이탈에는 무료 격파 보상/경험치가 없다. 보스 임박·액터 상한·다른 구조화 편대 교전 중에는 생성을 미룬다.

## 방패·중장 편대

v10.0.7: 기존 일렬/펼침 편대 순환에 방패 호위2기+중장1기를 추가했다. 정면 주무기 피해는 방패 호위45%, 호위가 보호하는 중장70%로 적용한다. 측면·재정비 시간·호위 격추/분리, 보조 무기와 공용 궁극기에 대응 기회가 있다. 무적이나 추가 체력은 주지 않는다. 최초 정상 출현은48초이며 보스/편대 중복 조건에 따라 연기할 수 있다. 자체 수치·방호 판정·단계별 규칙과 검증 증거는 `WING_PHASE6_IMPLEMENTATION.md`를 따른다. 아래 v6.1 검증은 당시 기록이다.

## 무장과 회피

- 총알: 속도 135, 6 피해. 현재 위치를 조준한 직선탄이므로 측면 이동으로 피한다.
- 고폭탄: 속도 145, 착탄 반경 46, 12 피해. 준비 시작에 착탄점을 고정하고 지점 표시를 유지한다.
- 곡사 유탄: 비행 시간 1.25초, 착탄 반경 38, 10 피해. 이미지 높이만 포물선으로 표현하고 표시한 지점에 착탄한다.
- 유도 에너지탄: 속도 140, 8 피해. 첫 1.05초만 초당 최대 1.25라디안으로 선회한 뒤 직진한다.
- 미사일: 속도 180, 10 피해, 폭발 반경 30. 첫 1.7초만 초당 최대 0.85라디안으로 선회한다.
- 레이저: 1.3초간 방향을 고정해 예고하고 길이 460·반폭 7의 광선을 0.38초 표시한다. 한 발당 12 피해를 한 번만 처리하며 플레이어가 광선 밖으로 피할 수 있다.
- 가디언·방어 펫은 총알·유도탄·미사일·비행 중 고폭탄을 막는다. 곡사 유탄·레이저·지뢰는 이동으로 대응한다. 모든 적 무장 종류를 보스 전환 시 정리한다.

적탄의 종류 19~24는 플레이어 무기의 적 피격 처리로 흘러가지 않도록 분기한다. 폭발 피해와 이미지 잔상을 분리해 중복 피해를 방지했다. 조준 예고·공격 쿨다운·탄 비행은 일시정지와 성장 선택 중에 정지한다.

## 검증

`test/enemy_flight_test.dart`는 일반 적 10종의 사거리 정착·근접 이탈, 적탄의 아군 오인 판정 방지, 유도 제한, 착탄점 고정과 회피, 레이저 예고·재장전·일시정지, 편대 직선 간격·보상 없는 이탈, 보스 전환·방어막 요격을 검사한다.

`tools/qa/flight_preview.dart`는 실제 엔진과 전투 화면을 사용하는 별도 시각 검증 진입점이다. 높은 체력·주입된 적 배치를 사용하므로 자연 플레이 완주 증거가 아니다. 일반 적 10종, 돌입 편대, 혼합 무장을 분리해서 관찰하며 정식 배포에는 포함하지 않는다. 증거는 `tools/qa/evidence/flight-v6.1/`에 보관한다. 변경 전 소스는 `.local/flight-before-20261016`에 보관했다.

최종 검사: Flutter 111개 통과, 정적 분석 문제 없음. 웹 12개 시나리오에서 일반 기체의 접근·선회·거리 유지와 각 역할의 실제 적탄 종류를 관찰했고 예외는 없었다. 정식 웹에서도 신규 게스트의 설정·출격·이동·일시정지·귀환을 확인했다. `build-hashes.json`은 프로필과 플레이어 무기/고유 능력 소스가 변경 전과 동일함을 기록한다.

기존 자동 조작 시뮬레이션은 새 적탄을 직접 피하지 않는 정책이다. 첫 항로에서 초기/성장 계정의 원형 회피 정책은 각각 3시드 중 2시드 완주, 정지·수집 정책은 모두 미완주였다. 인간 플레이나 전체 100항로 승률을 뜻하지 않는다. 100항로의 필수 보스/단계 전환은 별도 구조 검사로 통과했다. 거리 유지로 근접 무장의 용도가 달라지므로 기존 무기 실행 검사는 45·130·215 거리의 고정 표적에서 실제 피해가 발생하는지를 확인하도록 조정했다.
