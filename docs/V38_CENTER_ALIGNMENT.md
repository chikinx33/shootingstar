# v10.0.38 공통 가운데 정렬

사용자 요청: 제목·버튼 등을 모든 항목에 공통으로 가운데 정렬한다.

## 적용

- 공통 UI의 제목·설명·상태·버튼·입력 텍스트를 `TextAlign.center`로 명시한다. 텍스트 그룹은 셀/콘텐츠 영역의 중앙을 기준으로 하며 슬롯을 채우는 stretch는 보존한다.
- `GamePages`가 폭이 짧은 자식을 `(부모 폭 - 자식 폭) / 2`에 배치한다. 페이지별 측정·페인트·실제 입력은 같은 offset을 사용한다.
- `GameActionButton`은 실제 도색 버튼을 부모 가운데에 놓고 최대264px/기존72·64px 최소 높이/22·20px 글자를 유지한다.
- CatalogHeader의 제목은 아이콘과 행동48px 공간을 대칭으로 확보한다. 상태 설명은 아래 전체 폭으로 분리해 좁은 화면의 불필요한 줄바꿈과 본문 공간 부족을 줄였다.
- 공통 상세 창과 옵션 헤더도 제목 양옆 공간을 대칭으로 맞췄다. 옵션의 컴파일된 버전과3초 개발자 인증 동작은 유지한다.
- AppBar는 중앙 제목, 입력창은 중앙 입력/떠 있는 라벨을 기본으로 한다. 로비 제목은48px 대칭 조작 영역 사이에 배치한다. 격납고 바로가기는48px 아이콘/툴팁/접근성 이름으로 제공하며 기존 편성 화면에 연결한다.
- 배지/게이지·아이콘의 기능상 상대 위치, 고정 페이지와 반복 목록 구분, 저장·전투·음향은 보존한다. 로비 하단 버전을 되살리지 않는다.
- `tools/center_ui_text.py --check`를 소스 계약에 연결한다. 새 UI 문구가 다시 좌/우 정렬로 추가되는 것을 검사한다.

- 공통 변경의 관련 UI66개 통과: 위 실행의 `related-tests.log`. 320·360·390·430px와 글자1.0/1.3의 실제 도색 버튼/제목 중앙 좌표·페이지 이동·상세 창을 검사했다.
- 로비 제목까지 확장한 뒤 중앙 정렬/공통 규격20개와 전투 흐름1개가 통과했다. 예전 `격납고` 텍스트 탐색1개는 아이콘 변경으로 실패해 tooltip 탐색으로 교정했다. 최종 UI2개/정식 웹 빌드 통과: `.local/quick-web/20261020-132054-095152/report.json`.
- 처음320px 중앙 배치 테스트는 다음 페이지의 버튼을 바로 찾으려 해 실패했으며 실제 페이지 이동으로 찾도록 고쳤다. 개발자 도감은 중앙 제목의 좁아진 상태 문구 때문에 본문이112px 아이콘보다 작아져 실패했으며 상태 문구를 헤더 전체 폭으로 분리해 해결했다. 실패를 skip하거나 글자/그림을 축소하지 않았다.
- 별도 확대 렌더 QA의 O2 컴파일은 Dart3.13.4 SDK 내부 타입 추론 오류로 실패했다. QA 진입점만 O0로 컴파일해 확인한다. 정식 앱은 O2로 정상 빌드됐으며 배포에 QA 진입점이나 설정을 넣지 않는다.
- QA는 API에 접근하지 않는 Profile이므로 계정 이동 후 입력창을 기대했던 첫 자동화는 준비 안내 화면을 확인하도록 교정했다. 실제 계정 생성/로그인/외부 쓰기는 수행하지 않는다.
