## 렌더링과 화면 변경

`lib/art/toon_assets.dart`가 아틀라스를 한 번 디코딩해 공유한다. `RasterAssets.load()`는 새 그림을 우선 연결하고 정상 앱은 로딩 완료 뒤 실행한다. 기체·적·보스·세계의 기존 경로는 로드된 PNG를 선택한다. 이전 도형 코드는 로딩 전 위젯 환경용 대체 경로로 남아 있으며 정상 웹 화면의 주 비주얼로 사용하지 않는다.

카드와 버튼은 생성된 패널의 아홉 영역을 나누어 그려 모서리를 유지한다. 이는 SVG나 도형 패널로 이미지를 대체하는 방식이 아니라 생성 PNG를 크기에 맞게 샘플링하는 처리다. 등급 프레임은 생성된 프레임과 등급 색을 사용한다. 장비 아이콘은 부위만 반복하지 않고 실제 장비 종류 ID를 반영한다. 넓은 모바일 화면의 인벤토리는 4열, 작은 화면은 3열을 사용한다.

홈은 주황 패턴·생성 비행장·큰 기체·그림 탭으로 바꿨다. 상단 자원 영역은 짙게 유지하고, 전장 배경은 상대적으로 차분하게 두어 아군의 청록색·적의 붉은 탄환이 구분되도록 했다. 한글·가격·진행·수령 상태·버튼 동작은 이미지에 굽지 않고 실제 Flutter UI로 유지한다. 닫기·뒤로·체크 같은 기본 조작 기호, 게이지와 공격 범위는 조작과 피격 가독성을 위해 코드로 유지한다.

새 그림의 전장·크기·좌표는 기존 렌더링 인터페이스를 사용한다. 충돌 반경·무기 성능·이동·적 AI·보스 패턴·저장 스키마·재화·과금/광고 상태는 바꾸지 않았다. 전투 그림은 기존 렌더 크기를 사용하며 충돌 판정 수치는 변경하지 않았다.

아틀라스 9장의 PNG 합계는 약 18.5MB(10진), 디코딩 픽셀은 약 54MiB다. 실제 GPU/엔진 메모리 전체를 뜻하지 않는다. 원본 파일과 기존 아트는 보존했고, 작업 전 소스는 `.local/ai-toon-before-20261017/`에 별도 복사했다.
