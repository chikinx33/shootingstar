## 압박 예산과 휴지

- 편대 교전 중 일반 적 보충량을0.7배로 한다. 소수 잔여값을 기존 누적 계산에 합쳐 임의로 버리지 않는다. 이미 살아 있는 적과 적탄을 지우지 않는다.
- 일반 생성은 구간별 전체 적 수 기준 A60/B92/C112/D120/E148/F80에 도달하면 멈춘다. 세계 인덱스×4 + 항로 인덱스×2 + 기존 도전12를 더하고 일일 도전 밀도 배율을 곱한다. 범위24~254로 제한해 전체260 상한 안에 편대용6자리를 남긴다. 기존 증원은 전체260 상한을 사용하므로 혼잡하면 편대가 연기될 수 있다. 보스는 일반 생성 예산으로 생략되지 않는다.
- 새 편대 사이 최소 생성 간격: 일렬/펼침 뒤9.5초, 돌입 뒤9초, 방패 뒤11.3초. 기준 시점은 생성이며 조기 격추해도 바로 다음 편대를 쏟지 않는다. 정상 수명 뒤 약2.3~2.5초 휴지가 있고 실제 격추/지연으로 간격이 더 길어질 수 있다.
- 매 보스 전 마지막10% 구간과 최소9초 전에는 새 편대를 막는다. 기존 편대는 기존 종료 시각까지 진행한다. 보스 격파 후에도5초 동안 새 편대 진입을 막는다. 일반 생성의 기존2초 재개 대기는 유지한다.

고정된 항로·현재 구간·현재 액터 수만 사용하며 플레이어 HP/과금/숙련도를 읽어 몰래 난도를 바꾸지 않는다. 스크립트상의 위협 조합·보충량을 제한하는 규칙이며 실기기 FPS를 보장하지 않는다. 피해·보상·성장을 프레임 상황에 따라 생략하지 않는다.
