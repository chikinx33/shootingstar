## v10.0.26에서 구현한 기반과 남은 외부 정보

현재 비밀번호 재확인을 요구하는 앱 내 계정 삭제, 서버 계정/세션/저장 이력/길드 개인 기록의 외래 키 삭제, 이 기기의 진행/중단 전투/출격 기록/임시 백업 정리, 기기·클라우드 저장 차이와 직접 복사하는 진단 안내를 구현했다. 격리된 로컬 D1에서 삭제와 두 세션 무효화를 검증했다. 실제 운영 계정을 테스트로 삭제하지 않았다.

공유 길드의 집계값은 유지하며 다른 기기에 남은 로컬 데이터는 그 기기에서 삭제해야 한다. 요청 제한 버킷은 기존 만료 정리 규칙을 따른다. 외부 삭제 요청 URL, 지원 연락처, 정책 문구와 실제 업무 처리는 아직 확정되지 않았다. 법적/스토어 준수 완료를 뜻하지 않는다.

실제 상품/광고 ID, 게시자·지원 연락처/정책, Console 소유와 서명은 아직 없다. 승인된 모델 이외의 상품이나 예제 ID를 운영 확정 자료로 사용하지 않는다. 비밀 키를 채팅으로 요청하지 않는다.
