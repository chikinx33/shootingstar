## 공용 궁극기 초기 규칙

기본 파일럿 `common`에만 적용한다. 시작 충전 0, 실제 전투 시간 초당 5, 최대 100의 한 번 사용분이다. 정지·선택·종료 상태에서 충전과 발사 시간이 흐르지 않고 사용도 할 수 없다. 2초 발사 중에는 재충전하지 않는다. 다음 출격에서는 초기화한다.

발사 시 현재 기체 위치의 앞쪽 520, 좌우 70 범위에 즉시 한 번과 0.5/1.0/1.5초에 총 4회 공격한다. 매회 기본 피해 `45 × damageFactor`이며 기존 치명타·보스 피해 제한·처치 보상·통계를 공통 경로로 처리한다. 범위는 기체 이동을 따른다. 동일한 전방 범위의 요격 가능한 적 탄환(4/19/20/21)을 발사 중 제거한다. 뒤/옆 탄환, 유탄·레이저·폭발·지뢰는 제거하지 않는다. HP·보호막·무적 시간을 바꾸지 않는다.

실제 발사·피해는 `lib/game/common_ultimate.dart`, 기존 전투 갱신·피해 기록은 `engine.dart`, 버튼/Space는 `lib/ui/battle.dart`, 기존 렌더러를 사용한 전방 효과는 `battle_painter.dart`에 연결했다. 72px 주요 행동 버튼과 충전/발사 상태 접근성 이름을 사용한다.

## 방패 역습 초기 규칙

- 필요: 보유 `guardian` 3단계 이상 + `armor` 1단계 이상 + 현재 방호 태그. 주포/파일럿 제한 없음.
- 기존 수호자의 차단 타이밍·범위를 유지한다. 수명이 남고 피해가 양수인 요격 가능 적 탄환을 실제 제거한 경우에만 발동한다. 같은 차단 처리에서 여러 발을 제거해도 한 번이다.
- **3초 내 다음 주포 공격 한 번의 피해 +50%**, 재발동 간격 **4초**, 중첩·시간 갱신 없음. 전투 시간 기준이므로 정지/선택에서는 남은 시간이 보존된다.
- N으로 여러 발을 쏘는 주포는 한 번의 전체 발사 묶음이 강화된다. 주포 10종의 기존 투사체·직접 피해 경로에 연결했다. 표적 전용 주포가 표적 없이 아무것도 발사/타격하지 못했다면 장전을 소비하지 않는다. 3초가 지나면 사라진다.
- 기존 진화 펄스의 별도 자동 빔·보조 무기에는 배율을 부여하지 않는다. 강화된 본탄의 기존 가지 효과는 본탄 피해를 정상 상속하며 재귀 발동을 추가하지 않는다.
- 펫 요격, 항성포 탄막 정리, 아군탄·만료탄·피해 0 탄환, 요격 불가 유탄/레이저는 방패 역습을 발동하지 않는다.

`weapon_synergies.dart`의 기존 레시피에 단계별 최소 조건과 공통 주포 조건을 확장했다. 두 시너지가 준비되면 HUD에 두 줄을 모두 표시한다. 성장 카드의 수호자/반응 장갑 설명에도 조합을 안내한다.
