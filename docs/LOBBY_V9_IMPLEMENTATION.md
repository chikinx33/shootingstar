# 메인 로비 V9 — 굵은 선의 캐주얼 메카닉

사용자 확정 문구: **라인이 굵은 아기자기하고 캐주얼한 메카닉 디자인**.

## 원본 비교와 변경 범위

`F:\NKW\App\PuzzleKnight\work\UI 샘플 1\추가 메뉴.jpg`의 메뉴 뒤 로비와 `보관함 - 장비.jpg`를 직접 확인했다. 원본의 단순한 주황 바탕, 굵은 검정 외곽선, 큰 대표 캐릭터, 양옆 바로가기, 노란 주요 행동을 참고했다. 원본 로비는 메뉴로 일부 가려진 상태이며 원본 자산은 사용하지 않았다.

V8의 복잡한 공중 격납고·날카로운 기체를 메인에서 교체했다. 배경은 기어/도트가 있는 비어 있는 주황 바탕, 기체는 큰 캐노피와 짧은 날개·둥근 엔진의 SD 형태다. 오로라/벡터/모노리스의 선택값은 기존 ID를 그대로 사용한다. 변경한 그림은 로비 전용이며 전투·성장·보급 본문 전체를 이번 작업에서 다시 그렸다는 의미는 아니다. 공용 상단 재화와 하단 탭은 새 로비 아이콘/색상으로 연결된다.

## 그래픽 규칙

- 큰 실루엣과 색면으로 읽히는 장난감 같은 기계 형태를 사용한다. 실사 금속, 촘촘한 패널선, 작은 볼트와 강한 원근 배경을 금지한다.
- 기본 배색은 주황/노랑, 아이보리/파랑이며 테두리는 검정에 가깝게 통일한다. 새 생성물에는 일부 부드러운 음영이 남아 있으며 완전한 2색 양자화 그림이라고 주장하지 않는다.
- 배경 1장, 기체 3장, 기능/내비게이션/재화 아이콘 10장: 총 14개의 독립 PNG를 사용한다. 시즌과 보급은 같은 상자 의미의 아이콘을 공유한다.
- `assets/art/lobby_v9/generation.json`에 내장 image_gen 전체 프롬프트와 원본 경로가 있다. 원본 PNG를 바이트 그대로 복사했다. 트로피 첫 생성물은 가장자리 안전 여백 검사에 실패해 재생성했으며 최종본만 앱에 연결했다.
- `audit_lobby_art.py`는 실제 알파, 눈에 보이는 실루엣의 최소 24px 안전 여백, 생성 원본과 해시 일치를 검사한다. 배경만 cover, 나머지는 contain 비율을 유지한다. 격자/아틀라스 분할은 없다.
- 패널/버튼은 PNG를 늘이지 않고 기존 단일 연속 도색 경로에 밝은 노랑과 굵은 외곽을 적용한다. 상단·하단 테두리 외에 내부 접합선은 없다.
- 출격은 `GameActionButton`의 실제 72px 이상 도색, 22px 글자, 36px 아이콘, 최대 264px 폭을 유지한다. 임의 버튼으로 대체하지 않는다.
- 기체 그림만 화면 높이에 따라 줄어든다. 짧은 화면에서는 바로가기 4개를 한 줄에 둔다. 글자 배율을 무시하거나 글자를 축소하지 않는다. 로비 전체는 스크롤하지 않는다.

## 검증 근거

최종 결과와 실제 캡처는 `tools/qa/evidence/lobby-v9/`에 기록한다. 320×568, 360×640, 390×844, 430×932 각각 Flutter TextScaler 1.0/1.3을 적용한다. 브라우저 페이지 줌이 아니다.

`lobby-v9.cjs`는 새 격리 Chrome 컨텍스트에서 실제 UI로 장비 ID를 획득한 저장을 만든 뒤, 기존 편성/장비/재화/선택값을 가진 상태를 새로고침한다. 로비의 휠과 터치 드래그 전후 조작부 좌표, 스크롤 뷰포트 부재, 모든 바로가기/하단 탭의 진입과 읽기 전용 진행 보존을 검사한다. 사용자 브라우저 저장에 연결하거나 초기화하지 않는다.

초기 검증의 320px 화면에서는 중앙 기체가 너무 작아 보여 배치를 다시 수정했다. 최종 모바일 조건에서는 기체의 실제 그림 영역도 최소 110px 이상인지 검사한다. 노치 안전 영역은 기존 Flutter 고정 로비 테스트에 포함된다. 로딩 HTML과 파비콘도 같은 새 기체로 교체했다.

반복 새로고침을 많이 수행하는 한 Chrome 프로세스에서 시작 화면이 끝나지 않는 초기 QA 실행이 있었다. 최종 검증은 각 모바일 조건마다 브라우저 프로세스를 분리하고, 실제 탭/뒤로가기를 사용하며 한 조건 안의 저장 재실행은 유지한다. 초기 실패 로그는 최종 통과 근거로 사용하지 않는다. 이 변경만으로 사용자 환경의 모든 장시간 로딩 문제를 해결했다고 주장하지 않는다.

검증 명령:

```text
python tools/qa/audit_lobby_art.py
python tools/qa/check_ui_contract.py
flutter analyze --no-pub
flutter test --no-pub --reporter expanded
node tools/qa/lobby-v9.cjs
node tools/qa/ui-contract-20261017.cjs
node tools/qa/catalog-fixed-ui-20261017.cjs
```

기술 검증과 미술 평가를 구분한다. 최종 웹 캡처는 기체 실루엣·아이콘 선·배경 시선 분산·버튼 계층을 직접 원본과 비교한다. 테스트 통과는 원작과 화풍이 동일하다는 증명이 아니다.

최종 확인: UI 소스 규격 28파일 통과, Flutter 정적 검사 문제 0, 테스트 240개 통과/경고 0. 로비 8조건, 기존 메뉴·전투 결정 17그룹, 보급·시즌·우편·수집품 8조건을 통과했다. 최종 로비 실제 웹 캡처 18장, 저장 모델 19파일 변경 없음, 두 로컬 서버의 HTML/코드/메타데이터/신규 PNG 36파일이 최종 빌드와 해시가 일치한다. `tools/qa/evidence/lobby-v9/final-validation.json`이 집계 근거다. QA의 API 401 응답은 실제 외부 계정/길드 쓰기를 차단하기 위한 격리 응답이며 렌더/JavaScript 예외와 구분한다.
