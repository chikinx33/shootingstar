# v10.0.27 반복 탄환·결정 렌더 비용 개선

v10.0.26의 CPU4배 감속 후반 부하에서 프레임 간격 p95가150ms였다. 출시 성능 합격으로 처리하지 않고 별도 CPU 프로파일을 수집했다. CanvasKit Paint/색상 필터 생성과 반복 그리기 호출이 상위 비용으로 나타나, 전투 규칙을 바꾸기 전에 그리기 명령 재사용을 적용했다.

## 구현

- 기본 펄스/일반 적탄의 변하지 않는 그림과 꼬리선을 로컬 좌표의 `ui.Picture`로 한 번 기록하고 위치/회전만 적용한다. 기존 그리는 순서를 유지한다.
- 크기·도해 인덱스·꼬리선 색·효과 축소 설정으로 구분한다. 탄환 그림은 합계 최대128개이며 초과 시 오래된 그림을 해제한다. 경험치 결정은 별도1개를 재사용한다. 원본 그림 갱신 시 캐시를 해제한다.
- 기존 `효과 축소` 설정에서는 회전이 없는 다수 결정을128개 단위의 최대12개 필드 그림으로 재사용한다. 회수·새 드롭·위치/가시 영역·원본 갱신 때 변경된 묶음만 다시 기록한다. 원래 순서를 유지하며 임계 수보다 많으면 기존 경로로 전부 그린다. 일반 효과의 회전은 그대로 유지하며 설정을 자동 변경하지 않는다. 캐시는 파생 그림이며 저장 데이터나 획득량을 갖지 않는다.
- 멈춘/느린 탄환, 미사일, 레이저/광역, 수명·예고에 따라 모양이 변하는 탄환은 기존 경로를 쓴다. 그림 준비 전에도 기존 경로를 사용한다.
- 적·탄·결정·피해·충돌·보상·획득량·위험 예고·시간·체크포인트는 바꾸지 않는다. 원본 PNG를 수정하거나 새 아틀라스로 묶지 않는다.

## 검증

전체 Flutter626개 통과. Dart 분석 오류/경고0, 기존 정보20건, UI 소스 계약44파일 통과. 서버 로직은 v10.0.26과 동일하며 그 버전의 격리 서버9개 통합 결과를 참조한다.

`test/projectile_render_cache_test.dart`는 실제 원본 그림을 로드해 기존 경로와 새 경로를 같은 전체 전장에 렌더한다. 여러 방향·크기·친군/적군 색·출력 단계·효과 축소·정지 탄환·미사일/빔·회전 결정을 포함한다. 변환된 끝점의 미세한 AA 차이만 허용하며,8 이상 채널 차이는 전체의0.1% 미만, 평균 절대 채널 차이는0.12 미만이다. 앞서 시도한 다른 일괄 그리기 방식은 이 비교에 실패하여 반영하지 않았다. 통과한 현재 경로의 전투 체크포인트는 그리기 전후 완전히 같다.170개의 다른 크기를 그려도 캐시 상한을 지킨다.

## 웹 부하 비교

v10.0.26과 같은 초기 부하/시드/화면을 데스크톱 headless Chrome에서 측정했다. 아래는 단일 실행의 관측값이며, 다른 빌드/검사는 동시에 실행하지 않았다. 자연 진행이므로 프레임 간격 차이로 이후 전투 상태는 달라질 수 있다.

| 조건 | 이전 프레임 중앙값 / p95 | 새 프레임 중앙값 / p95 |
|---|---|---|
| 정상 CPU·일반 효과 |16.7 /33.4ms |16.7 /16.8ms |
|CPU4배 감속·일반 효과 |100.1 /150ms |66.7 /100.1ms |
|CPU4배 감속·효과 축소 |별도 이전 측정 없음 |50 /66.8ms |

일반 효과의 반복 탄환/결정 캐시 적용 뒤 첫 두 행을 측정했고, 효과 축소 전용 필드 보강은 마지막 행에서 확인했다. 전체 필드 재사용과128개 묶음 재사용의 비교에서는 p95가 모두66.8ms였으며, 묶음 처리의 별도 향상률을 주장하지 않는다. 원래 순서/표시를 유지하면서 새 드롭이 생길 때 변경된 부분만 갱신하는 구조를 남겼다. 효과 축소 결과를 필드 캐시만의 향상률로 해석하지 않는다.

정상 CPU의 p95는33.4→16.8ms로 줄었다. 그러나 감속 조건은 여전히 부드러운30fps를 보장하지 않는다. 이 결과가 실제 휴대폰의 최소 사양/발열/장기간 메모리 검증을 대체하지 않는다. 실제 결제·광고와 운영 외부 정보는 `STORE_RELEASE_CHECKLIST.md`의 미완료 조건을 유지한다.

원문: `tools/qa/evidence/performance-v10.0.27/performance.json`, `performance-reduced.json`; 최종 감속 실행 오류0건, 정상 저장/보상 쓰기 없음, 액터와 체크포인트 크기 한도 유지.
