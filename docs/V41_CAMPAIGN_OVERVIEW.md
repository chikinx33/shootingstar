# v10.0.41 항로 선택 카드 재구성

큰 세계 그림/제목/설명을 세로로 쌓던 목록을 가로형 요약으로 바꿨다. 세계 그림은112px에서56px, 세계 이름20px/완주 수·선택 중·진입 가능·잠금 상태14px를 함께 표시한다. 세계 설명은 펼친 영역에만 둔다.

세계별10항로는 `GameSlotRows`의3열 overview로 재구성했다. `CampaignStageCard`는 번호20px·이름16px·상태14px와 완주/비행/자물쇠 아이콘, 선택 패널을 제공한다. 글자는 줄바꿈하며 카드가 늘어나고 축소/생략하지 않는다. 잠긴 항로는 비활성이고 접근성 문구에는 앞 항로 완주 조건과 시간·보스·위험도까지 유지한다. 상세 공략/환경과 회피/보상/실제 선택 확정은 기존 페이지형 상세를 사용한다. 잠금/진행/저장 수치는 바꾸지 않았다. 세계 목록만 스크롤하고 공통 헤더와 선택 완료는 고정한다.

관련 command/completion/portrait25개가 통과했다. 모바일320·360·390·430px와 글자1.0/1.3에서 항로 상세 접근·선택 저장·잠금과 공략 안내를 검사했다. 정식 빌드와 분석 근거 `.local/quick-web/20261020-133809-968568/report.json`.

실제 정식 웹의390×844·320×568에 세계2 진행 fixture를 주입해3열 배치, 잠긴2-5 비활성, 완료 항로2-3의 상세 메타데이터→선택 확정→선택 완료, selectedStage=12와 기존13개 완주 보존을 확인했다. 목록 이동 중 완료 버튼 고정, 브라우저 예외/넘침0건.390px 첫 행은 각111.3×96px이다.320px 보고서의 높이는 목록에 의해 잘린 semantics 가시 영역이며 실제 전체 도색 높이로 해석하지 않는다. `tools/qa/evidence/campaign-v41/report.json`과 PNG2장.

최초 브라우저 도구는 bottom sheet의 등장 중 좌표를 잡아 버튼 이동으로 판단했고, 상세 종료 중에는 하위 페이지의 버튼을 찾으려 했다. 등장 안정과 상세의 실제 제거를 기다리도록 도구를 교정했으며 제품 코드를 변경하거나 통과 검사를 반복 빌드하지 않았다. 실제 계정/사용자 저장소에 쓰지 않았다.
