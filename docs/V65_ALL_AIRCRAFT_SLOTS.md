# v10.0.65 전체 슬롯 표시와 겹친 슬롯 선택

- 눈 ON에서 장비/무장/지원의 모든 장착부를 함께 표시한다. 슬롯 분류 메뉴를 제거한다.
- v64의 실제 장착 사각형과 AssemblyViewport 변환을 그대로 사용한다. 눈 전환으로 기체 위치/배율/구성이 바뀌지 않는다.
- 실제 부품 사각형이 같은 경우 테두리를 한 번 칠하고 공유하는 논리 슬롯 수를 표시한다. 주무장/주포, 선체/장갑처럼 다른 기능의 선택을 합치거나 제거하지 않는다.
- 48px 이상의 중심 터치 영역에 들어온 후보를 가까운 순서로 보여준다. 후보가 하나면 보유 목록, 둘 이상이면 슬롯 선택 팝업을 연다. 그림·슬롯 이름·장비/무장/지원 역할을 함께 표시한다. 슬롯을 고르면 기존 보유 목록→특성→장착 흐름으로 이어진다.
- 양쪽 날개/장갑/엔진은 논리 슬롯 ID로 후보를 중복 제거한다. 접근성으로 슬롯을 누를 때도 동일한 선택 규칙을 사용한다.
- 빈 선택 부위의+표시, 아이템 비교, 장착/지원 이동/저장과 한국어/영어 모드를 유지한다. 후보 선택/취소 자체는 프로필을 변경하지 않는다. 재부팅 전 수정과 관련320px 위젯 검사 통과 결과를 확인하고 작업을 이어갔다.
- 로비는 스크롤하지 않는다. 겹친 후보/보유 장비의 반복 목록만 공통 GameSlotList를 사용한다. Android APK를 빌드하지 않는다.

관련 검증은 test/lobby_aircraft_test.dart의320px 조건에서 전체 슬롯의 실제 부품 사각형 일치, 분류 메뉴 부재, 겹친 주무장/주포 선택과 취소, 날개 목록, 지원 이동/저장, 눈 OFF를 확인했다. 실제 웹 확인은 기존 quick-smoke의 선택적 슬롯 흐름에 통합한다.

최종 검증: 정식 웹 빌드 완료 후320px 슬롯/후보 선택/실제 장비 장착/가이드/출격/일시정지를 확인했다. 첫 웹 검사는 눈 버튼 전환 후 의미 구조 갱신을 기다리기 전에 개수를 확인해 실패했다. 해당 자동화 대기만 수정하고 동일 빌드를 재사용해 통과했다. 새 QA 빌드/전체 회귀는 실행하지 않았다.
