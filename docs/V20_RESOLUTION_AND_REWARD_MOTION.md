# 회수·격파·획득 연출 — v10.0.20

2026-10-19. 실제 상태 전환을 수정했으며 게임/저장 전체를 다시 만들지 않았다.

## 원인과 변경

기존 자석은 XP를 한 번에 더하고 보석을 삭제한 뒤 `_checkLevel()`을 호출했다. 최종 보스는 사망한 프레임에 `finished=true`가 되어 이후 효과 갱신이 멈추고 결과 화면에 가려졌다. 보상은 실제 증가분 팝업이나 텍스트 알림 뒤 곧바로 사라졌다.

| 사건 | 새 흐름 |
|---|---|
| 자석 | 보석마다 기체를 향한 곡선 이동 → 도착할 때 XP 한 번 지급 → 마지막 잔광0.18초 → 성장 선택. 먼 보석은 대응하는 전장 가장자리에서 들어온다. |
| 자석+상자 | 같은 프레임에 잡는 양쪽 순서 모두, 흡수가 끝날 때까지 보스 상자 선택을 기다린다. |
| 성장 선택 | 어두워진 전장 위3열 슬롯과 가능한 재추첨/교체. 진입/선택 확인0.24초 후 적용. 긴 역할/연계 설명은 슬롯을 길게 눌러 게임 테마 상세에서 읽는다. 선택 후 기체에 성장/회복 파동을 연결했다. |
| 보스 파괴 | 전투 시간을 멈추고 흔들림+13회 분산 폭발 →1.9초에 섬광/큰 폭발+같은 원화의12개 독립 파편 →2.55초에 클리어 문구. |
| 중간 보스 | 3.4초 후 기존 상자/다음 웨이브로 복귀. |
| 최종 보스 | 3.65초부터 히어로가 위로 가속/이탈 →5.35초 이후 결과/기존 보상을 한 번 정산. |
| 보상·구매 | 실제 지급 증가분 카드 등장 →닫을 때 같은 코인/보급권/장비/펫/테크 그림 이동 →현재 보이는 실제 재화 카운터/일치 슬롯에 도착 파동/수량. 목적지가 없는 화면은 보관함 수령 표시로 들어간다. |
| 성장·관리 | 장비 강화/합성/정련, 주무기 해금/강화/장착, 연구, 펫 성장/각성, 수집품 강화, 기체 선택/해금, 임무/우편/시즌/보급/교환, 전투 귀환에 공통 성공 피드백을 연결했다. |

일시정지/앱 배경 전환은 연출 시간도 멈춘다. 파괴 중 이동/궁극기 입력을 잠그고 일반 웨이브 안내를 숨긴다. 작은 화면 밖에서 격파한 보스는 은퇴한 배우의 파괴 위치만 보이는 영역으로 보정한다. 히어로 이탈은 도색 위치만 바꾸며 실제 전투 위치를 이동시키지 않는다.

## 보존과 예산

- 프로필 저장 키/형식, 일반/개발자 저장 분리, 구매 조건/비용, 보상 지급 함수는 유지한다. 애니메이션이 액션/보상을 다시 호출하지 않는다.
- 반복 자석/2,000개 보석에서도 XP를 버리지 않는다. 보스 파괴 중 들어오는 자석 XP도 끝까지 반영하고 최종 결과 레벨에 포함한다.
- 연출은 전투 RNG를 사용하지 않는다. 기존 큐80개 제한, 보스 파편12개, 보상 이동 최대12종×3개를 사용한다. 팝업의 전체 내역/장부 지급은 장식 제한으로 줄이지 않는다. 연속 행동은 오래된 장식만 교체한다.
- 전투의 ‘시각 효과 줄이기’는 섬광/흔들림을 제거하고 파편 회전을 완화한다. 필수 순서는 유지한다.
- 기존 PNG/아틀라스를 재사용한다. 새 유료 생성이나 APK 빌드는 하지 않았다.
