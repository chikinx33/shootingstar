# 세계 보스 전용 장비·세트 — v10.0.12

2026-10-18. 공유 roguelike-game-designer의 장비/빌드 상호작용, game-balance의 조건부 효율/기존 선택 보존 기준을 적용했다. 기존 재화·슬롯·보상·전투를 유지하고 확정 획득 장비20종과2피스 세트10종을 연결했다. 아래 수치는 자체 초도 규칙이며 실제 승률/최종 밸런스를 보증하지 않는다.

## 획득과 장착

**성장 → 장비 → 관리 → 보스 전용 장비**에서 회수한다. 세계별 기존 유효 출격 조건(30초·10기 격파)을 만족하고 보스를 잡으면 해당 세계 처치 기록을 더한다. 패배해도 인정한다. 기존 별도 항로 도전은 인정하지만 훈련·일일 도전은 기존 별도 보상 규칙을 유지해 이 기록에 넣지 않는다. 기존 기본/세계 보스/항로 반복/첫 보너스를 소비하지 않는다.

세계별 누적 **1·3·5…회**마다 선체→추진기→선체 순서로1개씩 확정 회수한다. 두 부위 모두 **희귀(등급2)·Lv.0·보호 잠금**으로 지급하며 자동 장착하지 않는다. 기존 장비 보관 탭에서 장착한다. 같은 세계 희귀 이상 선체+추진기2종을 실제 장착해야 세트가 활성화된다. 소유만 하기·혼합 세계·낮은 등급·잘못된 슬롯/중복ID는 활성화하지 않는다.

인벤토리가240개면 회수하지 않고 보관함 대기를 유지한다. 빈칸을 확보한 뒤 다시 회수할 수 있고 새로고침/순환으로 소멸하지 않는다. 회수 성공 후에만 수령 횟수를 올린다. 이미 회수한 장비를 재료로 쓰거나 초기화해도 과거 수령 횟수를 돌려주지는 않는다. 기존 강화·등급 합성·정련/융합·재료 반환을 사용하며, 합성 재료로 쓰려면 기존 보호 잠금 등을 직접 해제해야 한다.

기존 catalog0~11을 보존하고12~31을 세계 순서의 선체/추진기 쌍으로 끝에 추가했다. 선체는 기존슬롯3, 추진기는5다. 기존 센서/순환 코어의 정밀 연계·순환 방호와 함께 장착할 수 있다. 기존 재생 선체/고속 추진기의 개별 효과를 동시에 유지해 주는 대체품은 아니므로 그 장비와 선택 관계가 있다. 세트 자체는 등급·강화 단계에 따라 추가 증폭하지 않으며 새 재화/현금 결제/무작위 장비 추첨을 추가하지 않았다. 기존 일반 보급·상자·상점의12종 순환은 유지한다.

효과는 현재 상태를 읽으며 출격에 복사된 세트ID로 계산한다. 출격 중 계정 장비를 바꿔도 시작한 전투의 세트ID는 바뀌지 않는다. 같은 두 슬롯을 사용하므로 세트 여러 개를 동시에 쌓지 못한다. 기존 장비 등급/강화의 기본 선체·화력은 기존 수식 그대로다.

주무기 소스는 기존 gun/primary/soul/havoc/starforge/lance/void/sword-array/fissure를 사용한다. 특이점의 보조 무기는 실제 보조 공격 스킬/진화 로켓 소스에 적용하고 궁극기·펫·폭탄을 임의로 보조 무기로 세지 않는다. 감속 세트가 감속을 자동으로 주지는 않는다. 회복은10초 간격의 전투 시계를 사용하고 정지/성장 선택 중 멈춘다. 새 투사체/적/피격 무적/슬롯을 생성하지 않는다.

기존 방패 정면 피해 계수·보스 격벽/개방 피해 계수와 단계별 HP 하한을 계속 적용한다. 피해 감소 합계70%, 치명타65% 상한도 유지한다. 세트가 없는 기존 전투는 피해 배율1로 즉시 반환해 불필요한 보조 소스 탐색도 하지 않는다.

전투 일시정지 → 전투 통계 → 현재 빌드의 기존 주무기/연계 설명에 출격 세트 이름과 조건을 함께 표시한다. 정밀/순환 연계 설명·다른 전투 시너지·공용 궁극기는 그대로다.

## 저장과 보호

루트 `bossGearVersion:1`, `bossGear:{defeats:[10],claimed:[10]}`를 기존 저장에 추가한다. 세계별 처치는9999, 회수는해당 홀수 처치 마일스톤 수(최대5000)로 제한한다. 기존 저장은 빈 기록으로 시작하며 과거 보스/클리어 이력만으로 장비를 소급 지급하지 않는다. 업데이트 이후 재도전으로 획득한다.

GearItem은 기존id/spec/rank/level/잠금/사용 재료 저장 형식을 그대로 사용한다. 확장된 catalog 길이로 새로운 spec을 복원하며 기존 편성은 실제 장비 ID를 기억한다. Worker는 새 마커의 배열 길이·정수/범위·수령 가능 수를 검사하고, 구버전의 마커 누락/변경과 이미 저장된 처치/수령 횟수 감소를409로 막는다. 기존 보상/성장 버전 보호·revision CAS도 유지한다. 로컬 파일 조작까지 막는 안티치트는 아니며 D1 스키마/운영 DB 초기화·마이그레이션은 하지 않았다.

UI는 기존 세계 배지와 슬롯별 장비 그림을 사용한다. 기존12개 그림 인덱스에 강제로 맞추지 않고 새 spec의 실제 슬롯으로 선택한다. 새 미술 생성이나 유료 API는 사용하지 않았다.
