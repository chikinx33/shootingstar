# v10.0.45 짧은 문구 줄바꿈 정리

함대 활동의 행동 버튼에서 카드에 이미 있는 임무 종류/번호를 반복하지 않고 ‘보상 받기’, ‘수령 완료’, ‘보상 회수’로 표시한다. `GameActionButton.displayLabel`을 사용해 전체 접근성 이름과 기존 보상/음향 콜백은 유지한다. 수령 조건 미충족과 수령 완료는 기존 활성 여부와 별도 claimed 인수로 구분한다. 임무의 ‘활동 상자’ 탭은 좁은 화면에서도 한 줄인 ‘상자’로 표시한다.

출석/임무/상자/항로/순찰 안내는 긴 문장에서 짧은 사실 단위로 정리했다. 한국 시간과 갱신 시각, 보상 개방 조건, 출석 누적 유지, 계정당 1회 보상, 순찰 지급 조건/시간은 유지한다. 서로 다른 정보는 의도적으로 줄을 나누며 각 문구가 끝 몇 글자만 다음 줄로 넘어가지 않게 했다. 보상 조건과 보상 수량도 별도 행으로 나눴다. 글꼴/버튼 크기/터치 영역/중앙 정렬은 유지했고 말줄임이나 강제 한 줄 잘림을 추가하지 않았다. 큰 글자에서는 필요한 자연스러운 줄바꿈을 허용한다. 좁은 반복 보급 슬롯의 긴 보상 목록은 이번 한 줄 검사 대상과 구분한다.

실제 한국어 글꼴을 로드한320px 집중 위젯 검사1개가 통과했다. 변경한 안내/행동/탭의 실제 너비로 줄 수를 검사하고, 기존 카테고리 전환/목록 초기화/고정 탭/일일50 C 및 상자 수령/중복 차단/저장 복원도 확인했다. 첫 검사에서 기존 ‘활동 상자’ 탭의 줄바꿈을 발견해 ‘상자’로 수정 후 같은 집중 검사만 재실행했다. 관련 기존 콘텐츠 검사 선택자는 표시 문구 대신 전체 행동 이름으로 유지보수했다. 소스 계약/버전 검사 통과. 집중 검사 보고서: `.local/quick-web/20261020-140750-144836/report.json`.

정식 웹320×568에서 일일/주간 화면의 간결한 문구와 전체 행동 접근성 이름, 오류/넘침0건을 확인했다. 캡처를 직접 확인했으며 근거는 `tools/qa/evidence/copy-v45/report.json`, `daily-320.png`, `weekly-320.png`다. 격리 브라우저로 사용자 저장소를 변경하지 않았다. 기본 로비/옵션 컴파일 버전/안내/출격/정지 스모크도 통과했다.
