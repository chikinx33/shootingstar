# v12.3.0 고양이 컨셉 음향 전면 교체

사용자 요청(2026-10-24): 배경음·효과음을 수호묘 고양이 컨셉에 맞게 완전히 새로 만들고, 빠진 효과음을 채우고, UI 조작음을 누락 없이 적용한다.

## 제작 방식

`tools/compose_audio.py`가 외부 음원·샘플·유료 API 없이 numpy로 전부 합성한다(고정 seed, 재실행 시 같은 결과). 기존 v10.0.35 음원은 `.local/audio-backup-v12.2/`에 백업했다.

- **고양이 목소리**: 배음 음원 + 움직이는 모음 포먼트(m→i→a→o→u)로 "냐!", "야옹", "뮤", 트릴(mrrp), 투덜(mrrr), 비명(myah!)을 만든다. 숨소리 잡음은 배음보다 낮게 둔다.
- **골골송**: 26Hz로 맥동하는 저역 잡음. **병아리**: 짧은 사인 처프 "삐요".
- **악기**: 오르골·피치카토·칼림바·마림바·부드러운 칩튠 리드·브러시/박수/파우 탐 드럼.
- 효과음은 작은 방 잔향 뒤 −42dB 이하 꼬리를 잘라 실제 들리는 길이로 저장한다. 주무기10종은 같은 체감 음량이 되도록 부드럽게 포화시킨다.
- 음악은 원형 믹싱(꼬리·에코·잔향이 루프 처음으로 넘어감)으로 이음새가 없다.

| --- | --- |
| `lobby-groove.wav` 집사네 거실 | F 장조 100 BPM 스윙, 16마디/38.4초. 오르골 멜로디·피치카토 아르페지오·칼림바 엇박·브러시 드럼·악구 끝 새끼고양이 "뮤"·트릴·골골송 바닥 |

| `boss-theme.wav` 진공 제국 습격 (신규) | D 화성단음계 160 BPM, 16마디/24초. 진공청소기 웅웅 드론·타이코·스타카토 베이스·하악 악센트 |

| 성공 | 장착=방울 목걸이, 구매=동전+냐, 보상=반짝 아르페지오+야옹, 강화=골골+상승 아르페지오, 출격=길게 냐아~+휘익 |

| 신규 | `missile`(고등어 미사일 발사), `laser`(광선), `pet`(병아리 사격·회복·탄 제거 "삐요"), `pick`(성장 카드 선택), `transform`(무기 궁극 변신), `boss-theme`(보스전 배경음) |
| 별칭 | 엔진의 `lightning`→`skill-electric`, `explode`→`explosion` (이전엔 소리 없음) |

- 보스가 있는 동안 `AudioScene.boss`로 보스곡을 재생하고, 정지 후 재개해도 보스곡을 유지한다.
- 궁극 변신은 진화 신호도 함께 내므로 `transform` 직후 400ms 안의 `evolution`은 생략한다.
- 음악 음량은 곡 밀도가 달라도 로비와 같은 평균 크기가 되도록 `min(.44, .062/RMS)`로 맞춘다(기존 peak 예산 .44 유지).

## UI 조작음 전수 점검

모든 `onPressed/onTap/onLongPress/onSelected/onChanged/...` 콜백을 받는 위젯까지 추적했다. 새로 채운 곳:

- 전투 통계 탭바(`TabBar.onTap`), 격납고 팝업 메뉴(열기/선택/취소), 드롭다운 5곳의 열기음, 파츠 편집기 탭 선택.
- 성장 카드 선택은 일반 클릭 대신 `pick`.
- `GameAudioHost`: 로비에서 실제 탭/키 입력 뒤 1.5초 안에 프로필이 바뀌면 화면과 관계없이 강화(레벨 상승)·구매(재화 감소)·보상(재화 증가) 소리를 낸다. 고양이 장비·모듈 강화, 이야기 보상처럼 직접 소리를 부르지 않던 새 화면도 포함한다. 같은 소리의 중복은 디렉터의 이벤트 간격으로 합쳐진다. 장착 감지에 고양이 장비·기체 조립 파츠를 추가했다.
- 의도적으로 무음: 전투 이동/조이스틱 드래그, 편집기 팬, 글자 입력.
