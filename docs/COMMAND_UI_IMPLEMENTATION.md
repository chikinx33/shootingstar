## 적용 구조

- 길드: 로그인/합류 폼·현황·토벌·보급·오류는 `GamePages`. 모집 길드·길드원만 항목 목록. 네 분류가 글자 폭을 확보하지 못하면 2×2로 전환한다. 입력 키보드가 열리면 장식 헤더/분류를 접고 앱바·입력 페이지·페이지 제어를 남긴다. 실제 서버의 기존 요청/우편 지급·중복 ID 방지 경로를 유지한다.
- 편성: 여섯 슬롯만 목록으로 이동. 큰 64px 기체 그림, 24px 이름, 16px 요약, 공통 저장/적용/이름/삭제 버튼. 보이는 문구는 ‘편성 저장/교체/적용’으로 간결하게 두고 전체 기능명은 접근성 라벨에 유지한다. 모든 폼/확인은 `GameDialog`. 긴 사용자 이름은 본문에 두어 제목·닫기를 보호한다. 저장 대화상자가 열린 사이 슬롯이 바뀌면 덮어쓰기를 중단한다.
- 진화: 금색 고정 헤더·계열 탭, 고정 상단 도감 아이콘 48 터치/32 그림. 단계 목록에 그림 64, 제목 24, 효과 18, 상태/비용 16 이상과 공통 연구 버튼. 기존 `buyUpgrade`, 비용·레벨·한계는 그대로 사용한다.
- 챕터: 세계 그림/제목을 세로로 배치해 이름을 잘게 나누지 않는다. 반복 세계/항로만 목록. 항로 상세/선택은 고정 페이지 팝업. 선택 완료는 목록 아래 고정. 기존 해금·완주·순환·선택 저장을 유지한다.

주요 행동 72/22/36, 보조 행동 64/20/32, 결정 버튼 폭 최대 264, 종횡비 최대 4.25. 폼·상세·확인은 스크롤 대신 측정된 고정 페이지다. 편성/연구 알림은 바닥에서 80px 띄워 페이지 제어를 가리지 않는다. `CatalogHeader.action`은 선택적인 상단 도감 제어이며 기존 화면의 기본 배치는 유지한다.
