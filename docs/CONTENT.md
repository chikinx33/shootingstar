# 콘텐츠 v3 규칙

## v4.5 보상 개정 (2026-10-15, 아래 과거 보상 공식보다 우선)

기존 재화·장비 ID·잠금·강화 환급 이력·펫·테크·클리어 기록을 유지한다. 저장 버전은 4이며 content에 누적 보급 진행도와 희귀 테크 선택권 상태만 추가한다.

- 일반/도전에서 챕터 진행 30초와 10격파를 모두 달성하면 보상을 계산한다. 훈련은 제외한다. 보스전의 추가 시간은 시간 보상에 포함하지 않는다.
- 크레딧: `진행초~/3 + min(격파, 진행초*2)~/8 + 보스처치*40 + (승리 ? 100 : 0)`.
- 유효 출격의 진행 시간을 누적하여 120초마다 보급 묶음 1개. 남은 시간은 다음 출격으로 이월한다. 보스 처치당 1개, 승리 시 1개를 추가한다. 묶음마다 장비 1, 테크 1, 먹이 10, 설계도 1. 창고가 가득 차면 장비권으로 대체한다. 승리의 장비권 1·펫권 1과 첫 도전 보너스는 유지한다.
- 비교: 30초/10격파 귀환 20회는 220 C·묶음 5개, 600초/200격파/보스 3회 완주는 445 C·묶음 9개다. 동일 챕터 진행 시간에서 조기 귀환 반복의 고정 보상 이득을 없앴다. 실제 플레이 시간에는 보스전이 추가된다.
- 일일 출격은 120초 생존 또는 보스 처치 또는 승리 시 인정한다. 시즌 XP는 `진행초~/6 + min(80,격파~/20) + 보스*20 + 승리50`으로 변경한다.
- 첫 챕터 보스 처치 시 계정당 희귀 테크 선택권 1개를 해금한다. 성장 → 테크에서 확정해 받는다. 기존 첫 챕터 클리어 계정도 받는다. 이미 슬롯이 가득 차면 보유만 하고 직접 장착해야 한다. 수령 상태는 재접속 후에도 유지한다.

정산 ID 중복 방지, 이전 저장 호환, 보급 잔여 시간 저장, 테크 중복 수령 방지는 자동 테스트로 검증한다. 웹 검증은 별도 브라우저의 로컬 게스트 데이터로 수행하며 운영 계정과 서버 데이터를 수정하지 않는다.

## 장비

6슬롯 × 2종 = 12종. 일반→우수→희귀→엘리트→에픽→전설. 같은 종류/등급의 장비 3개 합성, 선택한 대상의 ID/레벨을 유지하고 나머지 2개를 소모한다. 잠금·장착·강화 장비는 재료 후보에서 제외한다. 합성 직전에 소모 ID를 확인한다. 최대 240개이며 가득 차면 출격 장비 드롭은 보급권으로 보관한다.

강화 상한은 20 + 등급×10. 비용은 30 + 현재 레벨×20 크레딧 및 설계도 1. 초기화는 실제 투입량을 전액 반환하고 등급을 유지한다. v2 강화 이력은 당시 비용 공식으로 복원한다. 장비 종류마다 시작 무기, 화력, 선체, 수집 반경, 이동 속도, 피해 감소, 회복 등이 다르다.

## 펫·테크

펫은 동일 로봇 여우 디자인의 역할 3종이다. 첫 루미 기본 지급, 이후 미오→볼트→루미 순환 구조. 중복은 유전자 +1. 먹이 레벨×10, 각성 유전자 3×(등급+1), 최대 전설. 보조 루미 쿨다운 -4%, 미오 회수 반경 +10%, 볼트 피해 -5%. 출전 펫과 보조 펫은 중복 배치 불가.

루미는 주기적 탄환, Lv.5부터 2발. 미오는 12초마다 회복, 볼트는 3초마다 근처 적탄 제거. 레벨/등급에 따라 효과 강화. 적과 접촉하면 체력 감소, 쓰러진 펫 80거리 내에서 8초 체류하면 부활. 정지/선택/결과 중 펫도 정지한다.

테크 8종은 무기 8종에 각각 대응. 공격 분류 4종 중 3개, 방어 분류 4종 중 3개 장착. 장착 부품의 최고 보유 등급 적용. 등급마다 해당 무기 피해 +5%, 희귀부터 명시된 고유 효과 적용. 무기 자체는 전투 중 선택해야 한다. 같은 등급 3개로 다음 등급 1개 합성.

## 보상·일정

일반/도전 출격 30초 + 10격파 이상: 장비 1, 테크 1, 먹이 10, 설계도/크레딧. 승리 시 추가 먹이 20, 장비권 1, 펫권 1. 훈련 제외. 전투 ID 중복 정산 방지. 창고가 가득 차면 장비권으로 대체.

장비 보급은 12종 순환, 매 3회 우수, 매 10회 엘리트. 드롭과 보급 횟수는 독립이다. 테크는 8종 순환. 유료 확률 상품 없음. 교환소 품목마다 하루 3회.

한국 시간 자정에 일일 임무·교환 횟수 초기화. 월초 시즌 초기화. 100 XP마다 단계, 총 20단계. 출격 XP = 20 + min(80,격파/20) + 승리50. 일일 임무 3개 각50 XP. 지난 시즌 달성한 미수령 단계는 우편으로 이월. 보상 수령은 한 번만 가능. 순찰 최소30분, 최대480분, 30분당20 C / 60분당 설계도1+먹이5. 기기 시계의 일반적 역행은 마지막 관측 시간으로 막지만 로컬 저장은 서버 권위 재화 보안이 아니다.

## 길드

`tools/play_web.py`의 `/api/` JSON API, SQLite 파일 `.local/guild.sqlite3`, 등록 토큰은 서버에 SHA256 형태로 저장. 길드 정원20, 6자리 초대코드, 실제 가입자 목록. 출석 하루1회 코인10/길드XP20, 기여 코인10→XP30. 길드Lv = 1 + XP/200.

주간 토벌 한국 시간 월요일 초기화, HP100000. 유효 출격 1격파=피해3, 1회 최대3000, 하루3회. 보고서가 서버 접수 당시 길드에 귀속되어 탈퇴해도 피해가 다른 길드로 이동하지 않는다. 전투 보고 재시도는 중복 적용되지 않는다. 주간보상은 본인 기여 필요. 일일보급은 코인10으로 먹이30+설계도2. 보상 영수증은 서버에서 재전송하고 클라이언트에서 ID 중복을 방지하므로 응답 유실 시 복구 가능.

현재는 개발용 loopback 서버다. 같은 PC의 별도 브라우저 프로필끼리 공유할 수 있다. 공개 서비스에는 TLS·정식 계정 인증/복구·서버 권위 전투 검증·재화 통합·운영 배포가 필요하다. Android 외부 서버 URL은 `--dart-define=GUILD_API=https://...`로 설정 가능하나 현재 공개 서버는 없다. 클라이언트 보고 전투를 신뢰하므로 공용 경쟁 서비스로 배포하지 않는다.
