# 전투 연출 즉시 재현 확장 — v10.0.22

사용자 요청의 피격·스킬 진화·궁극기·방패 역습4종만 기존 연출 재현 메뉴에 추가한다. 테스트 상단✨ → 연출 재현에서 기존 자석/보스/보상/구매와 함께3열 그림 슬롯으로 고른다. 뒤로/다시 재현을 제공한다. 슬롯마다 반복되는 “바로 재현” 상태 문구는 제거한다.

- 피격: 실제 적탄이 기체에 충돌해 체력 감소·피격 섬광·피격음을 실행한다.
- 스킬 진화: 로켓5단계+고출력 연료를 준비하고 실제 보스 보급 상자가 진화시킨다. 진화 섬광/궤도와 진화 로켓 발사를 확인한다.
- 궁극기: 기본 파일럿의 준비된 항성포를 실제로 발동한다. 전방 표적에 피해를 주는2초 빔과 파동이 재생된다.
- 방패 역습: 수호자3+반응 장갑, 펄스 주포를 준비한다. 실제 적탄 차단 후 다음3발 주포 공격이50% 강화되는 순서를 재생한다.

매번 기존 `Profile.presentationCopy`의 비저장 복사본을 사용한다. 저장 스키마/일반 전투/기존 개발자 진행과 전투 설정은 변경하지 않는다. 재현 준비는 엔진의 공개 전투 경로만 호출하며 진짜 판정 없이 그림만 강제로 띄우지 않는다.

짧은 네 재현은 화면 전환을 마친 뒤650ms의 활성 대기 후 시작한다. 명시적 일시정지/앱 배경 상태에서는 대기도 멈추며, 나가면 타이머를 취소한다. 이 네 화면에만 `presentationAutoplay`를 주어 입력 없이 정상 속도로 보인다. 일반 전투의 입력 해제5%·누름100%는 그대로다. 자석/보스/보상/구매 기존 경로는 수정하지 않았다. 새 네 재현에서는 연출을 가리던 일반 웨이브 예고·이동 안내·궁극기 충전 버튼을 숨기고 HUD/일시정지는 유지한다.
