# 한국어·영어 모드 — v10.0.46

설정의 `한국어` / `English`에서 즉시 전환한다. 처음 실행하는 기기의 기본 언어는 한국어다. 언어는 `shootingstar.language.v1` 기기 설정에 저장하며 플레이 진행/클라우드/백업/개발자 프로필과 분리한다. 앱이나 브라우저를 다시 열면 선택을 복원한다. 지원하지 않는 저장 값은 한국어로 돌아간다. 빠른 연속 선택의 저장은 순서대로 처리한다.

`lib/l10n/app_language.dart`의 `LanguageScope`/`AppLanguage`가 기존 위젯에 언어 변경을 알린다. Navigator와 StatefulWidget, 전투 엔진을 새로 만들지 않는다. Flutter 기본 조작의 언어도 `flutter_localizations`로 맞춘다. 웹 문서의 언어/제목과 다음 실행의 로딩 안내도 맞춘다.

`english_catalog.dart`는 오프라인 표시 번역1844개다. 메뉴/버튼/상세/입력 안내/접근성/콘텐츠 이름과 설명/전투 도색/길드 우편/서버 오류를 포함한다. `tr`은 표시 경계에서 원문과 조합된 데이터 라벨을 처리하며, `message`는 알려진 문구와 치환 인수를 분리해 숫자·순서가 모호해지지 않게 한다. 원본 콘텐츠 ID와 수치, 비교/보상/저장 규칙을 번역하지 않는다. 직접 표시하는 사용자 닉네임/길드 이름/편성 이름은 원문으로 둔다. 실행 중 온라인 번역 API나 비용은 없다.

영어 설정은 제목을 별도 행에 두고 링크 그림 아래 짧은 Profile/Input/Legal을 표시한다. 전체 접근성 이름은 Account/Controls/Licenses다. 하단 로비는 Trials/Lab을 사용한다. 공통 CatalogTabs는 한국어 글꼴18px/실제 글자 배율과 번역한 이름을 측정해 필요한 경우 행을 나눈다. 영어 Check-in/Missions 등의 끝부분을 Chip의 fade로 숨기지 않으며 글자 크기를 줄이지 않는다. 선택 인덱스/콜백/고정 탭과 반복 항목만 스크롤하는 규칙은 유지한다.
